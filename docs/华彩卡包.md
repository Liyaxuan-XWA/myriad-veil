## 入口与解锁

- **2026-10-30 用户定**：卡包从图鉴迁到「成就 → 成就收藏」，图鉴不再有卡包卷目。
  原初位面左上角「指引书 / 图鉴」下新增「成就」入口（`achievement_panel.gd`）。
- 成就分「成就任务 / 成就收藏」；任务页登记每只 BOSS 的四张卡获取条件，收藏页只列已获得的卡。
- 点亮条件按卡种分开（2026-10-30 用户定）：
  - **普通卡**：击败对应的 BOSS —— 万界塔看 `get_tower_clear_count(floor) >= 1`，
    万界位面击败同一只 BOSS（`boss_progress` / `is_boss_unlocked`）同样算，
    大陆核心首领看 `secret_world.core_kills[region]`；
  - **华彩 · 有背景**：击败同一层的双倍气血 BOSS（第 11 次起为 2× 血，`clear_count >= 11`）；
  - **纯华彩 · 无背景**：**无伤**通关同一层的双倍气血 BOSS
    （`CharacterData.tower_no_hit_double[floor]`，通关结算时若 `took_damage_this_battle == false`
    且当前已是第 11 次及以后，就记下）。
  - **纸本水墨**：每位 BOSS 都有一套，击败对应的塔层投影 / 区域核心即收（`unlock: boss`）；
    老存档只要已击败过，打开收藏册就自动补上。
  - 判定都是现算的：老存档只要满足条件，打开收藏册就会亮。
- 大世界核心首领（青岚古猿 / 云隐苍角 / 赤金火麟）也有普通卡，击败即收；
  华彩 / 纯华彩走**塔内分支重战**：`core_replay[region].clear_count >= 11` 解锁有背景，
  `no_hit_double` 解锁无背景（与塔层同口径，但状态分开存，不占塔层号）。
- **没获得的卡不显示**：连卡位都不出现；BOSS 一张卡都没有时整个格子也不出现。

## 页面

- **收藏册**：只列至少有一张卡的 BOSS，一格一位（3 列）。格子的**封面 = 展开页排第一的卡**，
  静态叠卡预览（有几张垫几层）+ 「N 张」+ 名字 / 层数浮签；悬停轻微放大。
- **点开一个 BOSS**：只铺已获得的卡，从舞台中央依次扇形展开（每张错开 0.05 秒，带旋转 / 缩放 / 淡入）。
  第一张在正中、压在最上层；其余左右交替往后排。四张时卡面自动缩到 216×324，
  扇距同步收窄，四张牌与底下卡种名不互相压住（三张及以下仍用 280×420）。
- **拖动换位**：展开页可以按住任意一张卡拖到别的卡位上，松手后整组重新排位；
  第一位就是收藏册封面。卡序存在 `CharacterData.card_order[boss_id]`（随存档走），
  关面板时若拖过会补一次自动存档。
- **单卡查看**：点卡进入大图；普通卡是静态原画；华彩卡可按住拖动看视差；
  纸本水墨卡打开时 1.8s 从主笔触向外落墨，鼠标在卡面移动时整卡微倾，
  快速晃动向墨面荡开一圈墨环；「上一张 / 下一张」切换，
  ESC 逐层后退（单卡 → 展开 → 收藏册 → 关面板）。
- 展开页的点击 / 拖动走 `AchievementView._input`（事件坐标是画布坐标），不依赖舞台面板的 `gui_input`；
  实时卡只在展开 / 单卡页创建，收藏册格子用静态贴图。

## 卡种与通用结构

- 卡面统一走 `scripts/ui/card_face.gd`（`CardFace`）：按 `style.kind` 决定用哪个渲染器。
  - `holo`：`HoloCardView`，视差 + 箔光（有背景 / 无背景两版）；
  - `ink`（纸本水墨，12 位一套）：`kind=still / fx=paper`，走 `assets/shaders/ink_paper.gdshader`；
    640×960 新原画，纸面纤维 / 吸水边缘 / 留白都直接留在图里；
    单卡页落墨 / 微倾 / 墨环，展开页与封面只出静态画面；
  - `still`：静态原画 + 圆角遮罩（`assets/shaders/card_still.gdshader`）。
    原画普遍偏暗（虎妖平均亮度约 40/255），shader 手写 sRGB 编码（`srgb_encode()`）
    让卡面亮度与原画一致；⚠ 本机引擎没有 `linear_to_srgb()` 内置函数，用了会编译失败退回无 shader 直绘。
- 数据在 `CodexDB.card_entry()` 里铺 `card_variants`：每个变体都有
  `id / kind / label / desc / art / unlock / unlocked`；展开与收藏册只认 `CardFace` 和卡序，
  不认具体卡种，数量 N 变化不用改布局（扇形按 N 自动算，四张时缩卡面）。
- **新卡种**：往 `CodexDB.card_entry()` 里追加一个 variant（或 `HOLO_CARDS[boss].styles`）；
  纸本水墨的公共样式在 `CodexDB.INK_STYLE`，每位只写 `INK_NOTES` 小传。若需要新渲染方式，在 `CardFace.configure()`
  加一个 `kind` 分支与一个 `_build_xxx()`，收藏册与展开自动多一张。

## 卡面分层与着色

资产（640×960，对应源卡 2:3）：

- `assets/ui/codex/holo/boss_01_art.png`：角色 RGBA（抠图、去棋盘格、2px 收边）
- `assets/ui/codex/holo/boss_01_bg.png`：完整背景板（无人物、无字、无框）
- `assets/ui/codex/holo/boss_01_lines.png`：白线结构图（从最终角色 alpha 轮廓生成）

着色器：`assets/shaders/holo_card.gdshader`，控件：`scripts/ui/holo_card_view.gd`。

- 背景：`b=(p-.5)*.5+.5-view*.25`，2× 取样，视角移动时独立错动。
- 角色 / 描边：同一坐标 `a=p-view*(depth<0?.06:.08)*depth`；叠加顺序固定为 **背景 → 角色 → 描边光**。
- 结构线只取 `lines` 覆盖 × 角色 alpha；描边光 12 次邻域取样做柔光，不向场景或角色内部溢光。
- 箔光带 + 视角高光；描边光以暖金为主，只掺一点棱镜色，避免整圈彩虹边。
- 圆角遮罩在 shader 内按 `card_px / corner_px` 计算；Godot 侧再叠两层细框与四角金线。

### 旧管线补背景的落地修正（2026-10-29）

- 旧模板 HTML 的背景 UV 是 0.5× 采样（视觉上把背景放大 2×），角色层近似 1:1；真实背景会被放大位移，石径和接触影跑到脚外，脚就像悬在雾里。
- 本作业把 `index.html` 的两处 `b=(p-.5)*.5+.5-view*.25` 改为 `b=uv-view*.08`，背景 1:1；角色/结构整体下移 18px；接触影按 1:1 重烘（底部石径在脚下）。
- `native.py assemble` 会重新生成 0.5× 的 HTML；重跑后必须重打这个 1:1 补丁。`task.json` / `provenance.json` 已记 `background_sampling` 备注。
- 虎妖待机帧本身有一后脚抬起，是步态；判断是否悬空要看脚底是否有石面/接触影，而不是四脚是否同高。

### 为什么上一版「无背景」仍不如第一版（2026-10-29 复盘）

不是参数没照抄，而是**上一版根本没有使用第一版的渲染栈**：

- 第一版 HTML：`emission=(spectrum*.85+.15)*line*envelope*40*contour`，发光值可达 6，再经过 0.5×/0.25× 两级 bloom 和 `1-(1-linear)*exp(-(emission*.38+bloom*.85))` 色调映射；卡片内部按约 880×1232 渲染。
- 上一版游戏 shader：LDR 直接加色，`emission` 峰值约 0.42，没有 bloom、没有 HDR 余量；为了补亮把 contour 提到 .24、gain 1.45、wide .5、aura .45。这会把颜色洗淡，而不是第一版的「亮线核心 + 暗底」。
- 其他偏差：背景采样 1:1（第一版是 2×）、结构线 40% 膨胀、详情卡 295×442（比第一版预览的约 440×660 小）。

现在 `holo_card.gdshader` 的 `legacy` 通道按第一版公式重写：保留 `+0.15` 抬升、`40×contour` 发光、箔光带 `.48`、星点/微尘、glare、bloom 包络与阈值、最终色调映射；背景改回 `.5/.25`；结构线用 20% 膨胀补偿 330 显示尺寸。**仍是近似**：游戏单 pass 不能用真正的分离式 bloom，卡片显示尺寸也比第一版预览小。要做到像素级一致，需要把卡片放到 2× SubViewport 或做大尺寸详情卡，代价是 GPU 与布局空间。
