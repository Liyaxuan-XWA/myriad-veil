# 赤霄界第三位 BOSS · 赤霄劫主「晏无咎」设计案

> 2026-10-29 · 每日 BOSS · 万界塔第 9 层 · 赤霄界终章
> 机制定稿：**三灾轮转**（风 / 火 / 雷 · 破灾与灾势）
> 设计案负责「为什么」；数值、AI、掉落见《晏无咎BOSS完整资料.md》。

---

## 一、头脑风暴与取舍

赤霄界前两位已经占掉「雷部判词」和「天火种争夺」；第三位是位面终章，
必须有一套能收束「风、火、雷」的机制，又不能重复现有七种机制
（刀痕、剑意、雷势判词、天火种、阵旗、气环、阴阳护体、距离/苔甲）。

| 提案 | 核心 | 优点 | 问题 | 结论 |
|---|---|---|---|---|
| **三灾轮转** | 风/火/雷三方相克；双方各有灾位，克位才能破灾、攒灾势 | 攻防双向读条；技能天然分成三组；二阶段可做「三灾归一」 | 需要把「谁克谁」讲清 | **采用** |
| 天劫回响 | 每次施法留下劫影，延迟重放该招 | 时间维度新 | 与刀客「留痕→引爆」太近 | 否 |
| 劫链 | 双方被一条雷火链连住，距离决定传导 | 连线感强 | 与阵线/牵日视觉与操作相近 | 否 |
| 劫数承负 | 每次出手积劫数，可转嫁给对方 | 资源转移有趣 | 本质仍是攒层放大招 | 否 |
| 雷火双印 | 给目标上雷印/火印，双印引爆 | 组合直观 | 与两仪印/灼心/感电叠层同构 | 否 |
| 劫云落点 | 场上劫云按编号落下，可推给 BOSS | 空间互动强 | 仍是延迟圈/场地，离照日轮已用 | 否 |
| 三头法相 | 三颗头分别代表风火雷，切换头 = 切招 | 形象强 | 三套 AI 成本高，玩家侧继承生硬 | 否 |

**取舍理由**：三灾轮转让「读对手当前状态」和「改自己的状态」变成同一件事。
不是 BOSS 单方面挂弱点，也不是玩家单方面攒资源：双方都在转轮，谁先被对方克住，
谁就掉灾势、吃额外伤害。玩家可以用技能顺序主动转轮，也可以被 BOSS 的「锁灾」钉住。
二阶段「三灾归一」把所有克制暂时关掉，改成 8 秒高风险高收益的爆发窗。

## 二、形象与位面终章

- 位面：赤霄界。赫连霄「雷出于地」、离照「火生于天」；
  晏无咎是「三灾落于人」——渡劫失败、却被劫灰重塑的**赤霄劫主**。
- 名字：**晏无咎**（无咎 = 无灾无过，反讽他走到哪里哪里就是灾）。
- 称号：**赤霄劫主**；判词：**执掌三灾的天劫**。
- 外形：清瘦、无重甲；**灰白丧服式祭袍**，内层压着赤火与雷紫；
  脸覆**裂开的白玉三目面具**，黑发披散，**不持兵器**，右手捏剑诀。
  背后悬着**三轮破碎的劫环**（风青灰 / 火赤 / 雷紫白），不是完整光环。
- 与赫连霄（重甲、铁笔、雷鼓、紫雷环）和离照（赤黑祭袍、日轮扇、赤日）
  在颜色（灰白为主）、剪影（无兵器、碎环）和气质（丧服劫主）上彻底分开。
- 战场：**三灾台**——灰白焦土、三道断裂的环形刻痕、风蚀/烬火/雷击三种地貌拼在一起；
  比焚天祭坛更冷、更荒，给彩色灾术留出对比。

## 三、机制：三灾轮转

### 3.1 灾位

- 三灾：**风（青灰）/ 火（赤金）/ 雷（紫白）**。
- BOSS 与玩家各有一个**灾位**，显示在头顶三灾轮上。
- 玩家施放**任意风 / 火 / 雷属性功法**命中都参与破灾 / 喂灾（不要求晏无咎本族）；玩家侧灾位切换、灾势、灾替与万劫归一仍由本族功法驱动。首战没有本族功法也能用现有属性功法破灾。
- BOSS 按当前灾位出招；每 8 秒（二阶段 5 秒）起一次「三灾轮转」换灾位。

### 3.2 相克与破灾

- 相克：**风克火 / 火克雷 / 雷克风**（三灾轮箭头明示）。
- 玩家用**任意克制 BOSS 当前灾位的风 / 火 / 雷属性功法**命中 → **破灾**：
  - 该次伤害 ×1.15；
  - 玩家 **灾势 +1**（上限 3）；
  - BOSS 进入 **灾崩 3 秒**：失去灾身 buff、受到伤害 +30%、灾轮在整段灾崩内冻结；
  - BOSS 灾势 -1。
- 玩家用**同灾位**功法命中 → 伤害 ×0.85，BOSS 灾势 +1（喂灾）。
- 玩家被 BOSS 的克制灾位命中 → 玩家吃 ×1.15、灾势 -1、挂「锁灾 2 秒」；
  玩家有「灾替」时改为免疫该次额外伤害并 +1 灾势；三灾轮转起手给 1.5 秒，三灾轮法宝给 8 秒，两者都只免一次。

### 3.3 灾势

- 玩家：每次**切换灾位** +1；每次**破灾** +1；上限 3。
- BOSS：每次**三灾轮转** +1；每次破玩家灾位 +1；上限 3；玩家破灾会扣它 1。
- **万劫归一**消耗全部灾势：每层追加灾柱/伤害；0 层也能放，只是弱。
- 灾势不是「攒满放大招」的独立资源：它只由**轮转和破灾**产生，逼玩家读灾位。

### 3.4 灾身

| 灾位 | BOSS 灾身 | 玩家灾身 |
|---|---|---|
| **风** | 移速 +25%；物理命中击退 200 | 移速 +12% |
| **火** | 命中挂「劫火」（每秒 6 点，4 秒） | 法技增伤 +12% |
| **雷** | 命中挂「感电」（受伤 +15%，3 秒） | 攻速 +12% |

- 灾身只在**未灾崩**时生效；破灾会把灾身打掉 3 秒。
- BOSS 的灾身是它「同灾位不可硬碰」的原因；玩家的灾身是轮转的收益，需装备被动「三灾·灾身」才会开启。

### 3.5 二阶段：三灾归一

- 50% 血进入 8 秒 **三灾归一**：
  - BOSS 同时拥有风/火/雷三灾身，所有命中附带击退 + 劫火 + 感电；
  - 三灾轮显示「乱」，**无法破灾**；
  - BOSS 受到伤害 **+20%**——这是玩家的爆发窗。
- 8 秒结束后：BOSS 灾势 +1，灾轮加速（5 秒一转），**万劫归一**的门槛从 2 层灾势降到 1 层。
- 这是二阶段专属机制层：不是加数值，而是**暂时关掉克制**，把读条战改成生存 + 爆发。

## 五、行为树与弱点

### 选招

1. **当前灾位**决定可用招：风=步/斩；火=印/燎原；雷=引雷/雷池。
2. **玩家克制自己**（连续两次破灾）→ 起「三灾轮转」换到克制玩家的灾位；若轮转在冷却，用位移/雷池拉开。
3. **玩家同灾位** → BOSS 灾势涨，优先「万劫归一」兑现。
4. **玩家贴脸** → 断空斩 / 燎原 / 雷池；**玩家拉扯** → 裂云步 / 引雷诀 / 焚天印。
5. **二阶段三灾归一**：全招池随机，结束前尽量放万劫归一；归一结束后灾轮加速。

### 弱点与反制

- **轮转前摇 0.7 秒可打断**：用克制它**当前**灾位的功法命中，会取消轮转并直接灾崩。
- **玩家雷池锁灾**：BOSS 3 秒不能换灾位，是连续破灾的窗口。
- **三灾归一 +20% 受伤**：玩家的爆发窗，但要先活过三重灾身。
- **弹反**：裂云步、断空斩是物理近战，弹反会让 BOSS 硬直。
- **不能逃课**：不理灾位 → BOSS 同灾位减伤、灾势涨、万劫归一；只用一个元素 → 无法破灾、没有灾势。

## 六、数值反推（结丹后期标准档）

- 结丹后期 · 宝器 +4（探针实测）：
  365 气血 / 127.0 物攻 / 82.5 法攻 / 物抗 62.2（38.4%）/ 法抗 27.2（21.4%）；
  2.5 刀/秒 402 DPS，满速 501 DPS。
- BOSS：**20,500 血 / 108 攻**；70% 有效输出约 69 秒，75% 约 65 秒；
  二阶段 ×1.25；三灾归一额外 +20% 受伤，抵消一部分机制时间。
- BOSS 单发（过抗后，宝器 +4 实测）：裂云步 53 / 断空斩 63 / 焚天印 72 / 燎原每跳 45 /
  引雷诀 98 / 雷池每跳 47 / 轮转 41；万劫归一 130（0 层）→ 约 240（3 层 · 二阶段）。
  普通招约 11~33% 气血；万劫归一约 36~65%（可走位躲）。
- 玩家万劫归一：1.6 + 0.5×灾势，3 层 3.1× 法攻；不参与常规 DPS，只做爆发窗兑现。
- 掉落装备不追数值膨胀：**劫锋**（力量 +20 / 攻速 +3%）补纯输出武器；
  **劫灰法衣**（气血 +20 / 物抗 +4 / 法抗 +4）补物法双抗的均衡生存。

## 八、美术与特效方向

- 角色：灰白丧服 + 赤火/雷紫内衬、裂开的白玉三目面具、无兵器、右手剑诀；
  背后碎成三段的劫环（程序化，不画进 T-pose，方便骨骼拆分）。
- 战场：灰白焦土 + 三道断裂环痕，冷灰紫环境，让三色灾术跳出来。
- 卡面：低机位 3/4，三目面具特写，右手剑诀，三段碎环悬在背后，风/火/雷三色灾印围绕。
- 特效语言：**碎环 + 灾印 + 灰烬**；
  风用青灰风带，火用赤金余烬，雷用紫白柔光柱（不用赫连霄的锯齿雷弧）；
  三灾轮转是一枚三色轮；万劫归一是三环合拢后炸成灰白风暴。
- 图标：8 技能三色圆徽（同一枚碎环母题），6 物品图标（劫锋/法衣/劫灰/元魂/劫主令/三元轮）。

## 九、验收口径

- 机制必须由 8 式联动：转轮、破灾、锁灾、灾崩、灾势、归一都能在实战中发生。
- 玩家侧完整继承：玩家可在任何战斗转轮、攒灾势、放大招；对本 BOSS 可破灾。
- 每个 BOSS 招式至少一个应用场景；每个玩家技能至少一个使用理由。
- 全链路探针覆盖：数据、八式双侧、转轮、破灾、同灾、锁灾、灾崩、灾势、二阶段归一、
  BOSS 八式全路径、玩家 `try_use_skill`、图鉴/塔/合成。
- 已验证：数据/八式双侧/被动探针 175 项通过、真实箱庭联调 11 项通过；**未实机、未提交**。
- 实机重点：三灾轮读条是否一眼看懂、破灾窗口、锁灾手感、归一爆发窗；长袍无腿分件，走路是滑行+起伏，实机若违和再加袍摆。
