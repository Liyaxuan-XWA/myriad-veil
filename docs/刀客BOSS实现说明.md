# 刀客 BOSS 实现说明

> 对应设计案：《万界秘境》刀客 BOSS 战斗机制设计案 V1.0
> 代码：`scripts/boss/domain_boss_01.gd` + `scenes/boss/domain_boss_01.tscn`
> 招式数据：`MoveDB` / `SkillDB` / `WorldDB.BOSS_MOVES`
> 最后核对：**2026-10-23**

## 0. 落地口径（与设计案的对应关系）

| 设计案要求 | 实现方式 |
|---|---|
| 刀势 0–100，命中 +10 / 落空 -8 / 每秒 -4 | ❌ **已整体删除**（2026-10-22 用户定）。满势断岳改为「目标站在刀痕上」触发，见 §1 |
| 刀势 60 起强化版、100 放满势断岳 | ❌ 随刀势一起删除。当前没有任何「刀势高就变强」的招式，也没有刀势条 |
| 不使用固定技能循环 | `_pick_best_skill()` 按评分选招 |
| 出招承诺不可取消 | 沿用 `BossState.WINDUP/ATTACK/RECOVER`，蓄力后段锁定方向 |
| 物理无 CD、法术有独立 CD | `MoveDB` 的 `boss.cooldown_p1/p2`，只有法术填写 |
| 刀痕上限 4、留存 10 秒 | `ScarField.MAX_NORMAL`、`BladeScar.SCAR_LIFE` |
| 激活 = 瞬间斩击（法术伤害），斩后刀痕消失 | `BladeScar.slash()`，见 §2 |
| 二阶段 50%，只强化不新增机制 | `_on_phase_two()`，只置 `_phase2` 影响倍率与移速 |
| 阶段切换不重置 CD / 不清刀痕 / 不回血 | `_on_phase_two` 里刻意什么都不做 |

### 与任务书冲突时的取舍（按用户要求，遵守既有规定）

| 冲突点 | 采用 |
|---|---|
| 设计案「不设置僵直破防」 vs 任务书「弹刀成功 → BOSS 僵直」 | **保留弹刀僵直**（任务书硬约束）；「无破防」= 没有韧性条，两者不矛盾 |
| 设计案未提弹刀 | 物理近战（P1–P5）可弹；法术（M1–M4）不可弹 |
| 远程物理无僵直 | `on_parried` 只被近战调用；投射物走 `deflect`，天然不给僵直 |
| 弹刀僵直时长 | **按该招式伤害系数缩放**：`0.45 + 系数 × 4.5` 秒（系数 0.12 → 0.99s，0.20 → 1.35s） |
| 设计案「伤害 = 玩家最大生命百分比」 vs 现有「攻击力 × 系数」 | **换算成攻击力系数**：BOSS `attack_power = 100`，`damage_coeff` 直接等于百分比（0.12 = 12 伤害），并受玩家抗性减免 |
| 二阶段是否新增机制 | 用户 2026-10-20 追加：**二阶段获得「弹反玩家物理远程」**，见 §5；这不改变「不新增主动招式」的原则 |

## 1. 满势断岳的触发（2026-10-22 用户改定）

**旧刀势机制（0–100、每招 +20、60/80/100 概率抢跑、刀势条 HUD）已全部删除。**
`MOMENTUM_*` 常量、`momentum` 变量、`_try_force_peak()`、`_peak_release_chance()`、
HUD 的 `MomentumBar` / `MomentumLabel` 均已移除；`MoveDB` 里三个 `momentum_*` 字段也已删除。

当前唯一触发条件：

```
目标（仇恨目标）当前所在位置，距离任意一处刀痕 ≤ 该刀痕的判定半径（52）
```

- 实现在 `DomainBoss01._target_on_scar()`；判定用 `target` 而不是硬取玩家，
  这样召唤物拉到仇恨时刀客会按仇恨目标判断。
- 满势断岳**不再抢跑**，与其它招式一起走评分；能进候选时 `E` 分量 +5.0，
  玩家明显在侧向时 `R` +2.5。
- 仍然受自身法术冷却约束（一/二阶段均 24 秒）。
- 设计意图：博弈从「攒刀势」变成「**刀客把玩家逼进刀痕 / 玩家主动躲开刀痕**」。

## 2. 刀痕（**不是基础系统**）

> **定位**：刀痕只是众多功法流派中的一套自成体系的玩法组件，供玩家构筑 build。
> 它不是全局基础设施 —— **没有任何人使用带 `scar_effect` 的招式时，`ScarField` 根本不会被创建。**

- 创建：`ScarField.ensure()`（懒创建，挂到当前场景）
- 查询：`ScarField.get_active()`（不存在返回 null，调用方按 0 处理）
- 归属：`BladeScar.owner_side` 为 `boss` / `player`，**只伤害非归属方**
- 普通刀痕：**留存 10 秒**，期间不造成伤害，只占位限制走位
- 激活（2026-10-18 用户改定）：刀痕**当场化为一次瞬间斩击**，对覆盖范围内的敌人造成一次
  **法术伤害**，然后刀痕立即消失。旧的「强化刀痕持续灼烧 + 减速」机制已删除。
- 连携加成：**同一次激活的刀痕越多，本次斩击伤害系数越高，每多一个 +1** ——
  激活 1 个 → 系数 1；2 个 → 系数 2；N 个 → 系数 N。所以「先铺满刀痕再一次激活」是满伤手法。
  单道斩击伤害 = `damage_power × 本次激活数量`
- 上限：场上最多 4 道普通刀痕；超额时替换「剩余时间最短」的一处
- **BOSS 侧刀痕**（2026-10-22 用户调高）：伤害系数 **1.6**（`SCAR_BOSS_DAMAGE_COEFF`），
  判定 / 显示半径 **52**（原 1.0 / 34）。
- 美术：刀痕本体 `ArtDB.VISUALS["blade_scar"]`；斩击特效 `ArtDB.EFFECTS["scar_slash"]`

### 双方共用的联动字段（`MoveDB` 招式根字段）

| 字段 | 含义 |
|---|---|
| `scar_effect` | `create` / `ignite_path` / `ignite_area` / 空 |
| `scar_offset` | 留痕位置距施法者多远（破步突进斩 70 / 留痕斩 150） |
| `scar_ignite_max` | 本次最多激活几处（也直接决定斩击系数：激活 2 处 → 每道系数 2）。现值：刀气追击 2 / 封路刀域 4（吃满）/ 满势断岳 3 |

因此玩家学会刀客招式后，可以自己搭「留痕 → 刀气激活 → 封路」的连招，
和 BOSS 打同一套刀痕博弈 —— 但玩家的刀痕伤 BOSS，BOSS 的刀痕伤玩家。

## 3. 招式清单

### 物理（无 CD，可弹刀）

| id | 名称 | 形状 | 系数(BOSS) | 特点 |
|---|---|---|---|---|
| `form_blade_slash` | 横斩 | 扇形 150 / 110° | 0.12 | 基础招，前摇 0.85s |
| `form_blade_heavy` | 沉步竖斩 | 扇形 165 / 55° | 0.20 | 前摇 1.25s；命中挂「重伤」3 秒（无法闪避 + 移速 -50%，见 `DebuffDB`） |
| `form_blade_dash` | 破步突进斩 | 连续两段突进 + 扇形 130 / 90° | 0.16 | 每段位移 620 × 0.44s；**两段各自结算伤害并各留一道刀痕**；第二段重新取玩家方位；二阶段突进 +8% |
| `form_blade_turn` | 回身斩 | 扇形 115 / 140° | 0.14 | **仅侧向可用**（正面点积 < 0.35，距离 ≤210；原设计要求侧后方，实测几乎打不出，已放宽） |
| `form_blade_scar` | 留痕斩 | 扇形 220 / 70° | 0.12 | 中距离（120–330），攻击终点 150 处留刀痕；场上刀痕已满 4 道时不再进入候选 |

### 法术（独立 CD，不可弹）

| id | 名称 | 形状 | 系数 | CD（一/二阶段） | 联动 |
|---|---|---|---|---|---|
| `form_blade_qi` | 刀气追击 | 投射物 560 | 0.15 | 10 / 8.5 | 沿途激活最多 2 处刀痕 |
| `form_blade_field` | 封路刀域 | 圆形 210 | 0.06 | 16 / 16 | 范围激活最多 4 处刀痕（吃满）；场上无刀痕时不进入候选 |
| `form_blade_counter` | 纳势反击 | 扇形 210 / 140° | 0.18 | 20 / 17 | 玩家 2.0 秒内用过功法且距离 ≤260 才可用；BOSS 蓄力 3 秒后斩出 |
| `form_blade_peak` | 满势断岳 | 投射物 620（速度 760） | 0.24（二阶段 ×1.0833 ≈ 0.26） | 24 / 24 | **目标站在刀痕上**才可用；沿途激活最多 3 处刀痕；出手方向锁定 |

> 玩家侧用同一批形态，但系数是倍率（× 自己攻击力），消耗走灵力 / 精力 + 冷却。
> 「纳势反击」玩家侧是蓄力格挡（最多 5 秒、物理减伤 70%、按蓄力秒数与受击次数叠伤害），
> BOSS 侧固定蓄力 3 秒。

## 4. 决策评分

```
S = D（距离/方位） + B（玩家行为） + E（联动） + G（场地） − R（风险） − Q（重复）
```

- **可用性先于评分**：距离、方位、冷却、刀痕条件不满足直接不进候选集
- **重复惩罚**：同一招连续两次 −3，连续三次 −6
- **随机只用于打破平局**：`SCORE_JITTER = 0.6`
- `E` 分量现在**只服务满势断岳**（目标踩痕 +5.0）；刀势已删，其它招式没有 E 加成
- 关键候选条件：
  - `form_blade_slash` / `form_blade_heavy`：距离 ≤190
  - `form_blade_dash`：140 < 距离 ≤430；玩家超出 220（`NEAR_MELEE_REACH`）时权重 +4.8（330 以上再 +1.2）
  - `form_blade_turn`：玩家在**侧方**（前向点积 < 0.35），距离 ≤210
  - `form_blade_field`：场上至少 1 处普通刀痕
  - `form_blade_counter`：玩家 2.0 秒内用过功法，距离 ≤260
  - `form_blade_peak`：`_target_on_scar()` 为真

## 5. 二阶段专属：弹反玩家的物理远程（2026-10-20 / 10-21 用户定）

刀客转二阶段后获得「弹刀」能力（不是功法，玩家学不到）：

| 项 | 规则 |
|---|---|
| 触发对象 | 只弹**玩家的物理远程**（`from_projectile = true` 且 `damage_kind = physical`） |
| 不触发对象 | 玩家的近战 / 法术攻击永远不触发 |
| 效果 | 本次伤害完全作废，投射物**原样弹回玩家**（方向 = 刀客 → 玩家） |
| 反弹伤害 | 玩家原本打出的数值 × **0.3**（`PARRY_REFLECT_MULT`）—— 不直接 100% 反射，避免玩家被自己一发打死 |
| 表现 | 金色光芒迸发 + 小火花 + 身体金光 + 头顶「弹刀！」飘字 |
| 追击 | 获得一次追击资格：下一次**近战**招式出手前闪到目标身前（远程招式不消耗，继续等近战） |

实现：`BossBase.take_damage` → `try_parry_player_projectile()`；
`_consume_parry_chase()` 在近战起手前消费追击。二阶段切换本身仍然
不重置 CD、不清刀痕、不回血、不瞬移。

## 6. 塔层掉落（随机感悟）

刀客对应**万界塔第 2 层**。首杀按 `WorldDB.roll_floor_reward_skills()` 从刀客的 9 门功法中抽取
（先排除已学再掷）：

| 结果 | 概率 |
|---|---|
| 必得 1 门（随机） | 约 65% |
| 得 2 门（不重复） | 30% |
| 一次得剩余全部 9 门 | 5% |

实测 4000 次：1 门 65.2% / 2 门 29.7% / 全部 5.1%。
