# 肉鸽爬塔模式「试炼之路」设计案

> 状态：设计定稿待评审（2026-11-08）
> 定位：独立模式，与万界塔并列，入口在万界塔面板内。
> 铁律：**模式内的一切临时状态不写入永久存档**；退出 / 死亡即还原，只结算锻造晶石与解锁进度。

---

## 一、模式定位与边界

| 项 | 决定 |
|---|---|
| 名称 | 试炼之路（万界塔内的另一条分支） |
| 入口 | 万界塔面板新增分页「试炼之路」，与「塔层」并列 |
| 玩家起点 | `CharacterData.BASE_ATTRIBUTE_DEFAULTS`（练气裸装：力 10 / 法强 10 / 双抗 10 / 血 100 / 灵力 50 / 精力 5），**不带任何装备、法宝、已学功法**；`realm_exp` 也归零（否则面板会把真实档的几万修为显示成「已满」，突破按钮亮着） |
| 局内成长 | 只来自「功法 + 增益 + 肉鸽专属法宝」，不产出主模式装备 |
| 死亡 | 每局 **1 次复活**；第二次死亡即结算回主城 |
| 主动退出 | ESC 弹确认框「退出将按当前层数结算」；确认后按到达层数结算 |
| 中途关游戏 | 不存档，按当前层数结算（下次进入是新的一局） |
| 战场美术 | 整局固定「无尽试炼台」`ArtDB.VISUALS.bg_rogue_trial`，**不跟着本层抽到的 BOSS 换战场**（模式隔离靠 `RogueRun.active` 一处覆盖） |
| 隔离实现 | 本局状态全部放在 `RogueRun`（autoload 或静态单例），只挂 `CharacterData.set_attribute_mod("rogue_*", …)`；退出时 `clear_attribute_mods("rogue_*")` + 还原功法/装备/法宝槽/修为快照 |
| 局内禁用（2026-11-08 补） | 本局进行中置 `CharacterData.rogue_lock = true`：① Tab 角色/背包面板打不开（按 Tab 给一句居中提示，不静默吞键）；② `equip_from_inventory` / `unequip_to_inventory` / 卸法宝全部拒绝；③ `break_stage` / `break_realm` / `perform_huashen_breakthrough` 全部拒绝；④ G 战斗轮盘关闭（轮盘只会去扣主模式背包里的丹药符箓）。出局 `restore()` 撤锁 |
| 前置解锁（2026-11-08 用户定） | **通关万界秘境·凡界的虎妖后才开放「踏入试炼」**；老档已有肉鸽进度直接放行（见 §9.0） |
| 主模式产出 | 锻造晶石 `mat_duanzaojingshi`（按到达层数结算，死亡 / 退出都给） |

**为什么入口放万界塔面板**：塔本身就是「一层一只 BOSS」的挑战集合，试炼之路是它的无限延伸；放这里不需要新做一张主城门的贴图，也不会让主城设施列表变成 10 个。

## 二、局内流程

### 2.1 一层 = 3 小关 + 1 BOSS 关

```
第 N 层
 ├─ 小关 1：3 波小怪（逐次加压） → 三选一
 ├─ 小关 2：3 波小怪（逐次加压） → 三选一
 ├─ 小关 3：3 波小怪（第 3 波含 1 只精英） → 三选一
 └─ BOSS 关：12 只 BOSS 随机 1 只 → 三选一（必出稀有） → 进入第 N+1 层
```

- 每层 **4 次三选一**；一层 5~6 分钟（3 小关各 75~90 秒 + BOSS 45~60 秒 + 选卡 30 秒）。
- 小怪波次在**同一战斗场景内推进**，不切场景；波次清空后原地刷下一波，玩家有 2 秒喘息。
- 选卡界面**暂停战斗**（`get_tree().paused = true`），选完恢复。
- 无限层，没有终点；层数即成绩。

### 2.2 BOSS 抽取规则

- 12 只 BOSS 洗牌成一个队列，按层抽队首，**抽完前不重复**；队列空则重新洗牌。
- 每 4 层（第 4、8、12… 层）优先从队列中取**元婴档**（`boss_04 / boss_04_b / boss_04_c`）；若队列里元婴已被抽走，顺延取队首。
- 第 1 层固定 `boss_huyao`（虎妖）作为教学 BOSS。

### 2.3 死亡与复活

- 第一次死亡：原地复活，满血、满灵力、满精力，清空场上所有敌方投射物与地面危害，给 3 秒无敌；**BOSS 血量保留当前值**（不重置）。
- 第二次死亡：结算回主城。
- 复活不消耗任何资源，每局只有一次。

## 三、数值基线

### 3.1 玩家

开局即 `BASE_ATTRIBUTE_DEFAULTS`：血 100 / 力 10 / 法强 10 / 双抗 10 / 灵力 50 / 精力 5。
普攻三段系数 1.0 / 1.0 / 1.4，即开局普攻约 **10 / 10 / 14** 伤害。

> 不额外给"肉鸽专用武器"。玩家的伤害成长全部来自增益里的「力量 / 法强 / 攻击力% / 招式强化」。

### 3.2 小怪（2026-11-08 平衡后）

**第 1 层是教学层**：下表仍是「基准值」，实际生成还要乘按层缓冲：

```
实际 HP  = 基准 HP  × 1.30^(层-1) × FLOOR_HP_RELIEF[层]
实际 ATK = 基准 ATK × 1.12^(层-1) × FLOOR_ATK_RELIEF[层]
```

| id | 名称 | 基准血 | 基准攻 | 移速 | 体型 | 攻击方式 |
|---|---|---|---|---|---|---|
| `rogue_rat` | 噬灵鼠 | 80 | 8 | 150 | 小 | 扑咬：前摇 0.35，扇形 70°，0.9× |
| `rogue_archer` | 山魈射手 | 60 | 6 | 90 | 中 | 射石：前摇 0.55，直线 420，0.8×；被贴近时后跳 120 |
| `rogue_golem` | 石傀 | 160 | 12 | 60 | 大 | 砸地：前摇 0.9，圆形，1.3× |
| `rogue_elite` | 赤目虎魈（精英） | 420 | 16 | 110 | 大 | 扑咬（扇形 110°，1.1×） |

| 层 | HP 缓冲 | ATK 缓冲 | 每波怪数 | 怪种 | 精英 |
|---|---|---|---|---|---|
| 1 | 0.60 | 0.45 | 1 / 2 / 2（共 **15** 只） | 鼠 / 射手 | ❌ |
| 2 | 0.80 | 0.62 | 2 / 2 / 2（共 18 只） | 鼠 / 射手 | ❌ |
| 3 | 0.92 | 0.82 | 2 / 2 / 3（共 21 只） | 鼠 / 射手 | ✅ 第 3 小关第 3 波 |
| 4+ | 1.00 | 1.00 | 2 / 3 / 3（共 24 只） | + 石傀 | ✅ |

- ⚠ **三条渐进解锁故意错开层**：怪数增加 / 缓冲回升 / 精英·石傀解锁若压在同一层，
  第 1→3 层会出现 **3.16× / 2.54×** 的血量断崖（`probe_rogue_balance` 首轮实测）。
- ⚠ 缓冲乘在成长曲线**外面**，第 4 层起全为 1.0，`pow()` 原样保留 → 后期曲线一分没动。
- 小怪攻击成长从 ×1.18 降到 **×1.12**：裸装玩家只有 100 血，攻击膨胀比血量膨胀更致命。
- 设计意图：每波 20~25 秒清完；小怪不是血牛，作用是打断节奏、逼走位。

### 3.2.1 关间补给（2026-11-08 新增）

- 每清**一小关**（三选一前）回 `STAGE_HEAL_PCT = 20%` 最大血；进 **BOSS 关**再回
  `BOSS_STAGE_HEAL_PCT = 30%`。一层共可回 90 点。
- 走 `player.rogue_heal_pct()`（自带 `RogueRun.active` 门禁 + `is_dead` 检查 + HUD 刷新），
  🚫 别自己写 `hp +=`。
- ⚠ 起因：原来一层 9 波**零回血**，裸装 100 血必然撑不到 BOSS（用户报
  「还没碰到第 1 层 BOSS 就死了」）。第 1 层实测承伤 48.8 / 补给 49 → **满血见 BOSS**。

### 3.2.2 局内回血丹（2026-11-08）

- 击杀小怪有 `MINION_HEAL_DROP_CHANCE = 18%` 概率掉一颗「试炼回血丹」，落在怪死亡位置；
  地上同时最多 `MAX_GROUND_HEAL_PILLS = 5` 颗，避免一路不捡越堆越多。
- 走近按 **F 拾取即回血**（`HEAL_PILL_PCT = 15%` 最大血）。沿用主模式 `item_pickup.tscn`
  的光柱 / 图标 / F 提示表现，**不新增键位、不做局内背包容器**。
- ⚠ **「无法带出局外」的三层保障**：
  ① 它是「局内虚拟物品」：`id = rogue_heal_pill`、`type = rogue_consumable`
  都不在 `ItemDB` 主表里，`CharacterData.mark_codex_from_item()` 直接早退 → 不写图鉴；
  ② `item_pickup.pickup_handler` 指向 `RogueArena._on_heal_pill_picked()`，直接调
  `player.rogue_heal_pct()`，**不走 `CharacterData.add_item()`** → 不进背包、不落存档；
  ③ 只在 `RogueRun.active` 下生成，切场景 / 结算时掉落物随场景销毁。
- BOSS 掉落仍整体屏蔽（`combat_arena._spawn_drops` 对 SOURCE_ROGUE 返回空），
  试炼唯一带出主模式的东西仍是结算锻造晶石。
- **2026-11-08 二次优化（用户定「要小巧」）**：旧版复用主模式 256² 回春丹大玉盘图标 +
  装备级 96×232 光柱，一颗回血丹看着像大盘子。现在
  - 专属贴图 `assets/ui/icon/rogue_heal_pill.png`：128² 透明底、主体只占 ~42% 的小玉青丹丸
    （柔光外圈 / 暖金描边 / 两道柔和丹纹 / 朱砂丹心 / 左上高光），程序化生成；
  - `ArtDB.ROGUE_HEAL_PICKUP_STYLE` 一套专属小尺寸参数：图标 62→**30px**、光柱 96×232→**38×88**、
    光晕 150×50→58×20、阴影收小、去掉躺地厚度叠层、F 提示字号 13→11、拾取飞起 28→16；
  - ⚠ 通过 `item["pickup_style"]` / `item["pickup_tint"]` **按掉落物覆盖** `ArtDB.get_pickup_beam()`，
    `item_pickup.gd` 把合并后的参数存进 `_cfg`，拾取特效也共用同一份。
    **没带 style 的主模式掉落物 100% 走全局表，一行都没动**（探针断言全局 `icon_longest` 仍 62）。
- **2026-11-08 三次修复（用户报「捡不了回血丹」）**：功能其实全通，但玩家按 F **完全没反应**。
  ⚠ 根因在 `combat_arena._unhandled_input()`：试炼之路分支
  `if current_source() == SOURCE_ROGUE: ... return` 末尾的 `return` 吞掉了所有其它键，
  而 F 的处理写在下面的**主模式** `if/elif` 链里 → 试炼里永远走不到。
  - 把 F（全模式通用、无副作用的键）**前置到所有模式分支之前**统一放行并 `return`，
    删掉主模式链里的 `elif KEY_F`。以后新增模式分支也不会再吞掉它。
  - ⚠ 探针原来直接调 `arena._try_pickup_nearest()`，**绕过了整个输入分发**，所以 25/0 全绿却漏测。
    现在改用 `Input.parse_input_event(KEY_F)` 走真实键盘事件，并额外断言
    「当前确实在会吞键的 rogue 分支」；另加**反向锁**：切到 `SOURCE_ARENA` 再按一次 F，
    验前置放行没弄坏主模式拾取。做过变异测试（把修复撤掉 → 探针红 3 条）。
  - `item_pickup.has_player_inside()` 加实时重叠兜底：掉落物若正好生成在玩家脚下，
    入树那刻的 overlap 可能没转成 `body_entered`，会「站在丹上按 F 也没反应 / 提示不亮」。
  - 回血丹判定圈单独放宽到 `HEAL_PILL_PICKUP_RADIUS = 56`（全局 42）。
    ⚠ `CircleShape2D` 是场景共享 SubResource，必须 `duplicate()` 后再改 radius，
    否则会把主模式所有掉落物的判定圈一起改掉（探针断言主模式仍是 42）。
  - 带 `pickup_handler` 的局内掉落物不再弹「获得 X」toast（它不进背包，说「获得」会误导），
    只由 handler 自己播「回血丹 · 气血 +15」。主模式掉落物文案不变。
- **替换口**：`RogueDB.HEAL_PILL_ICON`（换图只改这一行，缺图自动回退品阶色块）；
  落地尺寸 / 光柱 / 阴影 / F 提示 / 拾取动画参数全在 `ArtDB.ROGUE_HEAL_PICKUP_STYLE`。
- 验收：`tools/probe_rogue_heal_pill`（**30 项**，走真实键盘事件「生成 → 走进范围 → 按 F → 回血」，
  另验小巧参数、判定圈、主模式全局表与 Shape 资源未被污染、主模式 F 仍可用）
  + `tools/shot_rogue_heal_pill.tscn` → `output/rogue_heal_pill.png`（掉落物）与
  `output/rogue_heal_pill_picked.png`（按 F 后血量 50→65 + 回血公告）。

### 3.3 BOSS

**基准血量 500，每层 ×1.35**；按原 BOSS 档位乘系数：

| 档位 | BOSS | 系数 |
|---|---|---|
| 凡界 | `boss_huyao` / `boss_01` / `boss_01_c` | 1.00 |
| 筑基 | `boss_02` / `boss_02_b` / `boss_02_c` | 1.15 |
| 结丹 | `boss_03` / `boss_03_b` / `boss_03_c` | 1.30 |
| 元婴 | `boss_04` / `boss_04_b` / `boss_04_c` | 1.45 |

- 第 N 层 BOSS 血 = `500 × 1.35^(N-1) × 档位系数`。例：第 1 层 500、第 4 层（元婴）1785、第 8 层（元婴）5923、第 12 层 19647。
- 攻击力基准 12，每层 ×1.15，档位系数同上。
- **首层 BOSS 教学缓冲**（`FLOOR_BOSS_RELIEF = [0.75, 0.90, 1.0, 1.0]`）：第 1 层血/攻 ×0.75、
  第 2 层 ×0.90、第 3 层起 1.0。例：第 1 层虎妖血 375（原 500）。
  满血走到 BOSS 却被两下拍死，教学层就白做了。
- **保留原 BOSS 的全部招式、阶段、骨骼动画**，只替换血量 / 攻击 / 防御三组数值；招式前摇与判定一律不动（否则等于重做 12 只 BOSS）。
- ⚠ **BOSS 尸体不销毁、仍留在 `boss` 组**（`_set_boss_dormant()` 只关 `visible` / `process_mode`，
  下一层 BOSS 关才重新实例化）。玩家侧所有按组取敌的循环必须过滤 `BossBase.is_unit_dead()`，
  否则打完 BOSS 后**完美弹刀的追击位移 / 攻击软锁定会锁到那具隐形尸体**
  （2026-11-08 用户报「完美弹刀会索敌死的 boss」）。
  已在 `player.gd` 的 13 处 `get_nodes_in_group("boss")` 循环统一加过滤；
  统一入口 `BossBase.hostile_units()` 本来就带 `is_unit_dead`，新代码优先走它。
  验收 `probe_rogue_dead_boss_target`（11 项，含变异测试）。

### 3.4 难度曲线与目标

- 玩家每次选卡约 **+7% 复合战力**；一层 4 次 ≈ ×1.31。
- 敌人每层小怪血 ×1.30 / 攻 ×1.12、BOSS ×1.35；玩家约 ×1.31。
  ⚠ 攻速成长单独压低，是因为承伤 ≈ 敌方攻 × 敌方血 / 玩家 DPS，攻击膨胀是平方级的。
- 目标：普通玩家 6~8 层，熟练玩家 12~15 层，极限 20 层以上。
- **2026-11-08 已实测回调**：`tools/probe_rogue_balance.gd` 从真实表跑 1~10 层，
  打印「怪数 / 敌方总 HP / 玩家 DPS / 清层耗时 / 承伤 / 补给 / 净伤」表，
  断言第 1 层净伤 < 70、1→4 层渐进（1.15~2.05×）、4~10 层平稳（0.75~1.40×）、
  第 4 层起缓冲归 1.0，并**起真实战斗场景**验「表登记了 ≠ 运行时读到」+ 清关真的回血。

### 3.5 局内成长：BOSS 装备 + 修为突破（2026-11-08 用户定）

> **与「局内禁用背包 / 突破」不冲突**：之前禁的是**碰局外档**，本节做的是
> **局内独立一套**。局外角色面板仍锁（`CharacterPanel` 的 `RogueRun.active` 分支 +
> `CharacterData.rogue_lock` 数据层保险），Tab 改为打开 `RogueGearPanel`。

#### 装备

- 击败 BOSS **必掉「该 BOSS 的装备之一」**：`RogueDB.roll_boss_gear(boss_id)` 从
  `ItemDB.DROP_TEMPLATES[boss_id]` 的装备条目里等概率取一件（虎妖 = 虎皮袍 / 虎牙项链，
  刀客 = 弯刀）；占位 BOSS 没登记装备时从全部装备模板兜底。
- **落地掉落**（2026-11-09 用户定）：BOSS 死后装备落在地上（`item_pickup`，光柱 + 装备图标 +
  「F 拾取」），玩家自己走过去捡；**捡完最后一件后才弹三选一**（三选一会暂停树，落地就先弹
  会永远捡不了）。兜底：10 秒没捡完自动收进行囊再开面板，防卡关。
  - 地面那份是**显示副本**（`type = "rogue_gear_drop"` + `_rogue_real_type`），
    `mark_codex_from_item()` 才会早退；入包时由 `_grant_gear_to_bag()` 还原真 type。
  - 必须登记进 `combat_arena._drops_on_ground`，否则「看得见、按 F 捡不到」。
  - 显示参数走 `ArtDB.ROGUE_GEAR_PICKUP_STYLE`（装备原画留白大，全局 62px 摊到地上只有 ~28px）。
- 玩家在 **Tab 试炼行囊** 里自己点装备穿戴 / 点已穿戴卸下，同槽自动替换、旧件回行囊。
  行囊卡片是**图标 + 名称 + 词条**（`UIKit.equip_icon(..., trim = true)` 裁掉原画留白），不再是一行字。
- **遗物到手提示**（2026-11-11 用户加）：捡到遗物时，除了玩家头顶 1 秒飘字，屏幕**底部中央、
  技能栏上方**再挂一条 420×56 的可点提示卡 —— 第一行「◆ 获得遗物 · XX」，第二行
  「按 Tab 打开试炼行囊，点一下即可穿戴 · 也可点这里直接打开」。
  - 整条 `MouseFilter.STOP` + `accept_event()`：点一下直接 `CharacterPanel.open_panel()`
    （试炼里自动转到 `RogueGearPanel`）；不消费事件的话左键同时绑着攻击，点提示会顺带挥一刀。
  - 停留 `GEAR_HINT_SECONDS = 12` 秒，用 `_process` 真实时钟递减 —— 三选一暂停树时不计时，
    选完卡回来还看得到。点开行囊 / 超时自动收。

## 五、12 套技能组 × 3 条流派

> 每套 3 条流派，共 **36 条**。每条流派给 5 条代表性增益（普通/稀有/传说混排），实际卡池按此扩到 15 条左右。

### 5.2.1「本局流派」—— 开局三选一（2026-11-08 补）

原设计里 §4.2 / §9.2 写的是「卡池 = 通用 + 已解锁流派」，但开局功法只有剑修一套，
于是刀修卡进池就是**死卡**（局内没有刀痕招式可加强）。落地时改成：

- 入口页（万界塔 → 试炼之路）新增「开局流派」选择，当前开放 **剑修 / 刀修 / 虎妖**。
- 开局功法按所选流派给：`RogueDB.FAMILY_START`（剑修 4 式 + 被动；刀修 4 式、无被动；虎妖 4 式、无被动）。
- 卡池 = **通用 + 本局流派**（`RogueRun.active_families()`），不再按「已解锁」全开。
- 想做成跨流派混搭，得先有「局内学功法」的卡；在那之前全开只会污染三选一。

### 5.13 后九套落地口径（2026-11-08）

**结论：12 套全部可玩。** 每套 = 起始四式 +（多数带）流派被动 + 专属卡池 15 张；
入口按 `FAMILY_UNLOCK_FLOOR` 分层解锁（历史最高层达标即开），未解锁的按钮压暗 + 提示「第 N 层解锁」。

**兽潮流为什么不做召唤物。** 原案写「新增 `RogueBeast` 轻量召唤物（同队实体）」，但玩家侧同队实体
要过一整串边界：`is_ally` 必须在 `add_child` 之前设（层 16）、`BossBase.hostile_units()` 的队伍号判定、
棋局里我方棋子 `is_ally=false` / `faction="boss"` 的老坑…… 一个上限 8 层的小跟班不值得碰这些。
改成**虎煞层数**：击杀 → 层数 → 伤害 / 攻速乘区，满层再翻倍；HUD 顶栏读「◆ 虎煞 N/M」，满层转色。
