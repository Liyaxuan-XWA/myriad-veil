# 赤霄界第二位 BOSS · 赤霄火正「离照」设计案

> 2026-10-29 · 每日 BOSS · 万界塔第 8 层 · 结丹档第二位
> 机制定稿：**逐日·天火**（天火种争夺）

---

## 一、头脑风暴与取舍

赤霄界第一位的赫连霄是「雷部判官」，机制是判词·天律（行为律法）。
第二位必须换一套驱动力，不能再用「攒层 → 放大招」（剑意/雷势）、「留痕 → 引爆」（刀痕）、
「布点 → 连线」（五旗阵）、「环身 → 花环」（气环）或「行为禁令」（判词）。

| 提案 | 核心 | 优点 | 问题 | 结论 |
|---|---|---|---|---|
| **逐日·天火** | 场上一枚可被双方抢、拿、扔、炸的天火种 | 持有权是全新的争夺维度；八式全能围绕它；双方对称继承 | AI 与 HUD 需要新对象 | **采用** |
| 炉温·过热 | 火系招式涨炉温，满温进入过载 | 资源曲线直观 | 仍是「攒资源→爆发」，和剑意/雷势同构 | 否 |
| 赤日·阴影 | 日轮移动，光下受伤、影里安全 | 画面强 | 近战输出被光影逼死；玩家侧继承生硬 | 否 |
| 锻兵·器魂 | BOSS 现场锻出不同兵器换招 | 招式形态多 | 等于做三套 BOSS；玩家侧无法完整继承 | 否 |
| 香火·愿力 | 场上香炉提供愿力，打灭香炉削弱 | 有场景互动 | 与五旗阵的「打掉物件削弱 BOSS」重复 | 否 |
| 火候·连击 | 按节奏命中才吃满伤害 | 操作上限高 | 难读、难教，且与现有连击手感冲突 | 否 |

**取舍理由**：逐日·天火把「伤害资源」和「站位资源」合并成一枚实体。
玩家不是等 CD，而是决定「现在抢不抢、抢到后什么时候扔、被抢后怎么夺回来」。
BOSS 也必须为这枚火种改变行为（抢、夺、炸、守），而不是按距离随机出招。

## 二、形象与位面风格

- 位面：赤霄界（雷出于地，火生于天）。赫连霄代表「雷出于地」，离照代表「火生于天」。
- 身份：**赤霄火正**——掌天火、司日冕的天官。
- 名字：**离照**（离为火，照为日）。
- 称号：**盗火的天官**。
- 外形：清瘦、无重甲；赤黑层叠祭袍、单边金乌面具、赤金长绦；
  右手持一柄**巨大的日轮扇**（圆形扇面，扇骨如日芒），左手收在胸前。
  与赫连霄的重甲、铁笔、雷鼓、肩甲彻底区分。
- 舞台：**焚天祭坛**——焦红金裂的石坪，中央一圈日轮刻痕，四周残旗与余烬。
- 卡片镜头：低机位 3/4，日轮扇横扫前景，背后一轮被啃掉一角的赤日，火星逆飞。

## 三、机制：逐日·天火

### 3.1 生成（天火种）

- 战斗开始 3 秒后，祭坛中央偏随机位置落下第一枚 **天火种**；之后每次被消耗/爆裂，
  8 秒后在新的随机位置重生（二阶段 6 秒）。
- 火种落地时有一圈日轮预警，0.6 秒内不可拾取；之后双方走近 46 像素内自动拾取。
- 玩家学会任意一门逐日功法后，**日轮**会在没有火种时于阵心凝出一枚（仅玩家侧）；
  这样玩家在其他 BOSS 战里也能完整使用这套机制。

### 3.2 成长（日冕）

- 持种者每 1.6 秒叠 1 层 **日冕**，最多 3 层。
- 每层：力量 / 法强 +8%（玩家走 `CharacterData.attribute_mods`；BOSS 直接乘招式伤害）。
- BOSS 持种时额外获得 **15% 减伤**；这是「不能放着不管」的硬理由。

### 3.3 消亡（烈阳 · 灼心）

- 3 层后进入 **烈阳**：持种者开始 **灼心**（火焰持续伤害）。
- 进入烈阳 3 秒后火种不稳定爆裂：玩家受 12% 最大气血火伤；BOSS 受 6% 最大气血火伤。
- 玩家可以用 **投日**（扔出去）或 **日蚀**（引爆）主动结束；BOSS 会在 3 层后优先投日/日蚀。

### 3.4 变化（夺火）

- 火种可被抢夺，层数随火种一起转移：
  - **逐日步**撞到持种者 / **牵日**拉种 / **焚风**掀种 → 火种易主或落地。
  - 玩家从 BOSS 手里夺火 → BOSS 立刻失去 15% 减伤和日冕加伤。
  - BOSS 从玩家手里夺火 → 玩家失去日冕，并被挂上灼心。
- 火种被投出后落在目标点，0.4 秒后重新可抢；被日蚀引爆后消失并进入重生计时。

### 3.5 联系（八式联动）

| 招式 | 对火种的作用 | 形态 |
|---|---|---|
| 逐日步 | 突进到火种/持种者身边，抢种 | 位移 + 圆形落点 |
| 日冕斩 | 持种时伤害与灼心强化 | 近身扇形 |
| 投日 | 把火种扔向目标，火伤 + 灼心，火种落地 | 投射物 |
| 牵日 | 把火种从远处拉回自己 | 直线牵引 |
| 焚风 | 把对手吹离火种 / 把火种掀落 | 扇形击退 |
| 日蚀 | 在火种处引爆，逼对方松手 | 延迟圆 |
| 日轮 | 日轮阵：持续伤害并把火种往阵心拉；无种时凝种 | 地面持续圆 |
| 天火坠 | 二阶段：火种所在处落下天火 | 大范围延迟圆 |

**弱点**：BOSS 在逐日步 / 牵日的收招里有 0.7 秒硬直，受到伤害 +15%；
玩家可以故意让它抢到火种，再在它投日/日蚀的起手时打断或夺火。
**不能逃课**：放着火种不管，BOSS 拿种后 15% 减伤 + 每层 8% 加伤，
且二阶段天火坠会追着火种落；拖得越久越难打。

## 五、行为树

0. **抢种优先**：火种自由 + 逐日步/牵日就绪 → 抢种（逐日步优先近，牵日优先远）。
1. **玩家持种**：日蚀就绪 → 在玩家脚下引爆；否则逐日步夺火 / 焚风掀种 / 投日逼松手。
2. **BOSS 持种**：日冕 ≥2 层 → 投日/日蚀兑现；贴身 → 日冕斩；拉开 → 日轮。
3. **无种/重生期**：按距离使用日冕斩（近）/焚风（中）/日轮（远），并保留位移。
4. **二阶段**：天火坠加入常规权重；火种重生 6 秒；日冕斩附带灼心。
5. 连携：逐日步→日冕斩 +1.6；牵日→投日 +1.5；焚风→日蚀 +1.2；
   同招二连降权、三连封禁；0.3 秒决策节流；打不到不出招。

**应对弱点**：
- 贴脸 → 焚风击退 + 日冕斩；拉远 → 牵日/投日/天火坠。
- 一直抢种 → BOSS 的日蚀会逼你松手；一直不抢 → 它拿减伤和加伤。
- 抢到 3 层不扔 → 灼心 + 3 秒后爆裂，必须投日/日蚀或让 BOSS 夺走。

## 六、数值反推（结丹中期标准档）

- 玩家标准档（结丹中期 · 灵器 +8，探针实测）：308 气血 / 107.3 物攻 / 72.3 法攻 /
  物抗 37.3（27.1%）/ 法抗 46.3（31.6%）；普攻三段一轮 0.99 秒，2.5 刀/秒 339.6 DPS，
  满速 413.7 DPS。
- 目标 TTK 60~80 秒（有效输出 60~75%）→ BOSS 基础血量 **15,500**：
  标准档约 61~76 秒；持种 15% 减伤把「放着不管」的等效血量抬到约 18,200，逼玩家夺火。
- BOSS 攻击 **96**：主招过抗后 36~118，结丹中期 3~5 下大招收命；
  二阶段 ×1.25，天火坠单发约 148（48% 气血，有 1.1s 前摇 + 0.55s 落点预警）。
- 火种爆裂：玩家 12% 最大气血 / BOSS 6% 最大气血；
  灼心 DoT 每秒 6 点、持续 4 秒（可被投日/日蚀提前结束）。
- 塔 11 次起血量 ×2 → 31,000；结丹后期 500 DPS 下约 60~85 秒。

## 八、美术与特效语言

- 统一语言：**日轮 / 金乌**——柔和金色日核 + 赤红日冕 + 逆飞余烬；
  地面印记是「缺一角的日轮」；不用雷弧、阵线、气环、刀光的形状与配色。
- 八式特效区分：
  - 逐日步：一道贴地金色残影 + 落点日轮印；
  - 日冕斩：扇面内三层层叠的日冕弧，持种时多一圈金边；
  - 投日：拖着长尾的小太阳，落地炸成放射状日冕；
  - 牵日：一串由大到小的日核被拉回，带金色丝线；
  - 焚风：扇面上逆飞的余烬与热浪，不画硬边风刃；
  - 日蚀：先出现被啃掉一角的黑日，再炸出金环；
  - 日轮：旋转的日轮阵，八道柔光扇骨；
  - 天火坠：天上落下的日核 + 长尾，落地压出一圈焦金裂痕。
- 角色：赛璐璐；地面/图标/机制道具：写实档。
- 卡面：低机位 3/4，日轮扇横扫，背后赤日有缺口；与赫连霄的正面雷云卡构图区分。
