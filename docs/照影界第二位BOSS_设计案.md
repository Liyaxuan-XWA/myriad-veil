# 照影界 · 第二位 BOSS「执烛」设计案（2026-11-02）

选定方案 A（见 `docs/照影界第二位BOSS_方案提案.md`）。照影界第 2 位 = `boss_04_b` = **万界塔第 11 层**（塔层由 `WorldDB.DOMAINS` 自动生成，追加即成层）。

## 位面与视觉

- 照影界（`domain_04`），境界要求元婴，「镜水无波，万象皆有其影」。第一位观澜管**镜**（复制），第二位执烛管**影**（投射）。
- 视觉：一盏高位灯（界灯）把光压成一片冷银圆盘；全场只有一处光源，其余皆暗。执烛提一盏空灯 —— 它的影子比它自己先动手。

## 机制：投影 · 身外之影

**核心几何（唯一规则，全场通用）**

- 场上有且只有一盏**界灯**（光源，位于战场偏北处）。
- 任何单位都有一条**影身**：从该单位脚下沿 `单位位置 − 光源位置` 方向向外延伸的一条地面判定带；
  `影长 = 40 + 该单位到光源的距离 × 1.15`，上限 620。光源正下方 ≈ 40（只剩脚边一截短刃），贴场边 ≈ 620。
- **执烛的招式全部由影身交付**，本体只负责走位与一记近身扇形。影身永远在地上可见（墨黑柔边一条），所以它的射程不需要额外预警 —— 读数就是影子的长度和指向。
- **没有势条、没有资源条、不攒层、不引爆**；机制的状态用「灯亮/灯暗、影长/影短、影子属于谁」三个动作可见量表达。

**空手可破（首战不需要本关任何功法）**

| 玩家手段 | 怎么用 |
|---|---|
| 走位 | 站到「灯—执烛」连线靠灯一侧，影身就甩到你身后打空；把它逼到灯下，影长塌到 40，它的远程招直接哑火 |
| 弹反 | 影身招式（削影/投晷/踏灯/分影/长夜）都是**物理**，可弹反；弹反成功 → 影子折回斩在它本体上（反噬 0.9× 本体攻击） |
| 闪避 | 术法招（照骨）不可弹反，只能离开影身那条走廊 |
| 通用属性 | 任意功法都能打它本体；影身不是实体，不能被打、不能被挡，只有位置有意义 |

**反逃课（它的应对行为）**

- 你贴到灯侧、影身打不到你 → 它用**踏灯**掠到灯的另一侧重新拉出影身（真的位移，落点在灯的反面）。
- 你压到它脚边 → **明灭**压暗界灯：影身缩短，但本体攻速 +30%、本体招式伤害 ×1.35，暗场期间它只剩近身也够痛。
- 你缩在灯背后不出头 → **照骨**是本体直接朝你打的水属性光束，与影长无关，站桩躲不过。
- 灯不在场边时它不会硬凑：选招阶段按**真实影身走廊**校验能不能命中（不许空放）。

**二阶段专属机制层：夺灯 · 反照（P2 才存在的规则）**

半血转阶段（1.0 秒无敌 + 推开玩家）后，它把界灯**提在自己手里**：

1. 光源 = 执烛本体 → **它不再有影子**，P1 那套「站到灯与它之间」的解法当场作废；
2. **玩家脚下长出影身**（方向 = 玩家 − 执烛，长度随玩家与它的距离）；
3. 它的影系招式改为在**玩家的影身**上结算 —— 投晷打你的影尖，缚影抓你的影身，照骨沿你的影身加宽；
4. 于是你的退路被自己的影子占住：**越往它身上贴，你的影越短、越安全；越往后退，影越长、越被追着打**。P2 的近身压力由这条规则自然产生，不靠数值 ×1.25。

P2 数值补贴：伤害 ×1.5（沿用 2026-10-31 定的口径），前摇 ×0.85~0.9。

## 数值（按元婴后期实机面板反推）

方法论：战斗平衡用「TTK 反推」—— 先定目标击杀时长，再用实测玩家 DPS 换算血量。

- 实测基线：玩家 657 气血 / 184 物攻 / 414 法攻 / 法技增伤 ×2.965 / 普攻间隔 0.350s；观澜 40,000 血 + 法抗 100 时自动挂机 **63.4s**（前期+6 为 60.8s）。
- 观澜有效承伤速率 = 40000 / 63.4 = **631 DPS**；减免公式 `r/(r+100)`，法抗 100 → 减半。设该自动循环法术伤害占比 0.6，则**无抗目标承伤速率 ≈ 631 / (1 − 0.5×0.6) = 901 DPS**。
- 本只取**物理抗 20（减 16.7%）、法抗 0**（与观澜的「法术门禁」反向，奖励另一类build）：有效 ≈ 901 × (1 − 0.167×0.4) = **841 DPS**。
- 目标 TTK = 观澜 +13%（同位面递进）≈ **72 秒** → 血量 **56,000**（首档，实机 live 面板探针复测后收敛到 68~78s 区间）。
- 攻击 205；单下结算（玩家物抗约 34%）：削影 1.05→142（22% 血）、投晷 1.15→156、缚影 0.8→119 + 定身、踏灯 0.9→131、照骨 0.85→128、分影 0.7→105 × 5 段、长夜 1.30×P2 1.5→**264（40% 血）**。最快 4~5 下才致死，最长前摇的终局招单独一次不到半血。
- 移速 112 / 132；前摇 0.80 / 0.62；收招 0.55 / 0.44；僵直 1.0。
- 冷却（P1 / P2）：削影 5.5/4.5、投晷 7.5/6.0、缚影 12/10、踏灯 9/7.5、明灭 16/13、照骨 8/6.5、分影 22/18、长夜 34/30。
- 塔层成长与双倍血沿用现有口径（通关次数血量递增、第 11 次起双倍血）。

## 玩家侧继承

灯笼**跟在玩家身后**（拖尾弹簧，落后约 240px），因此**玩家的影身永远指向你面朝的方向**：

- 你在跑动 / 刚突进完 → 灯被甩在后面 → 影长暴涨 → 影系招式射程拉长；
- 你停下 → 灯追上 → 影身塌回脚边 → 只剩基础判定。

于是「影长 = 你与光源的距离」这一条规则，在 BOSS 那边是**空间博弈**（绕灯），在玩家这边是**移动表达**（跑位换射程）；双方读的是同一条地上的黑刃，任何战场都成立，不依赖照影界的界灯，也不读任何 BOSS 私有状态。

## 影族特效去硬边（2026-11-04 用户报「有些技能特效还没制作，现在还是硬边色块」）

**根因两条，都不在"没做"上，而在两个具体数值上：**

1. `_stretch_bar()` 用的是 `white_texture()` —— 一张 **4×4 纯白图**，拉成任意宽高就是四条硬边。
   影族八式里有 **8 处**在用它（削影/投晷/踏灯/分影/长夜各一根冷银描边，照骨三层全用它）。
   照骨那条最明显：三层硬边矩形一叠，就是用户说的"色块"。
2. 墨层不是几何错，是**太淡**：`ink_stroke_long.png` 自身平均 alpha 只有 0.25（实心>0.5 的像素占 25.4%），
   再乘调用处的 0.42~0.78，落到中位亮度 79 的地面上就成了一层淡污 —— 看着像"没做特效"。

**做法**

- 新增 `SkillFx.lightbar_texture()`：256×64，纵向高斯 σ=9.6（FWHM 占全高 25%），
  横向两端各 12% `smoothstep` 收口 —— 硬边的另一半正是"端头垂直一刀"。
  ⚠ 不能叫 `streak_texture`：那名字已被 64×256 的流丝贴图占着，**重名直接是 parse error**。
- 新增 `_soft_bar()`，与 `_stretch_bar` 同签名，但 **thickness 定义为看得见的芯宽（FWHM）**，
  外晕自己溢出去（整条画 thickness×4 高）。影族 8 处全部切过去；
  其它家族已经按实机调定过，不动，免得一次改穿全项目。
- 墨带密度按实机读数抬上来：投晷 0.46→0.92 / 踏灯 0.42→0.88 / 分影 0.50→0.95 /
  长夜 0.42→0.90 / 缚影墨指 0.55→0.95 / 兜底 0.40→0.90，芯宽同时加一档（8→12、12→15、16→20、22→26）。
- 照骨三层因为语义变了（总高→芯宽）要按"总 footprint 不变"重算：`w*0.62/0.26/0.10`
  → `w*0.30/0.16/0.075`，第一版直接沿用旧数把光束削成一根牙签（截图才发现）。

**度量与判据**（`probe_zhizhu` 新增 3 条，现在 **247/0**）

| 判据 | 实测 | 原来 |
| --- | --- | --- |
| 光带纵向 10%→90% 过渡 | 17.0 原生 px（实机显示约 3.3 px） | 0（硬边一刀） |
| 芯宽 FWHM 占全高 | 25.0%（夹在 18~32% 才算折算正确） | — |
| 影族四式子树里纯白图方块 | 0 个（共 41 个 Sprite2D） | 9 个 |

负面测试做过：把 `_soft_bar` 的贴图退回 `white_texture()`，第三条立刻红成"找到 9 个"。
**判据下限那条（"确实播出了 41 个精灵"）是必须的** —— 前两版分别因为
"遍历 caster 而不是遍历返回的 SkillFx"和"没等帧"数到 0 个，`hard == 0` 就成了假的绿。

**harness 的两个坑**（`tools/shot_shadow_fx.tscn`，八式叠在真实地面上拍）：
地面 sprite 必须 `z_index = -10`（实机 combat_arena 的地面就在 -10，而影族墨带是 z=-1，
留 0 的话墨层整个钻到地面底下，拍出来"特效只剩一根亮线"，会把工具的问题当成美术问题）；
抓图要抓出手那一拍（影族瞬时层 lifetime 只有 0.4 秒，等 0.1 秒再拍就是衰减尾巴）。
