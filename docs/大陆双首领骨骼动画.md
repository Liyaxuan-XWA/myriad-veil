# 大陆双核心首领 · 骨骼动画制作记录（2026-10-29）

> 对象：青岚野 **青岚古猿**（`world_core_lianqi`）、云隐谷 **云隐苍角**（`world_core_zhuji`）。
> 两只原来是静态立绘；本次各自拆成正面视角刚体件，接入 `BossRig` 的骨骼循环 + 逐招一次性动画。

---

## 一、为什么不做成虎妖那套侧视骨架

两只定妆图都是 **正面 / 四分之三正面**：

- 古猿：正面站立，双臂垂在身侧，双拳在腿前；
- 苍角：正面偏右，巨角朝上，四条腿前后错开。

虎妖的 `BossRig` 是**侧视四足**骨架（近侧/远侧腿、尾巴），套到正面立绘上会把两条腿叠成一条、
头角朝向也不对。所以两只各用一套**正面关节**，但复用同一套 `BossRigData` / `AnimationPlayer` / `SkinVisual` 管线。

---

## 二、分件

| BOSS | 分件 | 关节 |
|---|---|---|
| 青岚古猿 | `body`（躯干 + 头 + 石肩甲）、`arm_l` / `arm_r`（肘下前臂 + 手）、`lower`（髋下双腿 + 脚） | 肘 / 髋圆盘 |
| 云隐苍角 | `body`（躯干 + 苔披）、`head`（颈 + 头 + 巨角）、`leg_bl` / `leg_br` / `leg_fl` / `leg_fr` | 颈 / 四髋圆盘 |

- 猿没有拆独立头：正面抬头幅度小，拆头收益低、颈部接缝风险高；头的表演并入躯干。
- 猿的腿合成 `lower`：正面视角下左手压在左腿上，逐腿拆会互相吃像素；`lower` 做重心侧摆。
- 鹿的头、角是一整块：头绕颈转，巨角跟着扫；四腿各自独立，走路/踏地能分别动。

### 拆件工具

`tools/build_world_boss_rigs.py`

- 输入：两张透明底赛璐璐立绘；
- 归一化：猿内容高 504、画布 360×560；鹿内容高 1040、画布 700×1120；
- 圆盘关节 + 最近实色补洞（旋转时不露背景）；
- 输出：`ape_rig/`、`cangjiao_rig/` 的分件 PNG + `rig.tres` + 分色预览。

## 三、动画集

| BOSS | 脚本 | idle / walk | 招式动画 |
|---|---|---|---|
| 青岚古猿 | `scripts/visual/boss_rig_ape.gd` | 呼吸 / 正面重心起伏 + 双臂摆 | `slam` `throw` `volley` `quake` `orb` `attack` |
| 云隐苍角 | `scripts/visual/boss_rig_stag.gd` | 呼吸 / 四腿交替 + 躯干侧摆 | `gore` `stomp` `mist` `roots` `rocks` `sweep` `miststep` `roar` `attack` |

- 招式名写在 `SecretWorldDB.CORE_SKILLS` / `CORE_SKILLS_ZHUJI` 的 `anim` 字段里；同一个 `form_id`
  的不同招（如 `form_smash` 同时是砸地 / 山崩 / 踏地 / 古根 / 鹿鸣）因此能播不同动作。
- `ArtDB.BOSS_MOVE_ANIMS` 仍登记 form 兜底（muzzle / 旧调用）。
- `WorldEnemy._start_core_skill()` 在前摇首帧播放对应 `anim`；平A 在 `_begin_attack()` 播 `attack`。
- 动作幅度在脚本里用 `*_BODY_MOTION / *_LIMB_MOTION` 统一放大（0.25 显示下小角度几乎看不见）；
  招式打击帧通过 `_retime_impact()` 对齐到 `windup / (windup + 0.15) ≈ 0.84`。
