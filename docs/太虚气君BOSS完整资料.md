# 太虚气君 · BOSS 完整资料

> 冲和界第 3 位（万界塔第 6 层）｜ 2026-10-28
> 机制：**气环 · 化劲** —— 资源（气环）→ 姿态（化劲）→ 反击（气浪）
> 与已有机制的区分：刀痕是留在地上的标记、剑意是自己的层数、两仪护体是护盾与极性、三色阵旗是棋盘；气环是**双方共用的招式资源**，化劲是**把伤害存起来再放回去**的姿态。

---

## 一、身份与形象

- 名号：太虚气君；称谓「一息化万法的气主」。
- 形象：浮空的年轻气修，素白 + 石青宽袖长袍，长白发、青玉小冠；**没有腿，衣摆下缘化成三缕云气**；身后三枚淡青气环。
- 与前面五只 BOSS 的区别：刀客（刀）/ 虎妖（兽）/ 剑客（剑）/ 两仪（太极光环）/ 定阵（盲眼阵师、实体旗）—— 气君是**没有落地的气身**，轮廓最轻。
- 色板：石青 / 素白 / 淡金 / 墨；场地 = 云石台 + 中央气环刻纹。

## 二、核心机制：气环 · 化劲

### 2.1 气环（BOSS 侧）

- BOSS 上限 **3 枚**；身周环绕，点亮几枚 = 现有几枚。
- **生成**：只有引气·聚环 +1（缩地 / 吐纳不送环）。
- **消耗**：冲气·裂空自动花 1 枚（伤害 +0.35×、射程 +90）；气爆·周天花掉全部（每枚 +0.60×）；化劲·卸力要 3 枚全花。
- **不提供伤害加成**：气环只是资源，花出去才是收益（刻意与「剑意」区分）。
- **玩家侧 2026-10-30 改版**：上限 5；引气 +1、踏罡 +1；冲气花环 +0.5×；缚脉花 1 枚压 BOSS 减速 50% / 封技 2 秒；化劲只要 1 枚；吐纳要 1 枚、CD 10 秒。详见第五节。

### 2.2 化劲（BOSS 侧）

- 三环齐时起手，**2.2 秒**姿态：受伤 **-40%**，并把其中的 **60%** 存起来（上限 **140**）。
- 结束时向周围 260 放一道**气浪**：`1.20× 攻击 + 存下的量`，**物理近战**（可弹反、可闪避）。
- 读法：起手时只报招名「化劲·卸力」并亮出一圈气罩；**化劲时继续打 = 给它攒气浪**。
- **弱点**：化劲不还手、不移动；停手 2.2 秒即可白赚一个安全窗。气浪可弹反，完美弹反直接作废。

### 2.3 环身气（被动）

- 有气环时，玩家贴到**本体边缘 44px** 内每 **1.2 秒**被擦一下：0.30× 攻击 + **滞气 0.8 秒**（2026-10-28 由「圆心 92px」改成边缘口径，站下半身也吃得到）。
- 作用：气环不只是资源，也是「别贴太近」的持续压力。

### 2.4 滞气（新 debuff）

- 「气锁·缚脉」命中挂 **4 秒**：**灵力停止回复**、移速 -20%。
- 玩家侧同样能挂给 BOSS（BOSS 无灵力，只有减速生效）。
- **玩家侧 10-30 追加**：缚脉花 1 枚气环时，BOSS 额外移速 -50%（与滞气的 -20% 取更强）且 **2 秒不能起手技能**；正在前摇的招会被打断。

## 四、行为树

0. **化劲优先**：3 环 + 冷却好 +（玩家近 340 或最近挨打）→ 化劲。
1. **三环但玩家不打** → 冲气花掉 1 环，不站着空看。
2. **两环 + 化劲就绪 + 玩家在 340 内** → 一定先补到三环（抱气起势）。
3. **最近挨打 > 20** → 80% 先引气（被打得越狠越会抱气）。
4. **残血 ≤45% 且环 <3** → 70% 吐纳（会被打断的输出窗）。
5. **环 <2** → 55% 引气。
6. 二阶段环 ≥2 → 气爆。
7. 其余按距离评分 + 连携（引气→冲气/缚脉 +1.4；缩地→回旋 +1.6；回旋→冲气 +1.0）+ 同招二连降权、三连封禁。

**命中门禁**：冲气 ≤560、回旋 ≤190、缚脉 ≤250、气爆 ≤300、缩地 ≤480；引气/化劲/吐纳不设攻击门禁。

**反制与逃课检查**：
- 贴脸 → 回旋击退 + 环身气；一直拉远 → 缩地贴人 + 冲气（不花环也够长）。
- 一直爆发 → 它会抱气化劲，把伤害还成气浪；解法是停手或弹反气浪。
- 打到残血 → 吐纳回血；不打断就白打一截，打断则进 0.9 秒僵直（输出窗）。
- 没有无敌帧、没有必须特定功法的门；拔不掉任何「必须打的物件」。

- **回血被动（2026-10-30 用户定）**：接触伤害的 **10%** 回复气血，但必须**佩戴被动「气环·回息」**（`passive_effect = qi_ring_leech`，走气君塔层感悟池）；不佩戴时气环只伤敌、不回复。佩戴后每次回血走 `QiFx.play_heal` 飘治疗光。

- **起手报招名**：八式统一在 `_qi_precast` 飘青蓝色招名（与 BOSS 的 `show_windup_line` 同节奏）。
- **门禁**：满 5 环不能再放聚气；气爆 0 环也能放（基础 1.00 倍）；化劲要 1 环、吐纳要 1 环（不够时直接拦下，不白扣灵力 / 冷却）。
- **BOSS 侧保持原样**：气君本体仍是 3 环、化劲 3 环、吐纳不花环；本次只改玩家侧八门。
- **吐纳引导**：改成 1.2 秒引导，期间受伤 ≥8% 最大气血会被打断（无回复）；与 BOSS 同口径。
- 验证：`tools/probe_player_qi.tscn` 47 项断言全绿（含环接触：一次接触一击 / 未戴被动不回血 / 佩戴「气环·回息」后 10% 回血 / 滞气 / 同接触不重复 / 离开再碰再算 / 被动在塔 6 层感悟池）；窗口截图 `output/qi_player_wave.png` / `qi_player_burst.png`（三环 + SkillFx 气云）。

## 八、美术与特效

- 立绘 / 卡面：**AI 赛璐璐**（洋红底抠图，去溢色；牌面 640×960 深青渐变 + 气环）。
- 场地：云石台（程序化，中央气环刻纹）。
- 特效：**QiFx** 气系一族 —— 气环 / 气浪 / 气柱 / 气旋；颜色固定石青；与刀光、兽爪、太极、绞绳分开。
  - 引气：三圈气环向内收；冲气：三层气流 + 前端气环；回旋：两圈反向气旋；缚脉：扇面五枚气环锁扣；
  - 化劲：贴身气罩（2.2s）；气浪：三层气墙 + 尘土；缩地：残影 + 落点环；气爆：按环数放大的三环 + 气柱；
  - 吐纳：升腾气柱 + 治疗绿点；被打断：无气柱、进僵直。
- **骨骼 rig**：最终为**单件身体 + 气环**（早期 T-pose 双臂分件已弃用：手臂一旋转就露出横切袖摆，见 `美术资源接入记录` §33）。
  `qijun_rig/rig.tres` + `BossRigQi`：8 式 + idle / walk，全部由**身体俯仰 / 前后位移 / 缩放 + 气环缩放自转 + SkillFx 云烟**表达。
- **回旋动作（2026-10-28）**：整身 360° 转圈已去掉 —— 单张 2D 立绘转起来像纸片翻面；改成身体 ±0.14 rad 侧倾 + 下沉回弹 + 轻微挤压，

- **飘字时机**：八式招名在 `_begin()` 进入前摇第一帧出现（hold ≥ 前摇）；化劲与吐纳的招名停留覆盖持续阶段，但只报「化劲·卸力」「归元·吐纳」，不带应对语句。
