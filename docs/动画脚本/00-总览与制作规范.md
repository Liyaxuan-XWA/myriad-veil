# 《万界秘境》12 镜动画脚本 · 总览与制作规范

> 本套脚本是《故事动画脚本.md》（2026-10-25 第二版）的**可执行版**：把每一镜拆成逐拍表，每一拍都写清「观众必须读懂什么」。
> 设定事实一律沿用总纲与《故事动画脚本.md》；凡属镜头、节奏、构图、表演的具体做法，按原文规矩标〔建议〕，可以随便改。

---

## 一、故事骨架（写每一镜之前先记住这三层）

> **一个被自己最好的朋友杀了一次的人，用一整段重修，把自己被拿走的东西一样一样拿回来 —— 最后发现，连这件事本身也是别人安排好的。**

| 层 | 内容 | 观众什么时候懂 |
|---|---|---|
| 表层 | 跌落巅峰 → 万界重修 → 复仇 | 镜 01–03 就懂，是继续看下去的动力 |
| 中层 | 记忆复苏，越拼越不对：挚友不是纯粹的恶，戒指不是偶然的救 | 镜 04–07 一层一层给 |
| 底层 | 神明伏笔：你以为的"偶然掉进来"，其实是被人放进去的 | 镜 11–12 只给冰山一角 |

**每一镜只负责推一层。** 一镜里塞两层，观众两层都读不到。

## 二、结构（12 镜 = 3 + 4 + 5）

| 段 | 镜 | 作用 | 播放时机 |
|---|---|---|---|
| 序章 | 01 洞府残影 / 02 那一剑 / 03 醒来 | 先给最强的钩子：**我被人杀了** | 新游戏开场 |
| 记忆 | 04 少年 / 05 赠戒 / 06 血誓 / 07 洞府清晰版 | 倒叙补全：**他不是坏，是该告诉他的人没告诉他** | 通关第 1–4 个位面，玩家主动在「记忆」里点 |
| 终章 | 08 化神 / 09 再相见 / 10 决战 / 11 封印 / 12 冰山一角 | 兑现承诺 → 夺回 → 看见更大的东西 | 突破化神、最终 BOSS 通关后 |

**关键手法**：镜 01 是洞府的**模糊版**，镜 07 是同一段记忆的**清晰版**。同一件事先给残影、后给全貌 —— 这就是「记忆残缺 → 逐层解锁」这条设定本身。

## 三、贯穿全篇的六个母题（每一镜都要用，别自己发明新的）

| 母题 | 含义 | 用法 |
|---|---|---|
| **光在呼吸** | 「那件东西」活着，但不是活物 | 只给明暗起伏，不给形状；至宝、神明、戒指光壳都用同一个呼吸节奏（约 0.6 Hz） |
| **手** | 人的立场 | 掌心向下＝封（压住），掌心向上＝托（取走）；全篇只有这两只手势 |
| **同一枚戒指的光** | 双宝同源 | 一个颜色贯穿：镜 02、05、07、11 都用同一个青（`#7FD9D3`），不许换 |
| **同一记起手式** | 两个人是同一套拳教出来的 | 镜 04 练一遍（要停 2 秒），镜 10 用它打一遍 —— 同一个构图、同一个角度 |
| **雨** | 少年时代 | 镜 04 大雨，镜 09 山门无雨（他回来了，但雨停了） |
| **白** | 记忆断片 | 镜 01 卡住→白，镜 02 从白里出来，镜 07 结尾也白 —— 白是"记忆的开合" |

## 四、颜色弧（全篇一条线，别乱）

黑 → 白 → 暗金 → 戒青 → 暖青绿（原初位面）→ 过曝暖白（少年）→ 夜橙（赠戒）→ 暗红（血誓）→ 冷白（洞府清晰）→ 金白（化神）→ 冷白＋戒青（再相见）→ 剪影＋金（决战）→ 金→青→白（封印）→ 暖但比开场冷（冰山一角）。

**每一镜只允许两个主色**。第三个颜色出现，说明这一镜讲了两件事。

## 五、每一镜的脚本格式（12 个文件统一用它）

| 字段 | 写什么 |
|---|---|
| 头部表 | 时长 / 基调（色板）/ BGM / 解锁条件 / 前接后接 |
| 一句话 | 给配音和宣传用的一句话，也是这一镜的"命题" |
| 这一镜要让观众读懂 | 最多 3 条。超过 3 条，砍掉一条 |
| 逐拍表 | **时间 / 画面 / 观众读到 / 怎么做（保证读得懂）** —— 这张表是脚本的主体 |
| 旁白 | 台词 + 起止时间（精确到 0.1s，可以直接拿去录） |
| 台词 | 同上，标清是谁说的、什么语气 |
| 音 | 环境音 / 标记音 / 静音点 |
| 不做什么 | 这一镜的禁忌（防止做歪） |
| 制作笔记 | 引擎要点、难点、如果读不出来怎么加强 |

**「观众读到」这一列是全套脚本的核心**：它不写"画面里有什么"，只写"观众在这一秒必须明白什么"。做动画时，任何一拍如果读完这一列还是不清楚，就说明这一拍要重做，而不是加解释。

## 六、全篇三条硬规矩（做的时候别破）

1. **无字**：画面里不出现可读文字。镜 06 的「永世守护」、镜 07 的洞府警告，都不刻字 —— 用旁白念、用光的纹路暗示。唯一例外是镜 12 的片尾字卡。
2. **无脸**：主角和挚友都不给清晰五官。给剪影、给背影、给眼睛的一点点颜色。观众要能把自己放进去。
3. **不给形状**：时空至宝、神明，全篇只给"在呼吸的一团""在做动作的一道光"。
