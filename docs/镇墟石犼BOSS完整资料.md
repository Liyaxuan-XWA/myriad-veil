## 一、定位与形象

- **镇墟石犼**：四足石狮/犼，躯干由墓石拼成，鬃毛是一圈断裂碑石，眼睛被一条石带封死，裂缝透青幽火；尾巴是石槌尾。
- 3/4 朝右赛璐璐立绘；7 件 rig：`body / head（含碑鬃+封眼石带）/ tail / leg_front_near / leg_front_far / leg_rear_near / leg_rear_far`。
- 二阶段封眼石带裂开（世界层裂纹 + 长吼），震塌两根石碣；不是单纯数值 ×1.25。
- 与古猿（长臂）/ 苍角（鹿角）/ 火麟（独角火兽）剪影分开；与离照、晏无咎等不共享资源机制。

## 三、核心机制「闻声」

它看不见，只追**最后一次响声的位置**。

- **声点来源**：跑动每 0.45 秒留一次脚步点（二阶段 0.30 秒）；普攻 / 施法 / 闪避在起手位置留一次大声点。
- **静步**：停下 0.35 秒不再更新声点；超过 1.5 秒没听到声音，它会低吼、原地「搜地」震一圈（0.45× 物攻，半径 240）。
- **攻击目标**：它的追击目标是一个 `NoiseMarker`，不是玩家实时位置。盲扑 / 崩山撞 / 闻声吐息全部打向旧声点；盲扑与崩山撞在声点先显示预警。
- **正常近战 / 裂石爪 / 震地 / 石尾扫**：朝向声点，玩家若已静步换位，会打空。
- **弹反**：物理招（盲扑 / 裂石爪 / 震地 / 石尾扫 / 崩山撞）可弹反；闻声吐息为风属性法术，不可弹反。

## 四、石碣

墓庭六根石碣，围绕山门半径 320 摆放（每根 2 点耐久）：

- 盲扑 / 崩山撞撞上石碣：石犼**硬直 2 秒、受到伤害 +25% 持续 5 秒**；石碣裂一道，第二击塌。
- 二阶段破封时随机震塌 2 根；崩山撞沿途继续拆。
- 石碣在脱战后全部复原；Boss 死亡 / 离开场景时清理。
- 玩家不能攻击石碣；它是「引撞」的场地物，不是可拆资源。

## 五、二阶段「破封 · 听风」

- 封眼石带裂开：世界层青色裂纹 + 1.35 秒长吼。
- **震塌两根石碣**；脚步点间隔 0.45 → **0.30 秒**。
- **回声定位**：每 6 秒放三道声波（半径 300 / 600 / 900）。玩家**移动 / 出手 / 闪避 / 施法中被扫到**会暴露当前位置并接盲扑；**原地不动则安全**。
- 每次长吼后**自我震聋 2 秒**；闻声吐息后自聋 2.5 秒——这两段是玩家自由换位 / 贴脸的窗口。
- 崩山撞为二阶段招式（900 距离 / 1.30×），撞碑自硬直 2 秒。
