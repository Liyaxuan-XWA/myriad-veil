# 棋坛关卡制取代押注经济

万界棋坛原本靠**押注制**做经济主轴（设计案 §2b：AI 镜像玩家注额，赢 +50 / 输 −50 锻造晶石）。
2026-11-05 改为无限线性关卡阶梯后，我们决定**关卡模式下不再走押注**：
进关不扣钱、输了不罚、过关只在**首通那一次**发 8 锻造晶石，重打已通关卡不再产钱。

理由：押注的前提是"玩家自己控制风险敞口"，而关卡制的乐趣在于**同一副固定卡组可以反复针对重试**；
两者同时存在会让"打不过就无成本重开"和"重开一次要冒 50 晶石"互相打架，玩家要么被惩罚了不该惩罚的行为，
要么根本感知不到注额。8 晶石的量级（对比卡包非普通卡每张 50）刻意小到不能刷，所以无限关不会变成无限印钱。

**状态**：accepted。

**备选方案**：保留押注 + 8 晶石作额外首通奖（被否：与零代价重试冲突）；
取消押注但过关奖随关卡递增（被否：直接违反"数值不会膨胀"）。

**后果**：
- `MatchDB.bet_matched()` 与 `BET_MIN/BET_MAX` **保留不删**——设计案 §2b 明确写了 `min(A押,B押)` 这条规则
  本身是留给以后真人对局的。代码留着、调用断了。
- `_settle()` 里"负 → `consume_materials`"这条分支在关卡模式下不再可达，别把它当 bug 删掉，
  联机模式回来时还要用。
- 输一关的代价变成纯时间。这是刻意的。
