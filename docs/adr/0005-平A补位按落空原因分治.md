# 平A 补位按「落空原因」分治，且与弹反追击共用落点求解器

平A 近距离吸附（2026-11-10 上线）原来的判据是一句话：「这一刀预检打不到，就滑步到一个固定贴脸站位」。
用户实机反馈「有时候明明能打到敌人，还是会吸附到 BOSS 面前再打」。

查下来不是预检不准，而是**它把两种成因完全不同的落空当成同一种处理**：三段平A 的扇形差 2.56 倍
（`ArtDB.WEAPON_COMBO_SWEEPS`：劈/撩 −85°→70° 半角 **89.5°**、reach 76；刺 −30°→8° 半角 **35°**、reach 106.75）。
贴身循环时段 1/2 怎么都中，段 3 只有 ±35° 锥 —— 站在侧前方就判「会落空」，可这一刀**纯粹是角度不对、
距离绰绰有余**，只需要转腕子。旧落点公式不看原因，一律走到 `clamp(min(hit_r+18, body_r+24), reach×0.35, reach×0.72)`
≈ 54.7px，于是每三段白扑一次脸（以赫连霄最近球 r≈30 为例：只需站到 86px 就必定进判定，白走了 31px）。

用户 2026-11-11 逐题拍定以下口径，**这些是设计决策，不是实现细节**：

1. **按落空原因分开处理**：角度不够 ⇒ 只改 `attack_dir`，**位移为 0、不出残影**；距离不够 ⇒ 才补位。
2. **落点 = 命中上界 − 余量**：`reach + 该球自身半径 − 20px`，即「刚好进判定」，不再走到固定贴脸站位。
   20 = 玩家胶囊半径 12 + 这 0.12s 里 BOSS 常规追近的约 10px（P2 移速 85）。
3. **平A 只补「差一步」**：缺口 > 60px 一律不管（60px/0.12s = 500px/s，与闪避 480 同档）。
   旧的 `MELEE_SNAP_RANGE = 150` 阈值**删除**，改为纯缺口制 —— 用户选更大胆的那条，接受段 3 因射程更长
   而可吸范围放宽到约 166px。
4. **滑步落点锁死在起手那一帧**，tween 不再每帧重读 BOSS 位置；出伤前一帧再校验一次，还差就只补差的那段。
5. **弹反追击共用落点求解器，但门槛各自独立**：追击**不吃 60px 缺口上限** —— 它消耗完美弹反给的
   一次性资格，追远正是奖励本身（若一并限 60px 等于凭空削弱弹反流）。
6. **转向门禁只有一套**：移动中只认攻击方向前方 ±90°、静止不限（`_aim_gate_ok`）。吸附原先自己写了
   一句 `attack_dir = 朝敌方向`，绕过了软锁定的这道门禁。
7. **位移不兼任保命**：落点撞进 BOSS 前摇范围照走不误。弹反 / 闪避才是应对前摇的工具，
   加了「落点安全判定」就回到「有时补有时不补且玩家看不懂原因」，正是要消除的症状。

**状态**：accepted（2026-11-11）。

## 明确遗留（这次有意不动）

- **段 3 半角 35° 本身**才是「刺击容易空」的根，吸附只是救场。动它等于改平A 手感底座与伤害分布。
- **软锁定瞄身体中心、命中判最近球心**不同源（`_auto_aim_to_boss` 用 `boss.global_position`，
  `_damage_bosses_in_shape` 逐受击球判）。求解器内部用球心，把差异补掉了，但瞄准中心本身没统一。
- **宽体 BOSS 站头侧时一段只打到一个球**：曾评估过「落点选扇形覆盖球数最多者」，那是在改命中收益
  而不是改手感，会把伤害曲线一起拉高，否决。
- **功法位移不接这套求解器**（用户明确排除「三处统一」）：`_parry_followup_dash` 的功法入口
  （传 `target_range` 而不传 `shape`）站位口径一字未动。

## 后果与红线

- ⚠ **不许把弹反追击的实时追踪「顺手统一」成锁死落点**。吸附锁死是因为 0.12s 内只有常规追近（约 10px）；
  而追击这 0.22s 里 BOSS 会被弹反击退 **120px**（`BossBase.on_parried → _bump_back`，0.18s），
  锁死等于回到 2026-10-30 那个「完美弹反赫连霄后追击打不到他」的 bug。两条路的注释里都写了这一条。
- ⚠ **命中上界必须用该球自身半径 `sv.z`，不能用外接半径 `hit_radius()`**：那含头顶球，
  赫连霄 ≈93 → 站位 111 → 普攻容差只剩 2~3 像素（10-28 实测过的同一个坑）。
- ⚠ **再校验前必须 `kill()` 滑步 tween**：两者都是 0.12s，谁先跑完不确定；让 tween 多跑一帧，
  它末帧的 `global_position = target_pos` 会把刚补好的位置又拽回旧落点（M6 变异实测 hits=0）。
- 新增可调参数集中在四个常量上：`MELEE_SNAP_TIME` / `MELEE_SNAP_MARGIN` / `MELEE_SNAP_MAX_STEP` /
  `PLAYER_BODY_RADIUS`。`probe_attack_snap` 的 ① 有**像素级落点锁**，改 `MARGIN` 会直接变红，
  这是故意的 —— 改这个数必须连同手感一起重新验收。
