## 机制：一条几何规则管全场

- 战场只有一处光源：`ShadowLamp` 界灯（BOSS 自己在 `_setup` 后创建，同场复用，不依赖战场脚本）。
- **影身** = 从单位脚下沿「单位 − 光源」方向铺出去的地面走廊：
  `影长 = clamp(40 + 到光源距离 × 1.15, 40, 620)`，走廊宽度从脚下 54 张到影尖 104（垂直方向压 0.72 做地面透视）。
  全部公式在 `scripts/combat/shadow_law.gd`，BOSS 判定、玩家判定、特效、图鉴文案都从这里取数。
- 执烛的招式由影身交付，本体只负责走位与一记近身扇形。**地上那条黑刃 + 影尖那枚冷银亮点就是射程读数**。
- 二阶段「夺灯 · 反照」：光源转交给本体 → 它没有影子，**玩家的影带**成为交付通道，起手瞬间锚定在玩家脚下、朝背离它的方向铺。后退 = 走进自己的影子；解法是侧移或朝它压出去。

## 反逃课与弱点（都是实测过的）

- 弱点：把执烛逼到灯下 → 影长塌到 40，投晷 / 缚影射程当场消失（`probe_zhizhu` 用几何断言锁死这条）。
- 它的应对：影身盖不住人时**不许硬放远程**，改用踏灯绕到灯的另一侧重新拉出影子（落点按 `r ≥ (D−40)/2.15` 且尊重 620 上限解算，实测真的产生位移并恢复射程）。
- 你贴脸时它捻灯（明灭）换成本体近战节奏，暗场里它更疼但也更挨打 —— 不是无代价的贴脸免疫。
- 照骨与影长无关，逼你至少处理一道不可弹反的直线 —— 站灯后不出手并不安全。
- 弹反物理影招 → 影子折回斩它自己（0.9× 反噬真伤）；夺灯后它没有影子，这条自然失效，P2 逼你换解法。

## 数值反推（game-numeric-design 的 TTK 反推法）

- 基线：`docs/照影界首位BOSS_设计案.md` + 记忆里的元婴后期面板 657 血 / 184 物攻 / 414 法攻 / 法技 ×2.965 / 间隔 0.350s。
- 观澜 40,000 血 + 法抗 100（`r/(r+100)` → 减 50%）实测自动 TTK 63.4s ⇒ 有效承伤 631 DPS；按自动循环 60% 法伤占比换算**无抗目标承伤 ≈ 901 DPS**。
- 本只取物抗 20 / 法抗 0（与观澜的法术门禁反向，奖励另一类 build）⇒ 有效 ≈ 841 DPS。目标 TTK = 观澜 +13% ≈ 72s ⇒ **HP 56,000**。
- 单下结算（玩家物抗约 34%）：小招 119~156（18~24% 血）、终局招 P2 264（40% 血）⇒ 最快 4~5 下致死，没有一击过半。

### ⚠ 实测存档与基线不一致（要用户确认口径）

`tools/probe_zhizhu_live_play.gd` 读当前自动存档实测：

```
LIVE HP 711 物攻 443 法攻 222 间隔 0.168 法技x1.00
RESULT phase2=16.4 kill=33.3   ← 33 秒，不是 72 秒
```

查 `save_slot_1.json` 的 `equipment_data`：武器 `strength 236`、护甲 `hp_max 303`、饰品 `attack_speed 108`、`physical_resist 70`、`magic_resist 78` —— 全是**调试面板量级**（真实元婴装备是 力量 +20 / 气血 +24 一档），且这套装备的法技增伤为 ×1.00。所以这份存档不是设计参照，56,000 仍按 11-01 记录的真实后期面板反推。

**若你希望按这份实机存档定难度**：TTK 从 33s 拉到 72s 需要 HP ≈ 120,000（或把攻速 / 装备成长压回正常成长曲线）。等你实机看过再定，我没有擅自把血量翻倍。

## 玩家侧继承（同一条几何，另一种表达）

- 玩家的灯笼**拖在瞄准方向的反面**，落后距离由**最近 0.6 秒的移动速度均值**决定（`want = clamp(速度均值 × 1.3, 0, 250)`，灯笼以 430 px/s 追赶）→ 跑动 / 突进把灯甩远、影子拉长；真站着不动照样塌回脚边。
- **影系招式的射程 = 按下那一瞬定格的影长**（快照覆盖前摇+判定+后摇，`_shadow_fit_form` 与 `_shadow_handle_cast` 读同一份）。
- 明灭 = 影长归零换 2.5s 物理功法 +30%；分影 = 撕影尖那一截代打 4s、自己影长 ×0.72、只有缚影 / 分影等它回来；长夜 = 10s 影长钉在满值 + 走廊 ×1.25 + 削影必定双段（CD 20 / 24 灵力）；被动执灯 = 影长 ×1.3 + 完美闪避拉满。
- 不读写任何 BOSS 私有状态 → 演武场、万界秘境、别的位面战场都照常成立。
- 未带任何影系功法时，灯笼与影带**整条不创建**（无来源不显示）。

## 2026-11-05 元素改挂「暗」

- 八式 + 被动的 `damage_element` 从 `water` → **`dark`**（`AttributeDB.ELEMENTS` 扩到 8 个，新增 `resist_dark`、显示名「暗抗」、基础默认 0）。
- ⚠ **MoveDB 的 `damage_element` 是 BOSS 与玩家共用的一行**，所以执烛自己的影技同样改挂暗 —— 这是「一条几何管两边」的必然结果，不是漏改。
- 抗性别处仍按原口径：元素抗只乘在**法术段**上（`spell_final *= 1 - elem_red`），所以真正吃到暗抗结算的只有照骨（`spell_coeff 1.25`）；削影 / 投晷 / 缚影 / 踏灯 / 长夜是物理，走物抗。元素标签对它们的作用是图鉴与元素探查的归属，以及后续任何按元素写的交互。
- 文案同步：照骨「水寒光束」→「暗寒光束（暗属性）」；影没描述里的「没有光的深水」去掉水字。
- 符箓**没有**跟着加暗符（仍是七元素 × 28 张）—— 配方属用户定稿内容，不自行补。
- 守卫：`probe_elements` 12/0（八元素注册 + 暗抗显示名 + 基础抗性含暗）；`probe_zhizhu` 新增 3a 段，钉住 8 形态全为暗、且观澜镜身仍是水（防止哪天顺手把整界刷成暗）。

## 2026-11-05 暗属性的专属机制「蚀」

用户定：**暗是通用属性，不许绑在影子上**（我第一版提的「暗=削影长」被否）。所以规则挂在
「这一击的 element 是 dark」上，不挂在任何 form 的 `debuff_on_hit` 上 —— 将来别的 BOSS、
符箓、装备特效只要标暗，蚀自动生效。

**效果两条**（数值全在 `AttributeDB.DARK_EROSION_*`，DebuffDB 那条只是显示）：
1. 目标的**物抗 / 法抗 / 元素抗数值**先 ×0.60 再进减免曲线；
2. 期间受到的**治疗只剩 10%**（减疗 90%）。

**为什么不是又一档增伤**：现有 6 条 debuff 已经是「无条件乘伤」（灾崩易伤 30% 那类）。
蚀是**按你堆了多少减免按比例吃掉**，收益完全取决于目标有多硬：

| 目标物抗 | 无蚀 | 蚀后 | 多挨 |
|---|---|---|---|
| 0 | 100.0% | 100.0% | **+0%** |
| 40 | 71.4% | 80.6% | +12.9% |
| 100 | 50.0% | 62.5% | +25.0% |
| 200 | 33.3% | 45.5% | +36.4% |

所以暗的定位是**破硬**：高抗 BOSS 与堆抗流的解。软目标身上它几乎不存在，不会变成全民必带。

**公平阀 = 9 秒刷新锁**：同一目标每 9 秒最多被挂上 1 次，蚀期间再中暗招**不续杯**。
没有这条，执烛的暗招会把玩家常驻磨在减疗 90% 里（丹药 / 水愈符 / 气环·回息 / 续命灯全废），
而玩家对 BOSS 也只是把覆盖率拉满 —— 不对称。有了它，双方共用一个 6/9 的节奏。
（我上一条方案里提的「站灯下不刷新」**没有采用**：那等于把暗的解法绑回影子，正是被否的方向。）

**持续按暗抗缩短**：`6s × (1 - 暗减免)` → 暗抗 100 只剩 3 秒。这是新注册的 `resist_dark`
目前唯一的用处；暗抗的来源（装备词条 / 暗符）属用户定稿内容，我没补。

**实现要点（都是"只有一个真相源"的修法）**
- 穿抗只作用于 `DamageCalc` 结算层，**不改 `attribute()`**：角色面板显示的仍是真实抗性。
- 触发点在**受击方** `take_damage`（玩家与 BOSS 各一处），不在攻击方 —— 所以任何暗来源都成立。
- ⚠ **踩到并修掉一个旧的双真相源**：`player.gd` / `domain_boss_04_b.gd` / `shadow_sweeper.gd`
  里有 9 处把元素**写死成 `"water"`**，MoveDB 改暗之后它们没跟着走，结果真放一招影技只挂上
  影没、挂不上蚀。现在全部改读 `SkillDB.get_damage_element(skill_id)` / `form.damage_element`，
  影兽的元素由施法者 `setup()` 传入。探针「投晷真的把蚀挂上了 BOSS」就是守这条的。
- 回血入口统一：玩家全部走 `restore_health()`（吐纳那口原本绕过入口直接写 hp，已改）；
  BOSS 侧新增 `BossBase.apply_heal()`，剑阵尽破 / 两仪守阵常驻与破阵 / 02_c 引导 /
  世界怪法宝与续命灯 6 处全部改走它。
- 被弹反、闪避或无敌帧吞掉的暗击**不挂蚀**：元素交互跟着「这一下真的打中了」走，
  不能出现「躲开了却中减疗 90%」。
