# 照影界 · 首位 BOSS「观澜」设计案（2026-11-01）

## 位面

- **照影界**（domain_04），接在赤霄界之后，境界要求元婴。
- 视觉：黑镜水、银白/靛青、倒悬山影；镜面既是地面也是读数载体。
- 文案：镜水无波，万象皆有其影；照影界以倒影证道，真假同源。

## 机制：镜身 · 照影

- 场上只有一名**真身**与 2（二阶段 3）名**镜像**。真身脚下有倒影，镜像没有；这是唯一辨识依据。
- 镜像 1 击即碎，会周期性地向玩家打出镜影斩；碎裂不伤真身。
- **换镜**：真身与任一镜像交换位置；换镜后真身暴露 1.2 秒（受到伤害 +20%），倒影随真身移动。
- **碎镜**：真身碎掉一具镜像，碎片在镜像位置炸开；是 BOSS 用镜像换伤害的手段。
- **镜返**：真身进入 1.2 秒镜面架势；期间被近战/投掷命中会把 35% 伤害以水属性弹回，玩家可以停手、绕后或闪避。
- **水镜环**：以真身为圆心展开 3 秒镜环，环内每 0.8 秒受水伤并减速；走出环即可。
- **万镜归一**（二阶段）：真身与全部镜像同时出斩；真身那一斩带倒影，镜像斩只有 60% 伤害。
- 没有势条、没有资源条、没有攒层兑现；破解方式就是看倒影、打真身、碎镜像、躲镜返/镜环。

## 八式

| 招式 | 形态 | 用途 | 玩家侧对应 |
|---|---|---|---|
| 镜水斩 | 身前扇形，物理 | 近身主攻；镜像会跟着斩 | 镜水斩 |
| 照影刺 | 直线，物理，可弹 | 中距离穿透；镜像会补刺 | 照影刺 |
| 镜花 | 自身，召出 2/3 具镜像 | 建立场压；镜像碎后重召 | 镜花 |

| 镜返 | 自身，架势 | 反制近战/投掷 | 镜返 |
| 水镜环 | 以自身为圆心，水属性 | 近身区域封锁 | 镜湖 |

## 数值

- BOSS 24,000 血 / 110 攻 / 移速 108·126 / 二阶段 ×1.25；弱点：换镜后 1.2 秒受伤 +20%。
- 目标玩家：元婴前期~中期，道器 +4~+8；447~480 血，183~187 物攻，153 法攻，物抗 33~35%，DPS 约 580。
- 技能系数：小招 0.7~1.0；大招 1.2~1.3；P2 ×1.25；玩家大技能 1.0~1.8 倍。
- 掉落：照影刃（法强/法技增伤/回灵，法术持续向）、镜湖衣（气血/法抗/水抗/风抗，补玩家法抗与水风抗缺口）、照影镜砂（位面材料，20%）、观澜元魂（塔 11+ 50%）、观澜令（元魂+破损观澜装备）。
- 位面法宝：照影界三材料集齐后另做（本只先落第一件材料）。

## 玩家侧机制

- 玩家可召出**自己的镜像**（最大 2 具）。镜像会复制玩家下一次直接命中，追加 40~50% 伤害，然后消散。
- 镜花召 1 具；万镜召 2 具；换镜与镜像换位；碎镜碎掉镜像换范围伤害；镜湖留减速水场；镜返是格挡反击架势。
- 被动「照影」：完美闪避后留下一具镜像（8 秒内置一次）。
- 首战不需要任何镜系功法：BOSS 的镜像可以被打碎，真身有倒影可辨，空手物理/术法/弹反/闪避即可破。

## 美术

- 观澜：银白/靛青长袍、镜面半脸面具、手持圆镜/镜刃；站姿与前三只位面主不同；脚下倒影是机制读数。
- 镜湖战场：黑水镜面、银涟漪、倒悬山影。
- 技能特效：银白/靛青的镜片、涟漪、倒影；八式形状/颜色/时机各自可辨；不使用既有 BOSS 的日轮/雷纹/三灾轮质感。
- 原型先出：T-pose 定妆 + 可拆的镜/持镜手；rig 只拆 body / mirror，避免宽袖粘连；关节用圆盘补洞。

## 棋局数值口径：水镜环按「整场结算」归一化（2026-11-06 用户问「为什么下棋模式里水镜环伤害这么高」）

实测（`tools/diag_match_ring.tscn`，观澜棋子 vs 两仪量尺 22 秒，攻击力 8500 / 对面满血 31500）：

| | 修前 | 修后 |
|---|---|---|
| 本体环单次 tick | 4319（= 8500×0.5 名义一击） | **1108** |
| 一枚环从头到尾 | 17277（4 拍全中） | 4430 |
| 一次施放（本体 + 镜像环 2 枚 7 拍）raw | ≈ 24000 = 对面 76% 血 | ≈ 6650 |
| 战报里「水镜环」占它总输出 | 37.5%（出手 1 次 ≈ 照影刺出手 3 次） | 17.7% |

根因不是系数写错，而是**系数的口径**：`damage_coeff = 0.5` 是 PvE 值，设计案写明「走出环即可」，
本来就假设目标只吃 1~2 拍。棋子站桩对拼、不会走出这块 AoE ⇒ 3 秒 4 拍全中，实际等于名义的 4 倍；
再叠上 `_mimic_images(F_RING, …)` 让每具镜像各铺一枚自己的环（2 秒 3 拍、×0.5）。

**改法**：归一化放在 `MirrorRingField.setup()` 一处 —— 来源带 `team_id >= 0`（棋局棋子，镜像也继承队伍号）
时，单次 tick 除以拍数 `ceil(duration / TICK)`（3.0s ⇒ 4 拍、2.0s ⇒ 3 拍），
于是「一枚环从头到尾 = 名义那一击」。本体环、镜像环、以后任何复用这条场的招式都自动跟上。
**PvE 一个字没动**：玩家真走得出圈，那一档是设计好的压力。

判据：`probe_guanying` 195/0 新增两条同口径守卫（PvE 单次 tick = 名义 ±12%；棋局 单次×拍数 = 名义），
`probe_guanying_play` 11/0、`probe_match_report` 19/0、`probe_match_pieces` 32/0、`probe_match_balance` 39/0。

⚠ 顺带量到两件没动的事，等用户定：
① 环的 tick 结算走的是 `MirrorRingField._pulse()` 直接调 `take_damage`，**绕过 `BossBase.deal_damage_to()`**
   ⇒ 不吃 `world_frozen`（选牌时停里它照样掉血）、不吃尸体守卫、也不吃 `_match_damage_scale()`。
   今天 boss_04 的 scale 是 1.0 所以数值上无差，但这条路径是漏的。
② `calibrate_match_duel -- only=boss_04` 现在量到**有效 DPS 1532 = 名义 774 的 1.98×**（两侧 1481·1584，差 7%，
   比当年那条「549、两侧差 73% 噪声太大先不动」干净得多）。环削掉一档之后仍然偏高，
   说明 `ATTACK_CALIB["boss_04"] = 8500` 是在「镜像卫星静默 0 效果」修好之前校的老值。
