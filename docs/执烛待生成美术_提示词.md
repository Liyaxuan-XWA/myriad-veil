## 9. 执烛 13 张带深蓝圆角底板的图标 —— 已抠净（2026-11-04 结案）

**现象**：这批图标在背包 / 功法库 / 锻造台里是一张**方形蓝牌**，不是透明底。
抠之前 13 张的实心占比全在 82.8~86.9%（正常抠过的装备材料图标是 15~50%）。

### 先说结论：算法抠这一批**确实不行**，最后是「图生图换底 → 洋红键色」解决的

**A. 算法抠为什么不行**（`tools/mat_icon_plate.py` 里 `matte()` 这条路，四轮都记着）：
底板靠边一圈中位色 `(23,30,62)`，而影/墨物件本身就是深蓝黑，**和底板同一个色域**。
- v1/v2 全局二次多项式拟合：色距 p10/p50/p90 = `3.0/13.3/36.3`，阈值压到 0.13 只掉到 78~83%
  （底板还在）；拉到 0.40 掉到 42~58%，但物件先缺、还留一圈脏斑。
- v3 把底板在物件背后**重建**（1/8 网格解 Laplace + Jacobi 松弛）再逐像素比：还是不行，
  因为牌的纸纹幅度 ≈ 物件与底板的色差，任何单一阈值都在「留牌」和「烂物件」之间二选一。
- v4 **先 σ=1.2px 模糊再比色**（纸纹被平均掉、物件的大尺度色差留着）+ 阈值按本图底板带
  分位数现算 + 背景只从四边灌入 + alpha 用掩膜羽化（不再拿色距 ramp 当 alpha，否则底板拿到
  ~89 的半透明，浅底上一铺就是一个灰方块）：**暖色物件抠干净了**（执烛令 83.5%→54.1%，
  0 漏洞），深色物件仍然从中间被啃穿。
- v5 试过另外两条判据，实测都不成立：
  - 滞后双阈值（hysteresis）：烛泪坠的牌面连成一片，80.1% 全留，更糟。
  - **纹理判据**（底板无颗粒、物件有笔触）：量出来底板局部高频 p90 = 36，比刀身暗侧的中位
    12.1 还高 —— 底板的噪声尾部盖过物件的笔触，分不开。
  - 把物件轮廓当「墙」阻止泛洪穿过：加与不加数字一模一样（暗刀身到牌面是**渐变**，没有边）。

  → 所以 `tr_zhizhu_ling.png` 用 v4 抠（铜牌暖色，抠得干净），其余 12 张走下面的重出。

**B. 重出为什么行**：不是让模型重画一张，而是**图生图只换背景**——
把现役图标当 Image 1，要求「只把背景换成平涂洋红 `#FF00FE`，物件一笔不改，不要圆角牌/边框/
光晕/渐变/投影」。模型懂「哪部分是物件、哪部分是牌」，这是像素算法没有的语义。
13 张全部一次通过，物件完整（暗刀身、烛泪石面、蓝火苗、墨手、影弧都在）。

### 收片（`tools/mat_icon_plate.py --key`，已落盘）
- 键色：`k = ((r+b)/2 - g - 30)/70`，`alpha = (1-k)×255`，`k≥0.995` 直接清零。
- **颜色不反解，改从最近的实心像素搬**：反解 `观测 = 真色×(1-k) + 键色×k` 在亮边（冷银/白热）
  上过冲到偏绿，实测 照骨/投晷/缚影 的羽化带里 **36~40% 的像素偏绿**（实心区 0.00%）。
  搬色之后降到 2~13%。
- **去紫偏**：模型会顺着键色把墨迹画成紫罗兰（`skill_shadow_step` 可见区中位色 `(40,21,60)`，
  原设计是蓝黑）。判据取「r 和 b **同时**高于 g」的那部分一起减掉 —— 暖铜 `(150,100,60)`、
  皮肤 `(200,160,140)`、纯蓝墨 `(20,25,60)` 都不满足，不受影响。之后 13 张偏紫占比 0.0~0.2%。
- 掉碎点（<48px 的连通块，最大的那块永远保留）→ 按内容包围盒裁 → 等比放进 256²、边距 14。
- 改前原图全部备份在 `assets/_backup/mat_plate_20261104/`（14 张）。

1. 别一上来调阈值抠像素 —— 深蓝墨件和深蓝牌同色域，四轮都证明抠不干净。
2. **图生图换底**：原图当 Image 1，只换背景成平涂洋红，物件写死「不许改」。
3. 收片用「搬色不反解」+「r、b 双双高于 g 才去紫」，两条都是这次量出来的。

## 附：本次实际用的图生图提示词模板（照抄即可复用）

```
Use case: precise-object-edit — game icon background replacement for chroma keying
Input images: Image 1 is the source icon; its painted object must be preserved exactly.
Primary request: replace ONLY the background with a flat solid magenta key. Do not touch the object.
Scene/backdrop: a single flat uniform magenta #FF00FE filling the entire canvas outside the object
  silhouette. No rounded plate, no rectangle frame, no vignette, no glow, no gradient,
  no drop shadow, no paper texture, no border bevel.
Subject: <把这张图里的物件用一句话说清：造型 + 朝向 + 光色 + 笔触>
Style/medium: painterly wuxia / xianxia game icon, matching Image 1's rendering exactly.
Composition/framing: object centered, occupying about 78% of the canvas, generous even margin.
Constraints: do not restyle, recolor, reshape, reposition or resize any part of the object;
  do not add or remove any detail; <深色那部分> IS the object, keep every part of it;
  the magenta must be flat and consistent so it can be color-keyed;
  no magenta bleeding onto the object and no blue halo around it; no text, no logo, no watermark.
```

两个必须写进 Constraints 的点（不写就会踩）：
- **「深色那部分是物件，全留着」**——影/墨件的暗部跟旧底板同色，模型容易顺手把它当背景擦掉。
- 出图是 1024²，收片脚本会等比缩到 256²；**别在提示词里要求 256**，生图工具给小图会糊。
