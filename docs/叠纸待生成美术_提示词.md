```
内衬青灰 #6E7A82 / 青铜 #8A6A3C / 淡金 #E8D296。
禁止：赛博、机甲、日式萌系大眼、写实照片脸、发光描边霓虹、镜头光晕、体积光柱。
```

**这一位最容易被画错的地方，先说清楚：**
- 它是**纸**，不是布。袍面上只有**硬折出来的棱线**（像对折的纸那样一条直线 + 一侧压深一档），
  不许画成布褶、飘带、云雾袖。
- 它**不飘**。动作语言是「翻面 / 对折 / 压平」，不是「衣袂飘飘」。
- 它的脸是**一张对折的纸**，展开后露出一道墨痕；不许画成五官脸、面具脸、纸扎人偶脸。
- 手里的东西是**青铜镇尺**（压纸用的文房器，一根扁直铜条），**不是剑、不是尺形兵器、不是笏板**。
- 与同位面前两位必须一眼分开：观澜 = 银镜长袍、执烛 = 青黑广袖提灯。
  **叠纸不许出现灯笼、不许出现镜子、不许出现黑色长袍。**
