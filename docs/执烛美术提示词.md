## 0. 画风锚点（每张都要遵守）

- **角色 = 赛璐璐（cel-shading）**：有限色阶、明确阴影边界与描边；**不要写实材质、不要厚涂、不要渐变过渡**。
- **地面 / 图标 / 机制道具 = 写实偏手绘哑光档**（与既有战场、图标同档）。
- 配色只用这四组：**墨黑 `#0C0E16` / 靛青 `#1E2A3F`–`#2C3E58` / 冷银 `#C9E4F2` / 铜 `#8A6A3C`**；灯焰是**暖金 `#FAE8B0` 只给一点点**。
- 剪影识别点：**高瘦 + 广袖 + 一块垂到地面、边缘像墨迹的披影 + 一手提空铜界灯**；脸是低垂眼、无表情。
- ⛔ 不要与已有 BOSS 同质：**观澜**的银镜碎片/水波涟漪、**离照**的日轮与金焰、**赫连霄**的雷纹鼓盾、**晏无咎**的三彩劫环、**太虚气君**的云烟、**刀客/剑客**的刀光剑芒，一律不要出现在执烛身上。
- 抠图件（拆件、图标、decal）背景必须是**纯洋红 `#E6007E`**，不要阴影投到背景上、不要水印、不要文字。
