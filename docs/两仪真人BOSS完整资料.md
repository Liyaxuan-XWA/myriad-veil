## 三、核心机制：两仪护体（第一战）

### 3.1 护体条

- BOSS 有**仪态**：阳（金白）/ 阴（青黑）。护体值 100，显示在血条下方。
- 削盾渠道（2026-10-27 改版：**同色伤害不再磨盾**；2026-10-28 追加平A 减半）：
  - 同属性命中：护体 **0**（只吃 -50% 减伤，盾一点不掉）；
  - 异属性**功法**命中：护体 **-14**，实际伤害 **+30%**；
  - 异属性**平A**（不带功法的普攻）：护体 **-7**（`SHIELD_CHIP_NORMAL_MULT = 0.5`）——
    破盾的正解是异色功法与防御手段，不能站着点左键；
  - 弹反 BOSS 的招式：护体 **-20**（不看颜色）；
  - 完美闪避 BOSS 的招式：护体 **-20**（不看颜色）；
  - 普通闪避（起手）：护体 -6。
- 同一招式的多段伤害只计一次（0.12 秒内置冷却），避免万剑归宗一帧破盾。
- 护体归零：BOSS 硬直 **1.2 秒**、受到伤害 **+30%**，随后护体 8 秒回满并**翻面**。
- **破盾后 3 秒封窗**：这 3 秒内任何来源（伤害 / 弹反 / 完美闪避 / 起手闪避）都削不动盾，
  护体条变灰、仪态字显示「封」。窗口留给玩家打输出，也防止刚立起来的盾被连秒破。
- **封窗期回盾 ×2**（`SHIELD_REGEN_LOCK_MULT = 2.0`，2026-10-28 定）：回盾从硬直结束就开始，
  锁着的那段按 25/s 抢护体，封窗走完时盾已回到 **~45%**（旧值是 22%），之后退回 12.5/s。
- 二阶段：护体回满 6 秒、破盾硬直 0.9 秒、受伤 **+40%**；破盾必翻面。

### 3.2 为什么第一战不需要两仪功法

- 颜色只由**伤害类型**决定（物理 = 阳、法术 = 阴），跟有没有两仪功法无关；
- 纯物理玩家：等盾翻到**阴**再用普攻 / 物理功法磨，或者直接弹反它、完美闪避它 —— 防御手段震盾不看颜色；
- 纯法术玩家：同理，等盾是**阳**时输出，或靠防御手段震盾；
- 混合 build：任意时刻都握着一半的削盾效率，破盾最快。
- **同色期间硬打不会掉盾**，这是这版改动的核心考点：读色，而不是无脑堆 DPS。
- 唯一被硬卡的风险是「玩家只有一种属性 + 不会弹反 / 闪避」；所以封窗与翻面节奏要保守，实机验证见 §十。

### 3.3 BOSS 的应对（不能逃课）

| 玩家的行为 | BOSS 的应对 |
|---|---|
| 只用一种属性 | 同色打它**一点盾都不掉**，只能等翻面或靠弹反 / 完美闪避震盾；「两仪倒悬」架招还吸收同属性伤害并反击（异属性可打断） |
| 贴脸 | 「焚脉掌」近身扇形 + 「太极崩」压场 |
| 拉扯 / 跑远 | 「阳关三叠」三段突进 + 「阴风蚀骨」封路 |
| 龟缩 / 回血 | 「阴蚀」持续伤害（回血压力）+ 太极崩 |
| 带召唤物 | 「阴风蚀骨」范围清场 + 「阴阳双鱼」多目标 |

### 4.1 招式与机制的联动

- **两仪转**：护体低于 35% 时使用，翻面重置玩家的属性优势。**0.6 秒前摇打不断**（改版后它必定转成），玩家这段时间的收益只有减伤后的伤害与挂印 / 攒势，不能指望把转掐掉。
- **两仪倒悬**：玩家连续同属性 3 次时使用。同属性伤害被吸收，异属性伤害打断并破盾。
- **太极崩**：二阶段解锁；护体存在时也会用，作为压场手段。长前摇是玩家的输出窗口。
  被打中除了高伤害，还会**眩晕 2 秒**（`debuff_on_hit = "stun"`，只写在 boss{} 里 —— 玩家的太极崩不会反过来晕 BOSS）：
  2 秒内不能移动 / 攻击 / 闪避 / 弹反 / 施法，守势与翻滚会被当帧打断。**拉不出圈 = 挨打 + 罚站**，这是它二阶段最痛的一记。
- **阴阳双鱼**：中距离核心；同时考核弹刀与闪避，是「两种防御都要会」的教学招。
  两枚弹**沿反相的正弦横移**（摆幅 54 px、每秒 1.05 个周期，数据在 `form_yinyang_fish` 的
  `swim_amp` / `swim_freq`，两侧共用）→ 阳先摆左、阴先摆右，飞行途中互相交叉两次再对调侧别，
  看着就是两条鱼交错游过来。旧的 ±7° 散射已删（`spread` / `interval` 归零）：
  散射越远越开、远程容易打空，横移的平均航线始终压在瞄准线上（到 520 射程时偏离仅 ~22 px）。

## 五、行为树

```
每轮收招后：
  1. 若玩家连续同属性 ≥ 3 次 → 两仪倒悬（高优先）
  2. 若护体 < 35% 且两仪转冷却好 → 两仪转（翻面）
  3. 按距离 / 玩家近期行为 / 冷却 / 重复惩罚评分选招
  4. 二阶段：太极崩进入候选，护体回复更快

距离档（到本体边缘）：
  ≤ 150：焚脉掌（权重 3.0）、太极崩（P2，权重 1.8）、两仪倒悬（条件）
  150~280：阴阳双鱼（2.4）、玄冥指（2.2）、阳关三叠（2.0）
  280~480：阳关三叠（3.0）、玄冥指（2.0）、阴风蚀骨（1.8）
  > 480：阳关三叠（3.5）、阴风蚀骨（2.2）

玩家近期行为：
  - 连续同属性 ≥ 3 → 两仪倒悬 +4
  - 最近 5 秒内移动距离 > 600（拉扯）→ 阳关三叠 +2、阴风蚀骨 +1
  - 最近 5 秒内贴脸时间 > 60% → 焚脉掌 +1.5、太极崩 +1
  - 附近有友军召唤物 → 阴风蚀骨 +2、阴阳双鱼 +1

重复惩罚：同一招连续两次 -3，连续三次 -6；平局随机抖动 0.6。
```

### 5.1 弱点与反制

| 弱点 | 玩家如何利用 | BOSS 如何反制 |
|---|---|---|
| 破盾后 1.2 秒硬直 + 3 秒封窗 | 硬直 1.2 秒受伤 +30%，爆发放在这一下；封窗期专心打，不用管盾 | 回盾从硬直结束就开始，**封窗期按 25/s 双倍抢护体**（8 秒回满），封窗走完时盾已回到 ~45%；翻面重置颜色；出硬直可能立刻接倒悬架招 |
| 两仪转 0.6 秒前摇 | **打不断**，只能读色：转完就是新颜色，把手里的异色招留到转后 | 护体低时优先用；转完立刻有 12 秒冷却，这段时间是它的空窗 |
| 两仪倒悬怕异属性 | 切换属性 / 用混伤招式 | 玩家切换后，BOSS 会跟着翻盾，逼玩家继续切 |
| 太极崩前摇 1.2 秒 | 拉出圈后反打（圈半径 260，命中会眩晕 2 秒） | 用阴风蚀骨封路，逼玩家在圈内多待 |
| 阳关三叠可弹 | 弹中任一段断连 + 震盾 | 第三段伤害最高，BOSS 会用前两段骗弹 |

## 六、玩家侧：两仪势（打完 BOSS 后的奖励层）

### 6.1 解锁条件

- 玩家学会任意一门带 `yinyang` 标记的功法（塔第 4 层奖励池）后解锁。
- **第一战不显示势条、不参与任何数值计算**；打完 BOSS 在塔里学到功法后才出现。
- **被动「负阴抱阳」决定的是「谁能参与阴阳」**（2026-10-27 用户定稿，全项目第一门被动功法）：
  - **没戴**：只有两仪真人掉落的八门功法自己算阴阳 —— 逆式增伤、叠势、挂印、引爆全部照常；
    普攻与其他功法（刀痕、剑意、虎妖五门…）一律原样伤害，不叠势、不引爆；
  - **戴上**：阴阳这套语言推广到**所有伤害来源** —— 普攻与任何功法都算颜色、吃逆式 +20%、
    还能引爆目标身上的印。⚠ 只有**主动出手的命中**能叠势 / 翻面；后续触发只吃增伤与逆印结算。
    代价是占唯一的被动槽（2026-10-30 起被动只能带 1 门）。
  - 门禁认 `SkillDB` 的 `passive_effect = "yinyang_stacks"`（`player._yinyang_universal()`
    + `_is_yinyang_skill()`），不在代码里硬比 skill_id。
  - **覆盖范围（2026-10-28 修）**：普攻 / 其他功法 / **阵旗 / 气环 / 刀痕**等玩家来源的直接伤害统一走
    `player._deal_direct_damage()` → `_yinyang_modify_damage()`；后者带 `can_stack` 参数：
    主动技能命中传 true（阵旗 burst / line / pull、气环 wave / spin / burst / ward、封阵第一跳），
    后续触发传 false（旗自动剑气、环身气、刀痕、封阵后三跳）。false 时只吃逆式增伤 / 势层加成 / 逆印结算，
    **不加层、不翻面、不消耗「必定逆式」**。⚠ 主动命中仍只有**逆式（异色）**才叠层；全物理 build 必须带一门
    阴属性法术来交替，否则第一发起势后所有物理命中都是顺式、不会再涨。
- **头顶势条 = 三枚阴阳玉佩**（`scripts/ui/mechanic_pips.gd`，`MechanicPips`）：
  点亮几枚 = 几层势；玉佩颜色 = 当前仪态（阳金 / 阴青，色值直接取 `DebuffDB` 的阳印 / 阴印，
  与 BOSS 头顶那两个标记同一份色）；两仪转挂上「必定逆式」时右侧亮一个「逆」字。
  尺寸：玉佩半径 6.5、间距 4、行高 17、徽记字号 11（整体比初版小约三成）。
- **没有产势来源就不摆空槽**（`player._yinyang_source_equipped()`）：
  戴了被动 → 普攻也算色 → 一直有来源、一直显示；没戴被动 → 要求主动槽（Q/E/R/T）里装着
  **会算颜色**的两仪功法 —— 只带两仪转（中性）与太极崩（混伤）这两个「只吃不产」的、
  或者压根没装两仪功法时，势条整条隐藏，不留三枚灰格子。
  「谁能产势」判定在 `SkillDB.builds_yinyang_stacks()`：两仪 + 主动 + polarity 不是 neutral/mixed。
- **位置与扩展**：玉佩挂在玩家头顶的「机制徽记带」（`MechanicHud`，一个 `ALIGNMENT_END` 的
  VBox，预留两行 36 px、宽 128，顶边 y = −110）。以后新机制（剑意格、刀痕计数…）调
  `player.add_mechanic_row(control)` 就会自动排在上一行，不用再各找位置。
- **文案落点（改数值只改一处）**：两仪势的数字全在 `SkillDB` 的 `YINYANG_*` 常量里，
  `player.gd` 的 `YINYANG_*` 只是引用。功法库的两仪分组顶部挂规则卡（`SkillDB.get_yinyang_rules_text`），
  每门功法的详情由 `_yinyang_texts()` 现算本门颜色 / 逆式收益 / 挂什么印 / 引爆条件；
  印记与阴蚀 / 重伤的效果文字统一由 `DebuffDB.effect_text()` 生成（图鉴状态模块与功法库共用同一份）。
  图鉴 BOSS 卡按模块显示：专属机制（简述 + 要点，**不写数值**）· 状态（buff / debuff 讲清楚，
  负面从它招式表的 `debuff_on_hit` 现查）· 属性 · 招式 · 掉落 · 可感悟功法（只列名字与风味，
  机制说明的唯一来源仍是功法库）。八门 `desc` 一律退回纯风味，不再手写数值。

### 6.2 两仪势规则

- **仪态**：物理 = 阳，法术 = 阴；取玩家最近一次命中的伤害类型。
- **逆式**：用与当前仪态相反的招式命中 → 伤害 +20%、势 +1、仪态翻面。**势条为空时第一发任意属性都算逆式起势**（+1 层并定色），所以物理开局的第一发也能起势；之后才按相反色交替。**两仪功法自己随时如此**；普攻与其他功法要吃到这套结算，必须佩戴被动「负阴抱阳」。
- **顺式**：同属性命中 → 不叠势（仅限势 ≥1 时；空条第一发已按起势处理）。
- **势的上限**：3 层；每层 +2% 伤害（任何伤害）。逆式那一发把自己新叠的这层也算进去（1.2 × 1.02）。
- **势的消耗**：装备「太极崩」时，释放消耗全部势：每层给太极崩 +0.5 物理 / +0.5 法术系数；3 层额外造成 1 秒硬直并同时挂阳印 + 阴印。
- **印**：两仪功法命中时挂对应印（阳印 / 阴印，5 秒）；用相反属性命中会引爆对方的印，额外造成该次伤害的 25%，并移除印。
- **两仪转**：翻自己的仪态；移除「阴蚀」；若势 ≥1，消耗 1 层使下一招必定按逆式结算（4 秒内有效）。
- **两仪·倒悬**：守势 1 秒内，与当前势**同色**的攻击被全额奉还（免伤、势翻面、+1 层）；**异色**打进来则守势碎掉、这一发的反击不斩出、多受 30%。奉还一次后仪态立刻翻面，所以**同色连打第二下就破势** —— 想连续奉还，攻击必须一阴一阳地来（与「弹刀不看属性、只看时机」分工明确）。
- **势的来源只有三个**：逆式命中（含空条起势的第一发）、两仪转换 1 层「必定逆式」的预备、倒悬奉还。三者都不需要新 UI，读同一条势标签；标签本身只在佩戴被动时出现。

### 6.3 八门功法（2026-10-27 追加：由 4 门扩到 8 门）

| 功法 | 属性 | 形态 / 消耗 | 数值 | 作用 |
|---|---|---|---:|---|
| 阳诀·焚脉掌 | 阳 · 物理 | 近战扇形 170/150° / 1 精力 / 3s | 1.6 倍物理 | 站桩阳伤；挂阳印；逆式 +20% |
| 阴诀·玄冥指 | 阴 · 法术 | 直线 340/22° / 22 灵力 / 4.5s | 1.75 倍法术 | 远程阴伤；挂阴印 + 阴蚀 6s |
| 阳诀·三叠踏 | 阳 · 物理 | 扇形 150/90° ×3 段，每段前冲 180（空场共 540）/ 2 精力 / 7s | 0.72 倍物理 ×3 | 阳系最远的贴脸位移；踏中补阳印。**踏上人即停**（冲刺被身体挡住，实测贴 260 处的 BOSS 只走出 198），与破步同一套手感 |
| 阴诀·蚀骨风 | 阴 · 法术 | 自身圆形 180，三跳（间隔 0.45s）/ 20 灵力 / 11s | 0.55 倍法术 ×3 | 不须瞄准的贴身领域；逐跳刷新阴蚀与阴印 |
| 两仪·双鱼 | 阳 + 阴 | 双弹 520，沿飞行轴前后错开 46（阳在前、阴在后）+ 反相横移交叉（摆幅 54）；阳弹走物抗、阴弹走法抗 / 26 灵力 / 9s | 0.85 物理 + 0.95 法术 | 两色连走，阴态起手最多叠 2 层势；阳印自带引爆 |
| 两仪·倒悬 | 阳 · 物理 | 守势 1s → 扇形 190/120° / 2 精力 / 12s | 0.95 + 每次奉还 0.35 | 用防御叠势；同色奉还、异色破势 |
| 太极崩 | 混伤 | 圆形 260 / 26 灵力 / 20s | 1.2 物理 + 1.8 法术，每层 +0.5/+0.5 | 消耗势；3 层硬直 + 双印 |
| 两仪转 | 无 | 自身 / 12s / 无消耗 | — | 翻仪态、清阴蚀、蓄逆式 |
| **负阴抱阳**（被动） | 无 | 被动槽 1 格 / 常驻 | — | **戴了才叠势**：逆式与奉还才真的势 +1；不戴则势恒为 0 |

> 快捷位只有 Q/E/R/T 四格，八门轮着挑 —— 这是「挑功法」的意义所在。
> 被动只能带 1 门：「负阴抱阳」占这一格 —— 想要势的成长引擎，就得放弃其它被动（如「气环·回息」「盗火者」）。塔第 4 层感悟池共 9 门 = 八式 + 这一门被动。
> 推荐搭配：**输出型**掌 + 指 + 崩 + 转；**贴脸型**三叠踏 + 指 + 崩 + 转；
> **领域型**蚀骨风 + 掌 + 崩 + 转；**反制型**倒悬 + 双鱼 + 崩 + 转。
> 任意物理 / 法术招式都能叠势，所以不会「没抽到就玩不了」。

## 八、美术方案

### 8.1 顺序

1. 掉落物图标：两仪玉玦、玄素道袍、两仪玄石、两仪真人元魂、两仪令、太极盘；
2. BOSS 形象：黑白云纹道袍、半黑半白长发、背后太极环、拂尘；先出侧身定妆图，再拆 rig；
3. 地图：太极石台 + 云海；
4. 技能特效：金白（阳）/ 青黑（阴）双色，内部统一，但与刀客的炽金、剑客的霜青、虎妖的暗金赤煞区分；
5. 入场卡：640×960，动态侧身，太极环在背后，拂尘前指。

### 8.2 骨骼约定

- 朝向一律朝右；朝向只靠 `Visual.scale.x`。
- 7 套动作原型：`palm` / `finger` / `triple` / `wind` / `fish` / `counter` / `collapse`，外加 `flip`。
- 关节处用圆盘切，避免白缝；袍摆单独一件，不跟上臂粘连。
- 动作与 `hit_shape` 严格对应：扇形抬手、直线递指、圆形下压、突进前送。

### 8.3 特效约定

- 阳：金白、偏暖、向外扩散；阴：青黑、偏冷、向内收束。
- 不用折线 / 硬边圆环；范围 = 判定；高频精简；残留特效要流动。
- 技能特效走 `ArtDB.SKILL_FX` + `SkillFx`，BOSS 专属演出走独立节点。

### 8.4 特效与判定对齐（2026-10-28 重做）

用户要求「特效要和技能名称、效果、出伤时机与范围吻合」，本轮修的是**结构性错位**（观感仍需实机看）：

| 问题 | 原因 | 处理 |
|---|---|---|
| 八式特效比判定晚 0.6~1.2 秒 | 走了玩家版 `SkillFx.play()`，它会**再等一遍前摇** | 改走出手帧 `SkillFx.play_at_strike()`（`domain_boss_02._play_yinyang_fx`），并去掉手工挂的 anchor |
| 所有近战特效比躯干中心低 55 px | `SkillFx._body_center` 只查私有名 `_body_center`，查不到就退回 (0,−30) | 先读公开的 `body_center()`，三只人形 BOSS 的特效一起归位 |
| 阴风蚀骨的领域圈画在 BOSS 脚底（差 180+ px） | `_strike()` 对地面招无条件把中心拉回施法者，丢掉了传入的 origin | 加了 `_has_origin`：给了 origin 就用 origin（风场落在目标点，圈 = 三跳判定圆） |
| 三叠踏起手先白播一次特效，实际是 4 个特效对 3 次判定 | `_begin_triple` 起手就播 | 起手不播，只在三段冲到头时各播一次（3 : 3） |
| 破盾**完全没有特效** | `fx_yinyang_shield_break` 在 ArtDB 里根本不存在，查不到就静默返回 | 新增条目：冲击波 + 裂纹 + 翻面太极环，震屏 9.5 |
| 「阴阳易位」看不出翻面 | 只有泛用的旋转风 | 新增 `taiji` 开关：金色阳半环 + 青色阴半环反向旋转；两仪转 / 太极崩 / 破盾三处启用，圆形招的环径 = 2× 判定半径 |

范围对齐沿用既有机制：`SkillFx._radius()` 对直线 / 圆形直接取判定半径，扇形张角取 `form.angle`；
新增的太极环也按 `_radius()` 推直径，所以「看到的圈」就是「挨打的圈」。

### 8.5 阴阳八卦视觉语言（2026-10-28 第二轮：解决「分不清是哪招、跟别家 BOSS 一个质感」）
