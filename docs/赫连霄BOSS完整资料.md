# 赫连霄 · BOSS 完整资料

> 赤霄界第 1 位（万界塔第 7 层）｜2026-10-29
> 机制：**判词 · 天律** —— 不造地面物、不做护盾/层数，而是给玩家立一条**行为禁令**：
> 违律引雷、守律顺天。玩家学会后可以把律下给 BOSS，让它「少走 / 收手 / 少遁 / 少站」。
> 与已有五套机制的区分：刀痕（地面标记）、剑意（自身层数）、两仪护体（护盾极性）、
> 三色阵旗（棋盘/连线）、气环（环绕资源）—— 判词改的是**这一段时间该怎么打**。

## 一、身份与形象

- 名号：**雷部判官 · 赫连霄**；称谓「执劫之人」。
- 形象：焦金甲 + 赤黑官袍，背一面**青铜雷鼓**，右手执墨黑铁笔；脸覆半张雷纹铜面具，双目雷紫；
  头戴低矮赤金判官冠；**悬空半尺**，脚下雷弧缠绕；下摆焦黑、边缘透出雷紫电光。
- 与前面六只的区别：刀客（布衣刀）/ 虎妖（兽）/ 剑客（白衣剑指）/ 两仪（太极光环）/
  定阵（盲眼阵师、实体旗）/ 气君（无腿气身、气环）—— 判官是**甲胄 + 鼓 + 铁笔**的雷部神官，
  轮廓最“重”，也是唯一**以规则为武器**的 BOSS。
- 色板：赤金 / 焦黑 / 雷紫。场地：焦土 + 雷纹铁柱 + 中央雷印（暗紫地面纹样）。

## 二、核心机制：判词 · 天律

### 2.1 立律

- BOSS 的「宣判 / 判词·天律」在**前摇第一帧**选定一条判词（招名飘字同时出现），
  出手时落到玩家身上。判词按玩家**最近 1.5 秒的行为**自动选择：
  - 最近闪避过 → **禁避**
  - 最近打中过 BOSS → **禁攻**
  - 最近移动过 → **禁行**
  - 否则站定 → **禁立**
- 四条律（持续 **5 秒**，二阶段 **6 秒**）：

| 判词 | 禁止的行为 | 违律落雷 | 提示 |
|---|---|---|---|
| **禁行** | 累计移动 **110 像素** | 0.80× 攻击 | 「站住！」 |
| **禁攻** | 每次打中 BOSS（普攻/功法） | 0.90× 攻击 | 「收手！」 |
| **禁避** | 每次闪避（**弹反不算**） | 0.80× 攻击 | 「别闪！」 |
| **禁立** | 原地不动 **0.9 秒**起，每 0.9 秒落一次 | 0.70× 攻击 | 「动起来！」 |

- 违律**不结束判词**：只落一道雷（0.25 秒预警圈，可走位躲开），并给 BOSS **雷势 +1**。
  玩家可以顶着律硬打，代价是喂大它的九霄。
- **守律**：一条判词从头到尾一次未犯 → 玩家获得 **「顺天」6 秒**（攻速 +20%、移速 +10%），
  同时 BOSS **雷势 -1**。
- **抗辩**：宣判是一记**物理笔锋**（直线 320 / 宽 56），可以弹反。弹反成功 →
  这条判词当场撤销、BOSS 僵直 0.9 秒、雷势 -1。
- **雷势**（BOSS 资源，0~3，头顶三枚雷印）：违律 +1；被弹反 / 玩家守律 -1；
  「九霄·雷罚」消耗全部，每层多一道雷柱。
- **二阶段专属层**：
  1. **双律**：宣判一次落两条不冲突的律（禁行+禁攻 / 禁行+禁避 / 禁攻+禁避 / 禁立+禁避 / 禁立+禁攻），
     持续 6 秒；禁行+禁立是死锁，永不同时出现。
  2. **雷牢·天罚**进入常规选招：锁定脚下、1.2 秒收拢的雷环；收拢时仍在圈内 → 1.5× + 眩晕 1 秒。
     与「禁避」同场时，玩家要在「吃雷环」与「违律」之间选。

### 2.2 弱点与反制

1. **宣判可弹反**：弹反直接废掉一条律，并削雷势 —— 这是最干净的反制。
2. **喂行为**：判词按最近行为选，玩家可以主动诱导下一条律：
   - 想让它禁攻 → 先让它打你一下；
   - 想让它禁避 → 先逼它雷遁/突进；
   - 想让它禁行 → 拉远让它追；
   - 想让它禁立 → 等它站桩蓄力/吐纳。
3. **顶律硬打**是合法选项：吃雷换输出，但会喂高雷势；雷势高时九霄更痛。
4. **不要站桩**：禁立 + 定刑是最常见的惩罚组合；看到「动起来！」就保持移动。

## 四、玩家侧（八门主动 + 一门被动全部可学）

玩家侧的「判词·天律」读取目标最近 1.5 秒的行为，**一次自动下两条不同的律**。
所以玩家的操作不是“选律”，而是**先喂行为、再判词**；判词同时是伤害来源和行为控制。

- **双律**：主律/副律各自计时、各自记违律；目标同时挂两条 debuff，头顶两行判词。
- **雷势**：目标每次违律 +1；「聚雷·引霆」完成 +1；上限 3；「九霄」消耗全部。
- **满雷势 · 雷威**：普攻间隔 ÷1.3（攻速 +30%），且每一次普攻都会在身前 320 内最近目标处引落一道协同雷击（法术 ×0.5，落点 62 内有敌一起吃；计入雷积·震魂）；雷势未满时两项都不生效。
- **被动「雷积·震魂」**（塔 7 层感悟池）：每只敌人独立累计 9 次雷击 → 眩晕 0.5 秒并清零；每消耗 1 雷势 → 全主动功法 CD -1 秒。所有 `thunder` 功法 / `calamity_tag=thunder` / `metal` 元素命中都算雷击；满雷势协同雷击、五阵旗每秒雷击也计入，普攻本体与攻旗火轰击不算。眩晕期间目标头顶出现三颗金色绕转星（`StunFx`，玩家 / BOSS / 野怪共用）。
- **HUD**：
  - 头顶机制徽记带新增**三枚雷印**（`ThunderPips`），点亮数 = 雷势；学会任意一门判官功法后显示。
  - 新增**判词横幅**（`VerdictBanner`）：身上有 BOSS 的判词时显示「判词·禁行 3.2s」/「判词·双律 3.2s」；
    没有判词时**整条隐藏**。BOSS 施加的四条判词同时进 debuff 栏，效果文字由 DebuffDB 现算。
- **玩家给 BOSS 的判词**：目标头顶出现雷印 + 名称 + 倒计时；BOSS AI 会按律改变行为：
  - 禁行 → 先站住一小段，优先原地招；
  - 禁攻 → 收手 1.4 秒；
  - 禁避 → 放弃雷遁；
  - 禁立 → 绕着你侧移，不敢站桩。
- **顺天**：守律 6 秒攻速/移速提升；BOSS 被弹反/玩家守律时雷势 -1。
- **命中门禁**：判词/定刑/锁雷/九霄/雷牢在目标不在射程内时不扣资源、只飘字。

## 五、行为树

0. **宣判优先**：无判词在身 + 宣判就绪 + 玩家在 380 内 → 宣判（每 9~10 秒一次，不会无缝连下）。
1. **执刑**：玩家带判词 + 定刑就绪 → 定刑（带律目标 +50%）。
2. **雷势 ≥2** + 九霄就绪 → 九霄（消耗雷势）。
3. **二阶段** + 雷牢就绪 + 玩家在 520 内 + 玩家带「禁避」→ 雷牢（逼你在吃雷环/违律里选）。
4. **残血 / 雷势低** + 聚雷就绪 → 聚雷（可打断，最大输出窗）。
5. **贴脸** → 雷鼓（击退）；**中距** → 锁雷 / 定刑；**远距** → 雷遁贴人 / 定刑。
6. 其余按距离评分 + 连携（判词→定刑 +2.0；雷遁→雷鼓 +1.4；锁雷→九霄 +1.0）；
   同招二连降权、三连封禁；0.3 秒决策节流；打不到就不出招（命中门禁）。

**被玩家下律后的应对**（关键）：

| 玩家下的律 | BOSS 的行为响应 |
|---|---|
| 禁行 | 先站住 1.4 秒，优先定刑/锁雷/九霄等原地招；必须接近时用雷遁，认一次违律 |
| 禁攻 | 收手 1.4 秒，先走位/拉开；被逼急才出手（吃一道雷） |
| 禁避 | 放弃雷遁，改用走路贴近；其余招照常 |
| 禁立 | 绕着目标侧移，保持移动；不再原地长蓄力 |

**反制与逃课检查**：
- 贴脸 → 雷鼓击退 + 锁雷；一直拉远 → 雷遁贴人 + 定刑（指定落点）。
- 一直爆发 → 更频繁宣判「禁攻」，逼你停手；停手它就聚雷攒势。
- 一直跑 → 「禁行」+ 定刑；一直站桩 → 「禁立」+ 定刑。
- 无必须特定功法的门；无不可躲的全屏秒杀；所有大招都有预警/安全缝。

## 六、数值（结丹玩家反推，2026-10-29 重定）

旧值 5600 血 / 34 攻把「物攻 ~100」误当成了每秒输出，实际普攻是每秒 2.5~3.2 刀，
5600 血在 20 秒内就被打穿、34 攻单下只掉 5~13% 血。本次按结丹玩家的实测面板反推。

**玩家标准档（结丹初期 · 灵器 +6，探针实测）**

| 项目 | 数值 |
|---|---|
| 气血 | 279（带法宝/更高强化约 300~356） |
| 物攻 / 法攻 | 99 / 66 |
| 灵力 / 回灵 | 189 / 16.9 每秒 |
| 物抗 / 法抗 | 33（减伤 24.8%）/ 42（减伤 29.6%） |
| 攻速 / 普攻间隔 | +19.5% / 0.293 秒 |
| 三段一轮 | 1.0 秒，99 + 99 + 178.2 = 376.2 |
| 常态普攻 DPS | 2.5 刀/秒 ≈ 313；3.2 刀/秒 ≈ 376（功法施法会挤占普攻，实际更低） |

**反推过程**

1. **血量**：按真人 2.5 刀/秒、走位与躲招占 25~40% 计算，有效输出 190~235/秒。
   目标 TTK 60~80 秒 → 11,400~18,800 血，取 **13,000**。
   实测预期：标准档 55~69 秒，熟练满速 35~45 秒，结丹后期宝器 +10 约 20~30 秒。
2. **攻击**：目标「结丹初期吃 3~5 下大招收命」（279 血、过抗后每下 55~95）。
   雷鼓/定刑/雷牢三类主招反推得 80~95 攻，取 **90**。
   过抗后：判词 37（13%）/ 定刑 67（24%）/ 雷鼓 68（24%）/ 锁雷 41（15%）/
   雷遁 58（21%）/ 雷牢 95（34%）；二阶段 ×1.25 后雷牢 119（43%）。
3. **聚雷打断**：门槛改为 **2.5% 最大气血（≈325）**。原 8% 是按 5000 血写的，
   血量抬到 13,000 后 8% = 1,040，1.4 秒引导内根本打不断，会退化成白送雷势；
   2.5% 下标准档 1.4 秒普攻（约 346）刚好能打断，慢手需要补一门功法。

- BOSS：**13,000 血 / 90 攻** / 移速 **92·112** / 二阶段伤害 ×1.25 /
  受击三球 `(0,−50) r30 · (0,−4) r44 · (0,44) r38`（外接半径 80，本体厚度 44）。
- 塔血量成长（11 次起 ×2）后为 26,000；结丹后期 600 DPS 下约 40~60 秒。
- 调节单点：`COOLDOWNS`、判词时长（`verdict_time` / `verdict_time_p2`）、
  违律系数 `LAW_COEF`、雷势上限 `MAX_LEI`、九霄柱数/半径、雷牢半径/收拢时间。
