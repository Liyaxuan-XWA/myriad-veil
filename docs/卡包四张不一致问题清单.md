## 1. 离照 `boss_03_b` —— 四张里出现三套角色设计

| 对比 | 问题 |
| --- | --- |
| 卡1 华彩 ↔ 卡2 普通 | **不是同一张插画**。① 脸型：卡1 圆润年轻，卡2 瘦长成熟；② 发冠：卡1 小型双叉冠，卡2 高束金冠；③ **日轮盘**：卡1 紫红盘 + 放射纹，卡2 金色盘 + 八角轮辐；④ 腰带：卡1 金边窄，卡2 金带宽且外翻；⑤ 持镜手：卡1 左手抬至胸前，卡2 右手前伸低举；⑥ 缩放：卡2 人物明显更大更近 |
| 卡3 纯华彩 | 角色层跟卡1 同源 ✓，但镜盘仍是紫色 → 与卡2 的金色直接冲突 |
| 卡4 纸本水墨 | **第三套**：披发（前三张全部束发戴冠）、脸侧向、袍色偏黑、镜盘变银灰轮辐 |

核心道具日轮盘在四张里有 **紫 / 金 / 紫 / 银** 四种样子。日轮盘是他「引燃 / 逐日步」的视觉锚，
玩家从图鉴认成金色，进卡包看到紫色，等于机制提示被拆掉。

**需要重做**：卡2（普通卡）与卡4（水墨），统一到卡1 的角色层。

## 2. 青岚·古猿 `world_core_lianqi` —— 两套，差到像两只怪

| 组 | 设计 |
| --- | --- |
| 卡1 华彩 + 卡3 纯华彩 | **白毛**猿、**直立行走**、肩与臂覆圆形石甲 + 苔藓、侧面朝右 |
| 卡2 普通 + 卡4 水墨 | **墨绿岩石**猿、**四足撑地**、站在石台上、正面偏侧 |

毛色、姿态、石甲位置、体型比例全不同。
另有一处独立问题：**卡1 的背景是俯视草地**，而角色是平视侧面 —— 人站在从天上往下看的地面上，透视矛盾。

## 3. 云隐·苍角 `world_core_zhuji` —— 两套，镜头和角色都不同

| 组 | 设计 |
| --- | --- |
| 卡1 华彩 + 卡3 纯华彩 | **俯视**镜头、身后石环闭合成完整圆圈、体型偏小、**角是粉色枝状** |
| 卡2 普通 + 卡4 水墨 | **平视**镜头、体型更大、站在石台上、**角是灰褐枯枝色**、无粉色 |

## 4. 赤金·火麟 `world_core_jiedan` —— 两套，且分裂方式最难受

| 组 | 设计 |
| --- | --- |
| 卡1 华彩 + 卡3 纯华彩 | 红鳞、**两根向后弯的金角**、鬃毛收束、后腿抬起、图案化渲染 |
| 卡2 普通 + 卡4 水墨 | **多叉灰白鹿角**、鬃毛蓬松、写实渲染、峡谷日落背景、行走姿态 |

分裂方式是「华彩两张一套 / 普通+水墨两张另一套」，而**普通卡是玩家最先拿到、最常看的那张**，
并排看时冲突最直接。

## 5. 幽冥·石犼 `world_core_shihou` —— 前三张一致，水墨卡换脸

卡1 / 卡2 / 卡3 同一设计 ✓（蒙眼石带、胸口圆形青色光核、尾端石球、正侧朝右）。

卡4 纸本水墨漂了：
- **蒙眼石带变成露脸龇牙**（他的身份记号就是蒙眼）

- 视角从正侧变成左前 3/4

## 6. 晏无咎 `boss_03_c` —— 同源，两处工艺问题

3. 卡4 水墨左下那条橙色环被换成小圈，三环的数量与位置与前三张不同。

## 修复结果（2026-11-02 补，方向与我原来的判断相反）

**我上面把根因写错了。** 分裂的不是「普通卡 vs 华彩卡」，而是**华彩三层根本不该用战斗素材**：

| | 标准（赫连霄及之前） | 这四位我当时做的 |
| --- | --- | --- |
| 角色层 `_art` | 从**图鉴原图**图生图抠出来 | 从 `assets/characters/boss/*.png` 战斗透明立绘重新贴 |
| 背景层 `_bg` | 从**图鉴原图**图生图去掉人物补景 | 游戏内空场截图 `output/core_holo_bg_*.png` |

所以卡2 / 卡4 才是对的一（都源自原图），**卡1 / 卡3 是错的那两张**。
「古猿卡1 俯视草地 vs 平视角色」也不是原图的毛病 —— 那个草地根本不是原图的背景，是我拿游戏地面贴图凑的。

已按原图重出三层并落地：

## 追加：照影界三位的分层结构缺陷（2026-11-02 晚，用户实机截图报的观澜卡3）

这不是「两张卡长得不一样」，是**分层本身就是错的**，比一致性问题更隐蔽：

| 症状 | 根因 |
| --- | --- |
| 观澜 卡3 纯华彩整张糊成白紫一片，过曝 17.8%（同档其他卡 ≤0.7%） | `boss_04_lines.png` 是 **RGBA、RGB 恒为纯白、遮罩在 alpha 里**，而 shader 读的是 `texture(line_tex, a).r` → 整卡都被当成蚀刻线，legacy bloom 八个采样点一路积到饱和 |
| 观澜 / 执烛 / 叠纸 的 卡1 与 卡3 几乎是同一张图（MAD 4.5 / 5.1，标准 16.3） | 三位的 `_art` 与 `card_boss_*.png` **MAD=0.0** —— 等于把整张普通卡塞进角色层，alpha 全 255，shader 里 `base*(1-ch.a)` 恒为 0，`_bg` 永远不显示，「拖动时背景与角色分层错动」这条直接失效 |

**修法**：照上面同一套口径 —— 从原图图生图出「洋红隔离角色层」+「去人补景背景层」，
线条层的遮罩从 alpha 搬回 R 通道（`split()[3]` 转 L）。

- 观澜母本：`vibe_images/guanying_card_art_v2_…`（1024×1536，与卡面同构图；
  另一张 `guanying_card_art_…` 是白发旧版，已废弃，MAD 49.7）→ 合成 MAD 22.2，卡3 过曝 17.8% → **0.3%**
- 执烛：地面那道影子是他的机制身份（投影·身外之影），**必须进角色层而不是背景层** ——
  否则纯华彩（无背景）卡上只剩一个人，影子丢了。最终：`_art` = 人 + 界灯 + 影子连成一整块
  （alpha 覆盖 22%），`_bg` = 无影子的空厅（两道影子同时存在会在拖动时重影）。
  合成 vs 原图 MAD **5.3**；卡1 vs 卡3 MAD 17.3（该不同）；卡3 过曝 0.2%。
  新背景顺带把去水印糊斑清掉了（卡2 仍留，那是原卡面文件）
- 叠纸：卡面本来就是我程序画的占位图，改 `tools/gen_diezhu_cards.py` 让它**分别输出场景层和角色层**
  （角色层 = 完整卡面像素 + 人物 alpha），bg 叠 art 与卡面 MAD **0.65**，不用生图
- 复测：卡1 vs 卡3 MAD 观澜 23.3 / 执烛 21.8 / 叠纸 45.9，全部回到标准档；三位过曝均 ≤0.5%

**新增守卫**（`tools/probe_card_assets.gd` 的 `_guard_layers`）：逐位检查角色层 alpha_min 与
线条层 R 通道方差 —— 角色层完全不透明、或线条层遮罩躲在 alpha 而 RGB 恒定，直接报不合格。
已用「把旧坏层临时换回去」验证它确实会红，验完按哈希还原：

```
! boss_04 角色层完全不透明(alpha_min=0.98) → 背景层永不显示，卡1==卡3
! boss_04 线条层遮罩在 alpha 通道而 RGB 恒为 1.00 → shader 读 .r 会把整卡当蚀刻线
```
