## 二、角色设定（定妆图必须满足）

- 中性化道家守门人，面色苍白、半边面具般的平静面孔，长发束起。
- **高冠**：黑漆，正面嵌一枚小金太极，象牙簪横穿。
- **袍**：及膝偏下、**露出靴子**；正中间一分为二 —— 穿着者右半**纯黑**、左半**宣白**，交界处一条**做旧金边**。
- 深色**肩甲/披膊**，上面只有**一处**简单金色浮雕（不要满身纹样）。
- 腰间黑色宽腰封，正面一枚白玉「眼」形饰件。
- 手持**拂尘**（不是太极杖）：长柄 + 一段扫尾，垂在身侧。
- **视角：3/4 侧身朝右**（游戏里所有 BOSS 统一朝右，左向由代码镜像）。
- **细节密度：与刀客 / 剑客同档**（大色块 + 一条金边 + 一处浮雕），禁止繁复刺绣。
