# 万界塔挑战规则

> 一名 BOSS 对应一层；在万界秘境击败该 BOSS → 对应塔层解锁。

## 1. 反复挑战的血量成长（2026-10-21 用户定）

同一层每**通关**一次，下一次挑战的血量上限 +「基础血量的 10%」，最多 +100%（2 倍封顶）。

| 挑战次数 | 血量倍率 |
|---|---|
| 第 1 次 | 1.0（基础） |
| 第 2 次 | 1.1 |
| … | … |
| 第 11 次 | **2.0（封顶）** |
| 第 12 次起 | 2.0（恒定） |

实现：`CharacterData.tower_hp_multiplier()`，常量 `TOWER_HP_STEP / TOWER_HP_STEP_MAX`。
失败重打不涨（只有胜利才 +1）。

**区域核心首领分支（2026-10-30）沿用同一口径**：`core_hp_multiplier(region_id)` ——
每胜一次 +10%，最多 2 倍；次数存 `CharacterData.core_replay[region_id].clear_count`。

## 2. 通关用时纪录（2026-10-22 用户定）

**只有第 11 次及以后的挑战才记录用时**（也就是只记血量翻倍的场次）。

- 阈值常量：`CharacterData.TOWER_RECORD_MIN_CLEAR = 11`
- 前 10 次打完不产生纪录；面板显示「暂无纪录（第 11 次起记录）」
- 纪录只在**更快**时刷新（`tower_best_time[floor]`）
- ⚠ 老存档里已有的纪录会保留，直到被更快成绩刷新

## 3. 无伤通关奖励：50 晶石（2026-10-24 用户定，替换原极速奖励）

**任意一次**全程未掉血通关 → 在选关界面（万界塔面板）可领 **50 锻造晶石**，**每层只能领一次**。

- 判定：`combat_arena._on_boss_died` 读 `player.took_damage_this_battle`；只有 `_apply_damage` 实际扣了气血才置 true（弹反 / 闪避 / 0 伤害不算）。
- 不再与第 11 次挑战或通关用时挂钩；用时纪录仍按第 2 节单独统计。
- 常量：`CharacterData.TOWER_NO_HIT_BONUS_CRYSTALS = 50`
- 状态存 `CharacterData.tower_no_hit_reward`
  （`{ floor:int -> "ready" | "claimed" }`，随存档持久化；旧 `tower_speed_reward` 不迁移）
- 接口：`mark_tower_no_hit_reward(floor)` / `claim_tower_no_hit_reward(floor)`
- UI：`tower_panel` 的层行里，`ready` 显示「领 50 晶石」按钮，`claimed` 显示「无伤奖励已领」
- 旧「10 秒内通关领 20 晶石」规则作废；历史口径见 2026-10-22 记忆。

**区域核心首领分支（2026-10-30）**：分支有**重战记录碑**（重战次数 / 下次血量 / 掉落 / 无伤状态），
但没有领取按钮；第一次无伤通关时**直接发放** 50 锻造晶石并写入
`core_replay[region_id].no_hit_rewarded = true`，每个区域只发一次；
结算字幕显示「无伤通关！+50 锻造晶石」或「该核心的无伤奖励已领」。

## 4. 计时口径

- 计时从进入战斗开始，到 BOSS 死亡结算为止（`combat_arena._elapsed`）
- 只有万界塔战斗入账；位面 BOSS 不记录通关时间
- ⚠ 入账发生在 `BattleResolver.resolve_victory()` **之后**（此时通关次数已 +1），
  所以「本次是第几次挑战」直接读 `get_tower_clear_count()`；改动结算顺序要同步检查这里

## 5. 通关后再战（2026-10-24 用户定）

万界塔挑战成功后按 **C** 可立即重开同一层，不用先回主城。

- 只在**万界塔**生效；位面 BOSS 仍只在玩家死亡后响应 C。
- 感悟面板开着时 C 交给面板处理；若在结算字幕期间按 C，会先 `BattleResolver.confirm_tower_rewards()` 安全收下待确认功法，再重载场景。
- 重开照常结算下一次的通关次数、掉落与无伤状态；**未拾取的掉落会随场景重载消失**。

## 6. 区域核心首领分支节点（2026-10-29 用户定；2026-10-30 升级为完整重战）

击败大世界某区域的**核心首领**后，万界塔里**对应位面**的左侧出现一个分支节点，可重复挑战该首领。

- 解锁：读 `CharacterData.secret_world.core_kills[region_id]`；未击败不出节点。
- 对应位面：按区域的 `realm` 找同境界要求的塔位面（练气 → 凡界 domain_01，筑基 → 冲和界 domain_02）。
- 节点：塔身左侧圆形「战」印 + 区域名 / 首领名 + 「重战 ×N」；一条侧枝连到该位面中间层。
  tooltip 显示已重战次数、下次血量加成、无伤 50 晶石状态；**点击先选中分支**，右侧记录碑展示
  重战次数 / 下次血量 / 掉落 / 无伤状态，再点底部「进入」才
  `BattleResolver.start_world_core(region_id)`（与塔层「先看面板再挑战」一致）。
- 战斗：`SOURCE_WORLD_CORE`，`combat_arena` 用 `WorldEnemy` 按 `SecretWorldDB.get_core_boss(region_id)` 配置核心首领；
  世界敌人置 `standalone`，死亡时额外发 `BossBase.died` 走统一胜利结算（大世界模式仍只发 `world_died`）。
- **挑战次数 / 血量成长（2026-10-30）**：`BattleResolver._resolve_world_core` 胜利时
  `record_core_clear(region_id)`；`core_hp_multiplier` 每胜一次 +10%，最多 2 倍。
  战斗标题 / 入场卡第二行显示「第 N 次 · 血量 +X%」。
- **掉落（2026-10-30）**：每次掉该核心首领登记的装备各一件 + 锻造晶石（首胜 9 / 第二次 6 / 之后 3）。
  晶石掉在地上，走近拾取；不重复首杀材料 / 修为 / 功法。
- **无伤 50 晶石（2026-10-30）**：每个区域第一次无伤通关直接发 50；不写塔层奖励 / 不占塔层领取按钮。
- **华彩卡片（2026-10-30）**：重战第 11 次起为双倍血；赢下双倍血场次 → 卡包「华彩 · 有背景」，
  双倍血无伤 → 「纯华彩 · 无背景」。状态存 `core_replay[region_id]`（`clear_count / no_hit_double /
  no_hit_rewarded`），不写 `tower_progress`、不占塔层号、不产出塔层功法 / 用时纪录。
- 失败：按 `core_<region_id>` 记连败，不影响塔层连败计数。
- 数据扩展：新区域在 `SecretWorldDB.REGIONS` 填 `core_boss_id`，并在 `get_core_boss()` 加映射，即可自动生成节点。

**Why:** 用户要求「当击败某区首领后，万界塔对应的位面会出现一个分支节点，可以进入重复挑战首领」；2026-10-30 进一步要求
「首领在塔里也要有挑战次数：每胜一次加最大血量，双倍血给闪卡、双倍血无伤给无背景闪卡，掉晶石，并给一定次数的 50 晶石奖励」。
核心首领在大世界是一次性击杀，重战入口放在塔里，既保留首杀进度，又给玩家重复挑战 / 刷装备 / 集卡的入口。

**How to apply:** 分支不占塔层号、不写 `tower_progress`、不发塔层功法 / 用时纪录；首杀奖励仍只在大世界击杀时结算；
核心重战的一切状态走 `CharacterData.core_replay`。改区域境界或塔位面映射时同时检查节点落点。

## 7. 塔层掉落清单（2026-11-13 面板展示）

右侧记录碑在「下次挑战」下方新增「本层掉落」段，逐条列出**这一层下一次通关**会掉什么、概率多少。
数据全部现读，不在 UI 里写死：

| 来源 | 内容 | 概率 | 说明 |
|---|---|---|---|
| 投影本体 `DROP_TEMPLATES` | 该 BOSS 的装备 / 材料 | 装备默认 **50%**、材料 **20%**（有 chance 按表） | 塔投影复用本体 boss_id，`_spawn_drops` 的通用分支同样会投这一路 |
| 塔层表 `TOWER_FLOOR_DROPS_DEFAULT` | 锻造晶石 ×N | **100%** | N 跟着「下次是第几次通关」：首通 9 / 第二次 6 / 之后 3 |
| 塔层额外 | 蕴仙髓 ×1 | **5%** | `TOWER_YUNXIAN_DROP_CHANCE`，独立掷骰 |
| 双倍血量场次 | BOSS 元魂 ×1 | **50%** | 第 11 次起（`TOWER_RECORD_MIN_CLEAR`）；行内标「双倍」，未到该场次时在底部预告 |

⚠ 元魂判定用 `CharacterData.tower_hp_multiplier_at(challenge_no)`（该场开打时的倍率），
不能直接用 `tower_hp_multiplier()`：通关结算时 `clear_count` 已 +1，后者拿到的是下一场的倍率，
会让元魂早一场掉。面板与掉落层现在共用 `tower_hp_multiplier_at` 口径。

- 标题右侧写「按第 N 次通关」，晶石数量随 N 变化；
- 未到双倍场次：元魂在段末预告一行；已到双倍场次：元魂直接出现在列表里；
- 区域核心分支的记录碑继续用原来的「重战掉落」文案，不显示塔层掉落段；
- 该段放在「投影功法」之前，条目多时记录碑内部滚动（面板底部挑战键始终可见）。
- 元魂概率常量从 `combat_arena` 的 `SOUL_DROP_CHANCE` 挪到 `ItemDB.TOWER_SOUL_DROP_CHANCE`，
  面板与掉落共用同一来源。
