## 三、核心机制

### 3.1 三灾位

| 灾位 | 颜色 | BOSS 灾身 | 玩家灾身 |
|---|---|---|---|
| 风 | 青灰 | 移速 +25%；物理命中击退 200 | 移速 +12% |
| 火 | 赤金 | 命中挂「劫火」（6/秒，4 秒） | 法技增伤 +12% |
| 雷 | 紫白 | 命中挂「感电」（受伤 +15%，3 秒） | 攻速 +12% |

- **玩家灾身需装备被动「三灾·灾身」**：装备后任意风 / 火 / 雷属性功法命中都会切换玩家灾位并触发对应加成；未装备时仍可用任意对应属性功法破灾 / 喂灾，但没有玩家灾位、灾势、灾替与万劫归一，八式改走「灾劫连锁」（见 5.1）。
- **任意**风 / 火 / 雷属性功法命中都会参与破灾 / 喂灾，不要求是晏无咎本族功法；首战没有本族功法也能用现有火 / 雷 / 风功法破灾。
- BOSS 按当前灾位出招；每 8 秒（二阶段 5 秒）自动「三灾轮转」换到克制玩家的灾位。
- 相克：**风克火 / 火克雷 / 雷克风**。

### 3.2 破灾 / 灾崩 / 灾势 / 灾替

- 玩家用克制 BOSS 当前灾位的功法命中 → **破灾**：该次伤害 ×1.15、玩家灾势 +1、BOSS 灾崩 3 秒、BOSS 灾势 -1。
- 灾崩：BOSS 失去灾身、受到伤害 ×1.30、灾轮整段冻结；这是输出窗。
- 同灾位命中：伤害 ×0.85，BOSS 灾势 +1（喂灾）。
- BOSS 用克制玩家灾位的命中 → 玩家受伤 ×1.15、灾势 -1、锁灾 2 秒。
- **灾替**：三灾轮转起手 1.5 秒 / 三灾轮法宝 8 秒内，第一次被破灾改为免疫，并 +1 灾势。
  两枚同时存在时先消耗更短的轮转灾替。
- **锁灾**：玩家雷池首跳锁 BOSS 灾轮 3 秒；BOSS 雷池只锁站在池内的人，且整池只锁一次。
- **万劫归一**：消耗全部灾势，按层数追加伤害与灾柱；0 层也能放，只是弱。

### 3.3 二阶段 · 三灾归一

- 50% 血触发，持续 8 秒：三灾同身、无法破灾、BOSS 受到伤害 ×1.20。
- 归一期间全招池随机，万劫归一优先；结束后 BOSS 灾势 +1、灾轮加速到 5 秒一转、
  万劫归一门槛从 2 层降到 1 层。
- 这是二阶段专属机制层，不是单纯加数值。

### 5.1 灾劫连锁（装备或未装备「三灾·灾身」都生效）

- **三痕**：风灾命中附「风蚀」（移速 -15%，4 秒）；火灾附「劫火」；雷灾附「感电」。
- **引爆**：用克制已有灾痕的属性命中（直接命中或燎原 / 雷池跳伤）——
  - 风 + 劫火 → **风助火势**：消耗劫火，在引爆点留 **3 秒火龙卷**；每 0.5 秒一跳火伤（每跳 0.3×触发伤害）并续劫火，共 6 跳。
  - 火 + 感电 → **雷火交击**：消耗感电，目标处 **一次火爆**（×1.2），周围 0.6×，半径 110；没有后续跳伤。
  - 雷 + 风蚀 → **风雷引**：消耗风蚀，留 **3 秒风雷涡**；每 0.3 秒把半径 260 内敌人向中心拽 150，**不造成伤害**。
- **循环**：起手任意；之后每一下用克制上一招的属性，形成 **火 → 风 → 雷 → 火** 的循环。引爆后触发招式自身再留下本属性灾痕。
- **同一道痕只引爆一次**：燎原 / 雷池的跳伤也能引爆，但消耗后要重新挂痕才会再次引爆；万劫归一引爆后留灾崩，不再留火痕。
- **增伤口径**：火龙卷每跳 / 雷火爆发按「触发这一下的伤害」乘系数，吃火抗；风雷涡不造成伤害；反应本身不额外喂 / 破 BOSS 灾轮（触发招式本身仍按普通命中处理）。
- **读数**：目标头侧三枚小印（风 / 火 / 雷），亮 = 身上有该痕；装备 / 未装备被动都显示。反应名落在目标脚下，避开头顶血条。
- **适用范围**：普通 BOSS / 大世界敌人 / 演武场木桩都能挂痕与引爆；木桩只记录伤害，不结算持续伤害与易伤。三灾落点改为瞄准最近敌人，非晏无咎战也能命中。

- 规则卡：`SkillDB.get_calamity_rules()`，挂在功法库晏无咎分组顶部；图鉴卡
  `CodexDB.boss_entry("boss_03_c")` 的机制要点解释灾位 / 破灾 / 同灾 / 灾崩 / 灾身 / 灾替 / 锁灾 / 归一。
- **主动八式 + 被动「三灾·灾身」共 9 门**可在万界塔第 9 层感悟池随机获得；首杀位面给 500 修为与万界本源。

## 六、AI 与行为树

### 6.1 选招

1. **被玩家克**：轮转冷却好且未被锁 → 立刻「三灾轮转」换灾位。
2. **灾势 ≥2**（二阶段 ≥1）→ 万劫归一兑现；同灾位玩家也会触发归一。
3. 否则在**当前灾位的两式**里按距离评分 + 连携加成 + 重复惩罚选择：
   - 风：裂云步 / 断空斩
   - 火：焚天印 / 燎原
   - 雷：引雷诀 / 雷池
4. 连携：裂云步→断空斩、焚天印→燎原、引雷诀→雷池、轮转→归一。
5. 决策节流 0.3 秒；同一招连续两次 → 大幅降权，避免复读。

### 6.2 距离与反制

- **玩家贴脸**：断空斩 / 燎原 / 雷池；裂云步会把 BOSS 送到玩家身前 36px 再打。
- **玩家拉扯**：裂云步（460 内）、引雷诀 / 归一（520 内）、焚天印（460 内）。
- **弱点**：轮转 0.7 秒前摇，用克制当前灾位的功法命中可打断并直接灾崩；
  物理招可弹反；归一 8 秒受伤 +20% 是爆发窗。
- **不能逃课**：不理灾位 → 同灾减伤 + BOSS 灾势涨；只用一个元素 → 无法破灾、没有灾势。
- **通用破灾**：任意风 / 火 / 雷属性功法都计入，不限定晏无咎本族八式；首战可先用现有的火 / 雷 / 风功法打破对应灾位。

### 6.3 选招覆盖验证

探针在风 / 火 / 雷三灾位、80 / 220 / 380 三距离各随机 30 次，确认六门属性招全部会被选中；
另测「被克→轮转」「灾势 2 层→归一」「二阶段 1 层→归一」。

### 8.3 本轮修掉的真 bug

1. **`damage_taken_multiplier` 被基类 `clampf(0,1)` 掐掉 >1 的易伤** —— 晏无咎的灾崩 +15% /
   归一 +20% 以及离照的日冕破绽 +15% 之前**实际没有生效**。已把上限放宽到 3.0，
   并加「真正走 take_damage」的探针（normal 100 / broken 115 / fusion 120）。
2. **BOSS 端不读取减益的 `damage_taken_mult`** —— 玩家挂的感电 / 灾崩 / 定阵先生的「阵伤」对 BOSS 完全无效；

## 九、已知取舍

- BOSS 只有 body / 手 / 三段劫环五个分件：宽袖全部留在 body 上，只手从腕口切下，
  手腕摆幅限制 ±0.25 rad；这是为了避免 2D 刚体转袖口时露出白缝。
- 万劫归一 0 层也能放（设计口径），所以 AI 在「同灾位」分支可能 0 层起手；
  这是有意的惩罚招，不是空放。
- 归一期间「无法破灾」是通过 `calamity_state() == "fusion"` 让玩家侧 `_calamity_notify_hit` 直接返回实现；
  BOSS 仍会吃 +20% 伤害。
