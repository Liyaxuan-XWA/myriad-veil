## 一、位面 03：赤霄界

- 名：**赤霄界**（雷火焚天，兵戈作劫）。
- 描述：「雷出于地，火生于天；一念动，九霄皆兵。」
- 风格：赤金 / 焦黑 / 雷紫；天空裂痕、焦土、雷纹铁柱。
- 三位 BOSS 方向（仅定第一位）：**雷部判官 → 火部/兵解 → 界主**（后续再定）。
- 境界门槛：结丹；击败本界三位 BOSS 后开放下一界域。

## 二、身份与形象

- 名号：**雷部判官 · 赫连霄**；称谓「执劫之人」。
- 形象：焦金甲 + 赤黑官袍，背一面**雷鼓**，右手执雷纹铁笔；脸覆半张雷纹面具，双目雷紫；
  **悬空半尺**（脚下雷弧），袍摆垂成焦黑。
- 与前面六只的区别：刀客（布衣刀）/ 虎妖（兽）/ 剑客（白衣剑指）/ 两仪（太极光环）/
  定阵（盲眼阵师、实体旗）/ 气君（无腿气身、气环）——判官是**甲胄 + 鼓 + 铁笔**的雷部神官，
  轮廓最“重”，且是唯一**以律法/规则**为武器的 BOSS。
- 色板：赤金 / 焦黑 / 雷紫；场地 = 焦土 + 雷纹铁柱 + 中央雷印。
- 动作特征：不挥大刀、不放气环，**以笔判词、以鼓催雷**；身体前倾宣读，鼓面震出雷弧。

## 三、核心机制：判词 · 天律（脑暴后自选）

### 3.1 候选与取舍

| 候选 | 一句话 | 结论 |
|---|---|---|
| **判词·天律（行为禁令）** | 给玩家下一条「律」：禁行 / 禁攻 / 禁避 / 禁立，违律引雷、守律得「顺天」 | **选它**：不造地面物、不做护盾/层数，直接改「玩家这一段时间该怎么打」，与已有五套机制零重合；判官身份天然成立 |
| 劫雷·引落（延迟落雷 + 雷柱转印） | 点名 → 延迟落雷 → 玩家可把雷引到雷柱 | 好，但雷柱是「可打掉的地面物」，与阵旗同构；转印又像刀痕的“引爆”变体 |
| 雷池·导电（地面导电区） | 双方站在雷池上都会导电，玩家可引 BOSS 踩池 | 与阵线/阴风领域太近，且“引 BOSS 走位”在追击 AI 下难读 |
| 雷遁·镜像（真假身） | 假身被打反伤 | 可读性风险，容易判“恶心” |
| 雷音·鼓点（节奏判定） | 按鼓点闪避/出手 | 依赖音频与节拍，手机端与无音环境不可靠 |
| 雷劫·共鸣（双方雷势对撞） | 双方各攒雷势，满则对撞 | 更像资源对拼，缺少“每一招怎么用”的落点 |

**选择理由**：判词把「BOSS 的技能组」变成「一套会变化的规则」，而不是又一套地面物件或资源条。
玩家每一秒都在读“现在什么行为是犯法的”，BOSS 的八式则围绕**立律 / 执刑 / 逼你违规 / 改判 / 护律**展开；
玩家学会后可以把律下给 BOSS，让 BOSS 的**移动 / 出手 / 遁走 / 站桩**都变成可被惩罚的行为 ——
这是一套完整的“以行为为资源”的博弈，且与刀痕（地面）、剑意（自身层数）、两仪（护盾极性）、
阵旗（棋盘）、气环（环绕资源）全部不同。

### 3.2 规则

- BOSS 的「宣判·落笔」会在**前摇第一帧**选定一条判词，并在出手时落到玩家身上：
  - **禁行**（青紫）：每累计移动 **110 像素** → 引一道雷（0.8× 攻击，法术·金），雷势 +1。
  - **禁攻**（赤金）：每打中 BOSS 一次（普攻 / 功法）→ 引一道雷（0.9×），雷势 +1。
  - **禁避**（雷紫）：每闪避一次 → 引一道雷（0.8×），雷势 +1；**弹反不算违规**。
  - **禁立**（暗金）：原地不动超过 **0.9 秒** → 引一道雷（0.7×），之后每 0.9 秒再落一次。
- 判词持续 **5 秒**（二阶段 6 秒）；违律**不结束判词**，只吃雷 + 给 BOSS 雷势 ——
  玩家可以选择“顶着律硬打”，代价是雷势。
- **守律**：判词走完且一次未违规 → 玩家获得 **「顺天」6 秒**（攻速 +20%、移速 +10%），
  同时 BOSS **雷势 -1**（最低 0）。
- **抗辩**：宣判是一记**物理笔锋**，可被弹反。弹反成功 → 判词撤销、BOSS 僵直 0.9 秒、雷势 -1。
- **雷势**（BOSS 资源，0~3，头顶三枚雷印）：每次玩家违律 +1；被弹反 / 玩家守律 -1。
  「九霄·雷罚」消耗全部雷势，每层多落一道雷柱（2 + 雷势）。
- **弱点**：
  1. 宣判可弹反，弹反直接废掉一条律；
  2. 判词是**按玩家最近行为选的**（近 1.5 秒内闪避→禁避、出手→禁攻、移动→禁行、站桩→禁立），
     玩家可以主动“喂”行为，诱导它下一条律；
  3. 守律给顺天、削雷势，硬吃雷则喂它大招 —— 两种打法都成立，但不能无脑。
- **二阶段专属层**：
  1. **双律**：宣判一次落两条不冲突的律（禁行+禁攻 / 禁行+禁避 / 禁攻+禁避 / 禁立+禁避 / 禁立+禁攻），
     持续时间 6 秒；
  2. **雷牢·天罚**进入常规选招：锁定玩家脚下，1.2 秒收拢的雷环，收拢时仍在圈内 → 1.5× + 眩晕 1 秒。
     与「禁避」同场时，会逼玩家在“吃雷环”与“违律”之间选。

### 3.3 玩家侧继承（八式全部可学）

玩家侧的「判词·天律」与 BOSS 完全同构：**读取目标最近 1.5 秒的行为**，自动下对应的律。
所以玩家的操作不是“选一条律”，而是**先喂行为、再判词**：
- 想下「禁攻」→ 先让 BOSS 打你一下（或贴脸引它出手），再落笔；
- 想下「禁避」→ 先逼它用雷遁/突进，再落笔；
- 想下「禁行」→ 拉远让它追，再落笔；
- 想下「禁立」→ 等它站桩蓄力/吐纳，再落笔。
BOSS 被下律后会**按律改变行为**（见 §五），所以玩家的判词同时是伤害来源和**行为控制**。

玩家侧雷势：目标每次违律 +1；「聚雷·引霆」引导完成 +1；上限 3；「九霄·雷罚」消耗。
这与 BOSS 的雷势完全对称 —— 玩家也能用“逼对方违律 → 攒雷 → 九霄”的循环。

## 五、行为树

0. **宣判优先**：无判词在身 + 宣判就绪 + 玩家在 360 内 → 宣判（每 9~10 秒一次，不会无缝连下）。
1. **执刑**：玩家身上有判词 + 定刑就绪 → 定刑（惩罚站桩/被禁行的目标）；带律目标 +50%。
2. **雷势满 2+** + 九霄就绪 → 九霄（消耗雷势）。
3. **二阶段** + 雷牢就绪 + 玩家在 260 内 → 雷牢（与禁避联动）。
4. **残血 / 雷势低** + 聚雷就绪 → 聚雷（可打断，最大输出窗）。
5. **贴脸** → 雷鼓（击退）；**中距** → 锁雷 / 定刑；**远距** → 雷遁贴人 / 定刑。
6. 其余按距离评分 + 连携（判词→定刑 +2.0；雷遁→雷鼓 +1.4；锁雷→九霄 +1.0）；
   同招二连降权、三连封禁；0.3s 决策节流。

**被玩家下律后的应对（关键）**：
- 身上有**禁行** → 少走路：优先定刑 / 锁雷 / 九霄等原地招；必须接近时用雷遁（一次位移，认一次违律）。
- 身上有**禁攻** → 收手 1.2 秒，先走位/拉开；被逼急才出手（吃一道雷）。
- 身上有**禁避** → 放弃雷遁，改用走路贴近。
- 身上有**禁立** → 不停原地蓄力，改用移动 + 短前摇招式。
这套应对让玩家的判词真的能“控”它，而不是只多一条伤害。

**命中门禁**：判词 ≤380、定刑 ≤460、雷鼓 ≤210、锁雷 ≤340、雷遁 ≤520、聚雷不设、九霄 ≤520、雷牢 ≤520；
打不到就继续追，不空放。

**反制与逃课检查**：
- 贴脸 → 雷鼓击退 + 锁雷；一直拉远 → 雷遁贴人 + 定刑（指定落点）。
- 一直爆发 → 它会更频繁宣判「禁攻」，逼你停手；停手它就聚雷攒势。
- 一直跑 → 「禁行」+ 定刑；一直站桩 → 「禁立」+ 定刑。
- 无必须特定功法的门；无列不可躲的全屏秒杀；所有大招都有预警与安全缝。

## 六、数值（结丹玩家反推）

- 玩家标准档（结丹初期，冲和界毕业 + 灵器 +6，探针实测）：
  279 气血 / 99 物攻 / 66 法攻 / 189 灵力 / 物抗 33（24.8%）/ 法抗 42（29.6%）；
  普攻三段一轮 1.0 秒，单刀 99、终结 178.2；2.5 刀/秒 ≈ 313 DPS，3.2 刀/秒 ≈ 376 DPS。
- 反推：走位/躲招占 25~40% → 有效输出 190~235/秒；目标 TTK 60~80 秒 → 取 **13,000 血**。
  主招过抗后每下 55~95 → 3~5 下收命 → **90 攻**。
- BOSS：**13,000 血 / 90 攻 / 移速 92·112 / 受击三球**
  （(0,−50) r30 · (0,−4) r44 · (0,44) r38，外接半径 80，本体厚度 44）/ 二阶段 ×1.25。
- 聚雷打断门槛：**2.5% 最大气血（≈325）**；旧 8% 是按 5000 血写的，血量抬高后必须同步下调。
- 目标 TTK：标准档 **55~70 秒**；熟练满速 35~45 秒；结丹后期宝器 +10 约 20~30 秒。
- 节奏：判词 9s / 定刑 6.5s / 雷鼓 7s / 锁雷 9s / 雷遁 8s / 聚雷 14s / 九霄 24s / 雷牢 16s。
- 调节单点：`COOLDOWNS`、判词时长、违律雷击系数、雷势上限、九霄柱数、雷牢半径/收拢时间。

> 数值在实现后用**无头模拟 + 玩家侧实测**校准；最终数字以 `move_db.gd` / `domain_boss_03.gd` 为准。
