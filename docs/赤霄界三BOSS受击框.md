# 赤霄界三 BOSS 碰撞箱 / 受击框（2026-10-29）

> 对象：赫连霄（03）、离照（03_b）、晏无咎（03_c）
> 目标：碰撞箱与受击框覆盖立绘可见身体，不再出现「砍到衣服边不算中」或「隔着空气砍到」。

---

## 一、口径

- **受击框**：玩家攻击命中判定读 `BossBase.hit_spheres()`；本组三 BOSS 在各自脚本里覆写，
  把场景碰撞体采样出的球**投影到 y=0**（俯视地面），距离 / 扇形夹角都按地面算。
  这样头/腰/脚三排球的 y 偏移不会把贴身横砍算成「斜向上」而漏判。
- **碰撞箱**：物理碰撞仍使用场景里的 `CollisionShape2D` 原始 y；玩家站位按立绘身体外推，
  不会穿进身体。受击框与碰撞箱共用同一批形状（避免调了脚本忘场景），只差 y 投影。
- **包围盒采样**：`tools/check_plane3_hitboxes.py` 用 rig 非透明像素（alpha>20）在 1 世界像素网格上
  计算覆盖率 / 误覆盖 / IoU；背景光环、劫环不计入，武器/手按下面各条说明。
  ⚠ **2026-10-30 起赫连霄改用「实机剪影」口径**：上面那套是按 rig 拼图公式（T-pose + 0.25 + (0,5)）
  推算的，和实际渲染差了约 30~40px，误覆盖 6129px 却被算成「94.6% 覆盖」。
  现在由 `tools/shot_heiliao_silhouette.tscn` 拍 idle 实际渲染（1:1、纯黑底、去掉光环与 UI），
  `tools/fit_heiliao_hitbox.py` 直接读场景形状算覆盖率。离照 / 晏无咎仍用旧口径，未复核。
- **朝向镜像**：`BossBase._mirror_collision_shapes()` 会按 `_face_sign` 镜像形状的 x；
  本组所有非对称形状（离照 +5/+15/+25、晏无咎手 −25/+12、赫连霄左鼓/手臂）都会跟着美术翻转。

  掉头左右互换。
- 回归：`probe_heiliao` 141/0、`probe_lizhao` 151/0、`probe_wujiu` 164/0、`probe_wujiu_play` 11/0。
- 未实机、未提交；实机重点看：贴脸横砍是否命中衣摆/袖子、玩家被推到新身体边缘是否自然、

## 四、取舍

- 覆盖率优先于 IoU：破袍/披风/鼓是大量不规则透明边，圆/胶囊 Union 必然在轮廓凹陷处多出空白；
  但「打不到可见身体」比「多出一点判定」更伤手感。
- 赫连霄左鼓算身体（立绘轮廓）；铁笔只覆盖中段（r6×42），笔尖不加框 ——
  它随待机动画摆动，静态框跟不住，硬加会变成「隔空命中」。
