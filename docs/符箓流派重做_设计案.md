# 符箓流派重做 · 设计案（2026-11-10）

> 只改**试炼之路**里的符箓流派。局外七元灵符（符匣页 / Q/E/R/T 装配 / 制符台）**一行不动**。
> 旧「符匣 + 落笔/贴符/引爆/符罩 + 符心」整套退役。

## 一、一句话

选符箓流派 → 先「结符」挑四张符装进 Q/E/R/T → 开局四符**各自独立**施放；
在三选一里选到「连携」强化后，每放一张符，系统才**随机免费**帮你再放一张 =
「一符引一符」。灵机全部围绕符本身：连携更深、施符更省、符能改造、符能成阵成灵。

## 二、核心循环

1. **结符**：进本前从七张元素符里点选四张，装满四槽才能踏入试炼。
2. **施符**：每张符有独立冷却 + 灵力消耗，自动索敌（与现有元素符一致）。
3. **连携**（⚠ 2026-11-11 用户定：**不再是开局自带**）：
   三选一里选到「连携」解锁卡（稀有档，第 1 层起就可能刷到）才解锁；
   解锁后施放成功时，从「符囊」（四张主符 + 备符）里**随机**抽一张
   —— 不是本张、且不在冷却中 —— 以 **70% 效率**自动再放一次。
   - 连携符**不耗灵力、不进冷却**，也**不会触发二次连携**（防无限链）。
   - 抽到冷却中的符就跳过去重抽；符囊只有本张合法时本次无连携。
   - ⚠ 8 张连携深度卡（双符/顺笔/回响/定弦/引线/同气/贯注/连珠）带 `need_flag` 门禁：
     没解锁连携前**全部不进池**（防废卡，与符方/变体过滤同一层 `_buff_available`）。
4. **连携回灵**：每次连携成功回 **2 点灵力**（解锁连携后就有，随「连珠」叠加）。
5. **符囊**：初始 2 格，灵机可扩到 4 格。制符/符方得到的新符进符囊，
   兼做**仓库（换符）+ 连携候选池**；没解锁连携时只是仓库。
6. **换符**：每层开始时免费把符囊里的符与主槽互换一次。

## 五、灵机池

| 类别 | 卡 |
|---|---|
| 连携解锁 | **连携**（解锁连携机制本体：每放一张随机免费连携符囊另一张、70% 效率、回 2 灵力；稀有，max 1） |
| 连携深度 | 双符（连携 2 张，传说）／顺笔（连携不打折，传说）／回响（25% 再连一张，传说）／定弦（连携必抽不同元素，稀有）／引线（连携后主符 CD -1.5s，稀有）／同气（连续两次同元素连携，第二张 +80%，稀有）／贯注（手动 +15%、连携 -10%，普通）／连珠（连携回灵 2→4，稀有）⚠ 8 张全部 need_flag 门禁：没选「连携」解锁卡前不进池 |
| 施法经济 | 无墨（不耗灵力、CD +25%，传说）／灵泉（灵力上限 +20%，普通）／回息（灵力回复 +30%，普通）／血墨（灵力不足用气血付，稀有）／疾书（全符 CD -15%，稀有）／引灵（击杀回 5 灵，普通）／蓄势（8s 未施符，下张 +50%，稀有）／开匣（符囊 +1，稀有） |
| 符方 ×10 | 每张符一张「符方」，未拥有则获得、已拥有则 +1 档（最高 4 档） |
| 变体 ×20 | 每张变体一张卡，互斥 |
| 通用 | 法强 / 气血 / 移速 / 双抗 / 力量 各一条 |

三选一过滤规则：变体卡只在「已拥有该符 + 尚未选过它的任一变体」时进池；符方卡只在「未拥有 或 未满 4 档」时进池；连携深度卡只在「已选『连携』解锁卡」时进池（`_buff_available` 的 need_flag 门禁）。

## 六、数值与隔离

- 施符伤害走 `_tal_hit_one` 钩子链（试炼全局乘区、命中挂减益都在那条链上），**不能**直接 `take_damage`。
- 连携效率 0.70；`顺笔` 改 1.00。所有连携加成只乘一次，变体参数不再各乘一遍。
- 品质倍率、变体参数、灵力、冷却全部在 `TalismanDB` 里，运行期不写死。
- 试炼不写存档；结符选择只活在 `RogueRun` 静态状态里。
- 局外 `ItemDB.ELEMENT_TALISMAN_BASES` / `talisman_cabinet` / `player.use_talisman` 保持原样，
  只在 `use_talisman_slot()` 里加一个 `if RogueRun.active → use_run_talisman()` 的分流。

## 八之二、2026-11-10 傍晚两条实机反馈（用户「面板固定在地上 / 按技能用不了符」）

| 现象 | 根因 | 修法 |
|---|---|---|
| 换符页面板像「钉在地上」，红色地面从四周露出来 | `talisman_swap_page.gd` 是**裸 `Control`**，被 `rogue_arena.gd:574` 挂到 `get_tree().root`，与战斗 `Node2D` + `Camera2D` 同处 layer 0 → 跟着相机平移；写死的 1280×720 遮罩也盖不住视口。另外缺 `PROCESS_MODE_ALWAYS`，`open()` 暂停树后按钮收不到输入 | 改成 `extends CanvasLayer` + `layer=105` + `PROCESS_MODE_ALWAYS`，Dim 用 `PRESET_FULL_RECT`（CanvasLayer 直属 Control 的 anchor 基准是视口）。与 `SystemPanel(101)` / `ConfirmDialog(110)` / `tutorial_overlay(120)` 同一套约定 |
| 选了符箓流派、技能栏四格显示正常，按 Q/E/R/T 却毫无反应 | HUD 直接读 `active_skill_loadout`（不过滤），但按键分发读 `equipped_active_skills()`；后者对试炼槽值 `talisman:tal_jinfeng`（**裸 base_id**）查 `ItemDB.get_consumable()` 返回 `{}` → `append("")` → `_poll_skill_keys()` 逐格 `continue` 静默吞键。`use_talisman_slot` / `use_run_talisman` 从未被调用 | `equipped_active_skills()` 补 `TalismanDB.base_def(tid)` 兜底：局外带品质档的符仍由 ItemDB 分支覆盖，试炼裸 base 走 TalismanDB 分支。局外行为不变 |
