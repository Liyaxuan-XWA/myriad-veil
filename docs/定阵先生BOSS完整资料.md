## 三、核心机制：阵旗 · 连线

### 3.1 阵旗

- BOSS 最多同时存在 **5 面阵旗**：「插旗」只铺到四面，第五面靠「垒旗」「踏阵」顺带插上。
- 插旗点会**关于玩家做镜像**：新旗与已有旗的连线必然穿过玩家，且离玩家 170~430（不贴脸）。
- 每面旗要**打三次**才倒（按次数，不看伤害），属于 `array_flag` + `breakable_sword` 组；**不会自然消失**（只有「解阵」清空或玩家打掉）。
- 受击判定与贴图对齐：判定点抬到旗面中心、半径 32（原来按脚下原点算，砍旗面不算中）；被砍中时整面旗会涨一圈再回弹。
- 旗与旗之间**按下标顺序连成阵线**（1-2、2-3、3-4、4-5，5 面时再补 5-1 收口成环）。
  每段**一根阵绳**（写实绞绳贴图），挡住对手的移动；施法者与友军可穿行。线的两端随旗的插/拔即时重连，**打掉旗才会解除对应的线**。

### 3.2 三类招式

| 类别 | 招式 | 与机制的关系 |
|---|---|---|
| **布点** | 插旗·定星 | 往目标点插旗（不加伤害，但决定后面的线怎么走） |
| **用线** | 引阵·朱弦 / 卷阵·收旗 / 封阵·四象 | 在旗之间连线、把旗拉向自己、四面成环封锁 |
| **拆点** | 扫阵·横天 / 垒旗·镇岳 / 踏阵·走罡 / 解阵·雷落 | 不依赖旗的近身与位移手段，保证「没旗时也有威胁」 |

### 3.3 三色阵旗（2026-10-28 定稿）

颜色即作用：**朱砂=攻、墨=困、石青=守**；插下即定型。杆顶另有写实顶饰（枪尖 / 锁环 / 玉璧），远处看色、近处看形；插旗前摇 0.6 秒先在落点亮同色阵纹。

| 色 | 被动（不用出招） |
|---|---|
| **攻** | 玩家进 **150px**：0.5 秒预警 → 剑气 0.45×（26 攻≈11.7），每 **2.6 秒**一次；命中叠「阵伤」受伤 **+8%/层**、3 层封顶，离开攻旗范围 **4 秒**清空 |
| **困** | **90px** 内移速 ×0.6 + **禁闪避**；零伤害，走出即恢复（地面有很淡的墨环标边界） |
| **守** | 任意一面存活 → BOSS 受伤 **-50%**（不叠加）；守旗被打掉后 **8 秒内不再补守旗**（这 8 秒是输出窗） |

**旗型分配**：先补缺色（三才），三色齐后按局面选；场上已有某色 2 面时 45% 概率补成三同色（凑套）。

**八式读色**：

- **引阵**：每段一根绳，按多数旗色整段结算——攻 0.8× 灼烧 / 困锁步 1.0 秒零伤 / 守无伤；不消耗旗。
- **卷阵**：攻＝沿路伤害 + 点燃 3 秒；困＝把玩家拽向旗位约 120px；守＝旗收回身侧继续吃减伤。
- **封阵**：场上多数色定型（平票 攻>困>守）——攻多每跳 ×1.25（4 跳 ×0.55）/ 困多牢内**眩晕 5 秒** / 守多 BOSS **减伤 70% 持续 10 秒**，任一成阵旗被破守牢立即结束。
- **解阵**：攻＝伤害 / 困＝锁步 2 秒 / 守＝BOSS 回 8% 气血。
- **垒旗 / 踏阵**顺带插的旗取当前缺色；**扫阵**不变。
- **五旗环**：五面旗首尾闭合成区域。环内使用者攻击/防御 +30%（防御按受伤 ×1/1.3）；环内对手攻击 -10%；每秒雷击 0.6×法攻/攻击力，每次扣 10 法力/阵力，资源不足时五旗自动消散。BOSS 用隐藏阵力 100（耗尽撤旗，重新起阵补满）。

**成套杀招**（某色 ≥3 面，5 面旗最多同时凑一套）：

| 套 | 招式 |
|---|---|
| 三攻 | **万剑汇聚**：1.2 秒预警后三道剑气落向玩家当前位置（各 0.8×，物理，可弹反） |
| 三困 | **定身锁**：玩家站在三面困旗三角内时起手，0.7 秒预警 → 定身 1.5 秒（可反击、不能移动） |
| 三守 | **龟甲阵**：减伤 70% + 每秒回 1% 气血 |

凑齐时三色线变亮、BOSS 脚下亮同色环；拔掉任一面立刻掉档。

### 3.4 玩家如何破

- **拔旗**：打掉旗，让它那几段线消失；五旗环与后续「引阵 / 封阵」也一并失效 —— 这是主要解法；
- **闭合前走位 / 打断布点**：线会挡路，五旗一闭环就会被关在区域里吃雷与减攻；要在第五面插下前离开，或先拔旗；
- **读插旗点**：插旗前摇 0.6 秒，看清它把旗插在哪，提前离开那一带；
- **贴脸**：它没有护体，近身只有「扫阵 / 垒旗 / 踏阵」三招，靠弹刀与闪避硬吃。

### 3.4 它如何反制

| 玩家的行为 | 它的应对 |
|---|---|
| 专门追着拔旗 | 「卷阵」把旗收回身边（拔旗等于把线拉到自己脚下）+ 「踏阵」直接跳到旗旁 |
| 一直贴脸 | 「扫阵」横扫 + 「踏阵」后撤拉开距离 |
| 一直拉远 | 「插旗」插在你身后 → 「引阵」横切你的退路 |
| 站着不动 | 四面旗「封阵·四象」；五旗环持续雷击 + 削攻，逼你动起来或拔旗 |
| 用五旗把它围住 | 最近的玩家旗会被当成普通目标，它用正常招式/投射物打旗；旗有实体、三次伤害才消失，环破后恢复追玩家；破掉一面会触发玩家**眩晕 5 秒 + 15 秒「破阵反噬」**，期间不能插旗/踏阵/垒旗 |

## 五、玩家侧：阵旗（塔第 5 层奖励层）

- 学会任意一门本 BOSS 功法即解锁「阵旗」；**第一战不显示、不参与计算**。
- 与 BOSS **同一套口径**（2026-10-28 对齐）：
  - 最多 **5 面旗**，旗**不会自然消失**（只有解阵清场 / BOSS 本体退场才消失）；插旗满 5 面后不能再插，不会顶掉旧旗。
  - 插旗**落在玩家当前坐标**（用户 2026-10-28 定）：不再绕目标/镜像布点；前摇内脚下亮同色阵纹预告。
  - 旗型先补缺色（攻/困/守三才），某色已有 2 面时 45% 补成三同色；布面颜色 + 旗顶饰与 BOSS 旗完全一致（玩家旗在旗座多一枚小金印区分归属）。
  - 三色被动同 BOSS：攻旗 150 内每 2.6 秒落预警剑气（0.45× 法攻）；困旗 90 内锁步；守旗存活时玩家受伤 -15%。
- 六式分工：**布旗**（插旗·定星、垒旗·镇岳）→ **用线**（引阵·朱弦、封阵·四象、卷阵·收旗）→
  **引爆**（解阵·雷落）。
  - 引阵：**全部相邻旗段**一起拉线（5 面时首尾收口），每段一根线，按**多数旗色整段结算**（攻伤害 / 困锁步 / 守无伤），**不消耗旗**。
  - 卷阵：只把离你最近的一面旗卷回身侧，沿整根线按旗色结算，**不撤旗**。
  - 封阵·四象：四面旗成阵，按**多数旗色**结牢，以阵心连打四跳（每 0.55 秒，半径 210），**不撤旗**；困牢让牢内敌人**眩晕 5 秒**；守牢让玩家**受伤 -70% 持续 10 秒**，任一成阵旗被破立即结束。**攻牢才有法伤；困/守牢本身零伤害**。玩家侧起手招名会报本次牢型（困/守标「无伤」+ 效果）。
  - 解阵：引爆全部旗，攻旗 140 内伤害 / 困旗锁步 / 守旗回血 8%，引爆后清场。
- **五旗环（2026-10-29）**：五面旗首尾闭合成区域；环内玩家攻击/防御 +30%（防御按受伤 ×1/1.3），环内敌人攻击 -10%、每秒雷击 0.6×法攻并扣 10 法力；法力不足时五旗消散。BOSS 侧同规则，但消耗隐藏阵力 100（每次雷击 -10，耗尽撤旗；重新起阵补满）。**玩家旗是实体**：有 Area2D 命中体、可被 BOSS 正常索敌/招式/投射物命中；被围住时 BOSS 把最近的旗当普通目标，旗吃三次伤害消失，环破后目标回玩家。没有额外的「破阵」技能。**破阵反噬**：完整五旗被敌对破去一面时，玩家**眩晕 5 秒**，并获得 **15 秒** debuff，期间插旗 / 踏阵 / 垒旗全部不可用（不扣资源/冷却）；玩家自己解阵清旗、只有四旗时被破都不触发。
- 命中门禁：没旗（卷阵/解阵）、旗不足四面（封阵）、阵位已满（插旗）时不扣灵力/精力与冷却，只给飘字提示。
- 常驻阵线：两旗以上自动连线（每段一根、挡对手移动；五面首尾收口成环），让「线在哪、下一招打哪」可读；施法者与友军可穿自己的线。
- 收益：站在任意一段阵线上时，其它招式伤害 +10%（「守阵」），离开即失效。

## 六、行为树

0. **成套优先**：某色 ≥3 面且冷却好 → 直接起手成套杀招（三攻万剑 / 三困定身锁；三守龟甲是被动）。
1. **布点**：插旗只铺到**四面**——旗 < 2 时 80% 插旗，旗 ≥ 2 时 25%；旗 = 3 时 70% 补到四面（封阵/解阵要四面）。第五面靠「垒旗」「踏阵」顺带插上（不站桩刷旗）。
   选招按 0.3 秒一次决策（`_decide_wait`），否则 CHASE 每帧调 `_choose`，概率门槛形同虚设、插旗会霸占所有出手。
2. **四象**：旗 ≥ 4 时，二阶段且「解阵」可用 → 解阵（55%）；否则「封阵」可用就封阵。
3. **踏阵 = 位移**：480 以内都可用（≥320 靠它贴人），不按攻击招数做命中门禁。
4. 其余按距离评分（与现有 BOSS 同构）+ 连携加成 + 重复惩罚：
   - 连携：插旗→引阵/卷阵 +2.5；卷阵→踏阵 +2.0；踏阵→扫阵/垒旗 +2.2；引阵→踏阵/封阵 +1.6；
   - 随机 ±1.1；同一招二连 -2.4，三连直接封（`_repeat_penalty`）。
5. **命中门禁（防原地空放）**：除插旗（布点）与踏阵（位移）外，选中的招必须"现在真能打到"——
   - 引阵：玩家在任一旗线附近（含 5 旗的首尾收口线，半宽 56）；
   - 卷阵：旗→BOSS 的判定线够得着玩家（卷的是**离玩家最近**那面旗）；
   - 封阵：按旗阵中心算 210 半径；解阵：按每面旗 140 半径算；
   - 扫阵/垒旗：按扇形/圆形实际判定 + 张角算。
   都打不到就不出招、继续追击（等踏阵贴人）。
6. BOSS 旗**不会自然消失**：只有「解阵」清空、玩家打三次、或 BOSS 本体退场（含阵旗令召唤到期）才会消失；其余招式都不撤旗。

## 八、美术与特效

- 形象：盲眼阵师，短袍、背旗匣、手持朱砂罗盘；色板 朱砂红 / 墨 / 石青。
- 场地：石台上叠加**朱砂阵纹**（与两仪的太极石台区分）。
- 特效：**全部走 `ArrayFx`（阵旗一族专属表现层）**，与其它 BOSS 的刀光 / 兽爪 / 八卦 / 太极分开；
  材质语言固定为「朱砂绞绳 + 阵钉 + 阵柱 + 方框牢笼 + 旗影」，颜色取旗型（朱砂 / 墨 / 石青）。
  - 插旗：落点一圈**同色阵纹** + 四枚阵钉 + 尘土（与 0.6 秒预告同点）；
