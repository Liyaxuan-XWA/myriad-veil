# 调试道具面板（F2）

> 2026-10-21 用户专用。只在**编辑器运行**时存在，导出包里没有。

## 怎么用

游戏里任意场景（主城 / 战斗）按 **F2** 开关，再按 F2 或点别处关闭。面板不暂停游戏。

| 页签 | 内容 |
|---|---|
| 装备 | 每件装备模板一行：`获取`（正常）、`破损版`（直接 `is_broken=true` + 磨损拉满，用来测合成台） |
| 材料元魂 | 每种材料一行：`+20` / `+99`；元魂用紫色显示 |
| 法宝 | 每件召唤法宝一行：`获取`、`满强化`（等级 10 + 加成 10 级 + 进阶 2 次，直接看召唤强度与时长） |
| 快捷 | 晶石 +100、所有元魂各 +1、所有法宝各 +1（满强化）、所有装备各 +1（破损版） |

右下角实时显示 `背包：N 件 · 晶石 ×M`。

## 为什么打包后别人用不了

面板**不是靠隐藏或密码**，而是根本不会被创建：

```gdscript
# game_state.gd
func _setup_debug_item_panel() -> void:
	if not OS.has_feature("editor"):
		return          # 导出包（debug / release 都一样）走这里
	var panel := DebugItemPanel.new()
	add_child(panel)
```

`OS.has_feature("editor")` 只在用编辑器运行（F5 / F6）时为 `true`；任何导出包里恒为 `false`。
所以导出后既没有这个节点，也没有 F2 的监听者。

> 想验证：导出一次，进游戏按 F2 —— 什么都不会发生。

## 文件

| 文件 | 作用 |
|---|---|
| `scripts/ui/debug_item_panel.gd` | 面板本体（`class_name DebugItemPanel`，全部代码构建 UI，走 `ui_kit` 配色） |
| `scripts/systems/game_state.gd` | `_setup_debug_item_panel()`：只在编辑器里挂载 |

## 加新东西到面板

- 新的装备 / 材料 / 法宝：**不用改面板**，它直接遍历 `ItemDB.EQUIPMENT_TEMPLATES /
  MATERIALS / TREASURE_TEMPLATES`
- 新的快捷操作：在 `_build_quick_page()` 里加一个按钮，连到对应的 `_grant_*` 即可
