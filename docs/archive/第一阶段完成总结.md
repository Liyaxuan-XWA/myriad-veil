## 一、项目概况

第一篇章聚焦**单场 BOSS 攻坚的完整战斗循环**，核心目标是把手感做扎实：闪避、弹刀、连击、精力管理、阶段切换，以及与之配套的打击反馈。

本阶段不涉及的（留给阶段2）：境界系统、装备、功法、存档、多 BOSS、场景流程、正式美术与音频资源。当前所有视觉为色块占位、所有音效为程序生成的占位波形。

## 三、核心系统

### 3.1 玩家系统（`player.gd`）

**基础**
- 100 点血量、5 格精力、移动速度 220
- 输入采用 `_physics_process` **轮询** `Input.is_action_just_pressed()`，而非 `_unhandled_input`，避免鼠标点击被 UI 消费导致攻击/弹刀无响应

**三段连击**
- 第 1 段「来」→ 第 2 段「回」→ 第 3 段「终结技」
- 终结技：伤害 ×1.8、范围 ×1.4、后摇加长至 0.5s
- **攻击后摇取消**：攻击进行到 50% 后可被闪避/弹刀打断收招

**闪避**
- 位移 0.18s，冷却 0.5s，消耗 1 格精力
- **完美闪避**：闪避开始后前 60% 时间内被攻击判定为完美 → 回复 2 格精力、触发子弹时间慢动作、复制角色形象生成 3 个蓝色残影、蓝色冲击环 + 蓝色浮字

**弹刀（格挡）**
- 窗口 0.22s，冷却 0.6s，消耗 1 格精力
- **必须站定释放**：弹刀期间移动被锁死（不能边跑边弹）
- **完美弹反**（窗口前 35% 内弹中）：无击退、追击位移可用，额外 0.2s 定身演出（期间禁止一切操作）
- **普通弹反**：受 180 力度自身击退，无位移
- 可弹：物理近战、物理投掷；不可弹：元素/法术/能量/神魂
- 弹近战 → BOSS 僵直 1.2s；弹投掷 → 投掷物反弹且对 BOSS 造成 12 伤害
- 弹反成功回复 1 格精力

> ⚠ **本节已被 2026-10-17 的弹刀重做更新**，现行规则见下面「弹刀重做（现行）」。

**弹刀重做（现行，2026-10-17）**
| 规则 | 内容 |
|---|---|
| 站定 | 普通弹刀**零前摇**（按下即判定、移动锁定）；只有完美弹反有 0.2s 定身，期间不能操作 |
| 次数增伤 buff | 弹刀成功获得「**下一次近战伤害 ×1.5**」，造成一次近战伤害后消失；**不累计，最多一层** |
| buff 范围 | 只吃**近战物理**（普攻 + 物理功法）；法术、投射物、刀痕都不吃 |
| 自动再弹 | ~~弹刀后 1.2 秒内站着不动挨到可弹物理伤害会自动弹刀，可连弹~~ **← 已于 2026-10-17 取消**：连续弹刀机制删除，想弹必须自己按键；1.2 秒窗口只留给下面的追击位移 |
| 追击位移 | **仍只限完美弹反**；窗口内下次「普攻 **或近战物理功法**」都会快速位移贴近 BOSS，**一次性** |
| 旧规则 | 「首段伤害翻倍 ×2」已删除，由上面的 ×1.5 次数 buff 取代 |

**精力**
- 5 格，弹刀/闪避各扣 1 格，每 4 秒回复 1 格（回复不因消耗而打断）
- 受击时精力扣 **1 格**（2026-10-17 由「减半」改定），惩罚贪刀
- 耗尽时空格红色脉动警示

**受击**
- 无敌帧 0.3s（缩短版，保留连续被击的压迫感）
- 击退按攻击类型分级：近战 320 / 物理投掷 140 / 元素 120

**软锁定**
- 攻击时自动朝向最近 BOSS，但限制在**攻击方向前方 ±90°** 内，避免背后的目标被误锁

**攻击判定**
- 扇形几何判定（遍历 boss group + 距离/方向夹角双重过滤），不依赖 Area2D 物理重叠

### 3.2 BOSS 共有机制（`boss_base.gd`，`class_name BossBase`）

按任务书 2.12 强制规范实现的骨架，所有 BOSS 共用：

| 机制 | 实现 |
|------|------|
| 双阶段 | 50% 血量切换 |
| 阶段差异 | 一阶段慢速规律；二阶段保留招式 + 移速/攻速提升 + 伤害 ×2 |
| 无预警设计 | 无 UI 预警、无红圈、无范围标记、无韧性条、无破防 |
| 读招方式 | 仅靠肢体动作（蓄力时放大 1.25 倍 + 变色） |
| 弹刀规则 | 物理可弹、元素不可弹；弹刀成功 → 抵消伤害 + BOSS 僵直 + 玩家输出窗口 |
| 转阶段保护 | 进入无敌并把玩家推开，保证「能量聚集」演出播完 |
| 转阶段特效 | 12 颗能量球向中心汇聚 + 身体闪红 |
| 弹刀反馈 | 僵直 + 变黄 + 沿受击反方向踉跄后撤 120 |
| 死亡演出 | 缩小渐隐 + 20 片碎片迸发 |

状态枚举：`IDLE / CHASE / WINDUP / ATTACK / RECOVER / STAGGER / DEAD`
子类特有状态从 **100 起**编号，避免与基类冲突。

### 3.3 原型 BOSS（`prototype_boss.gd`）

基础招式组 + 两个位移技能：

**招式**
- **近战横扫**：110px 范围、120° 扇形、15 伤害（配扇形横扫视觉）
- **物理投掷**：速度 520、12 伤害（可弹刀）
- **元素法球**：速度 338、18 伤害（不可弹刀），仅二阶段且冷却完毕时 50% 概率释放，二阶段视觉放大 1.8 倍

**距离驱动选招**
- ≤130px → 近战；≤320px → 远程（物理/元素随机）；否则继续追击

**后撤步技能（连续 2 次近战触发）**
- 基础概率 70%，未触发则概率递增 10%（上限 100%），无 CD
- 一阶段：单纯后撤后接一发投掷
- 二阶段：后撤距离/时间加长（0.32s），并扇形连发 **5 发**投掷物

**突进 + 砸地技能（连续 2 次远程触发）**
- 基础概率 70%，未触发则概率递增 10%，无 CD
- 突进速度 800，抵达或超时后进入砸地
- **砸地为物理伤害，可被弹刀**
- 二阶段：连续 **3 次**砸地，每次范围递增 40px

### 3.4 打击反馈体系

**顿帧 / 慢动作**
- 统一的**时间流速序列管理器**（`game_state.gd`），用真实时间戳 `Time.get_ticks_usec()` 驱动，不受 `Engine.time_scale` 影响
- 支持「顿帧 → 慢动作」多阶段串联，命中顿帧 0.05s（time_scale 0.05）
- 场景重开前 `reset_time_flow()` 清理，避免残留卡慢

**弹刀六件套**
1. 屏幕震动
2. 冲击环（ShockwaveRing）
3. BOSS 踉跄位移
4. 投掷物反弹火花
5. 完美弹反分级（金色更亮更大 + 浮字「完美弹反！」）
6. 音效区分（普通/完美两套波形）

**其他**
- 玩家攻击：渐变月牙刀光（SlashDrawer）
- 完美闪避：子弹时间 + 蓝色残影 + 蓝色冲击环 + 蓝色浮字「完美闪避！」
- 低血量：屏幕四边泛红 vignette + 血条转红
- 击杀：慢动作 + 震动 + 击杀音效
- 死亡：慢动作 + 震动 + 提示按 R 重试

**音效**（`GameState` 全局管理器，均为程序生成的 AudioStreamWAV）
- `attack_hit` 命中「唰」、`player_hit` 受击「咚」、`boss_attack` 出招「呼」
- `phase_change` 转阶段「嗡」、`boss_death` 击杀「轰」
- 玩家侧另有普通/完美弹刀、普通/完美闪避 4 套独立波形

## 六、关键技术决策（踩坑记录）

| 问题 | 原因 | 解法 |
|------|------|------|
| 鼠标左右键无法触发攻击/弹刀 | `_unhandled_input` 被 UI 消费 | 改为 `_physics_process` 轮询 `is_action_just_pressed()` |
| 空格触发游戏重置 | 焦点按钮被空格激活 | 按钮禁用焦点，R 键改用 `physical_keycode` 且过滤 `echo` |
| 调试面板 tscn "has vanished" | 复杂层级实例化失败 | 改为纯代码构建 UI |
| 斜下方攻击打不中 | Area2D 旋转后 `get_overlapping_bodies()` 有一帧延迟 | 改为纯几何扇形判定 |
| 顿帧与计时冲突 | `Engine.time_scale` 影响所有 delta 计时 | 真实时间戳驱动的序列管理器 |
| BOSS 粘贴到玩家身上 | 追逐时无分离逻辑 | 距离 <40px 时主动反向分离 |
| 贴近 BOSS 时攻击反向 | 软锁定锁定到背后目标 | 限制为攻击前方 ±90° |
| 手机版按弹刀自动攻击 | 触屏被模拟成鼠标左/右键，`attack` 绑定左键、`parry` 绑定右键 | 关闭 `emulate_mouse_from_touch` + 触控索引隔离（**该手机 UI 已移除**） |
| 精力最后一格无法使用 | 判断边界条件错误 | 修正为 `stamina >= STAMINA_COST` |
| 消耗精力打断回复 | 回复计时器被清空 | 消耗不再重置计时器 |
