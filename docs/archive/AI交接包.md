## 2. 五条硬约束（违反 = 返工）

### ① 美术素材可替换性（最高优先级）

用户计划**后期统一替换所有美术**，所以现在所有可视内容都必须留好替换口：

- 角色 / 场景实体 → `SkinVisual`（`scripts/visual/skin_visual.gd`），**绝不把 `ColorRect` 当最终形象**
- 一次性特效（旋转/缩放/淡出/播完自毁）→ `ArtDB.EFFECTS` + `FxPlayer`，**禁止** `ColorRect` + `create_tween` 硬编码
- UI → 走 `ui_kit.gd` 的贴图机制（`icon_node`）与 `assets/ui/`，配色与尺寸不得写死在业务逻辑里
- 新实体 / 新特效必须在 `art_db.gd` 登记，必填 `placeholder_color` + `placeholder_size`：**没贴图也必须能跑**
- 玩法代码只操作 `Visual` 这一层（翻转 / 闪色 / 缩放 / 残影），**不碰 SkinVisual 内部子节点**
- 不可翻转的元素（血条、朝向标记、名称标签）挂**实体根节点**下，不挂 `Visual` 下
- 需随 `duplicate()`（残影）复制的字段必须 `@export`

> 例外：`player.gd` 里弹反/闪避的 4 处特效用户明确说「效果还不错，保持现状」，不要动。

### ② 装备 / 法宝的「实体唯一归属」

同一件装备同一时刻只能存在于**穿戴槽 / 背包 / 铁砧**三者之一：

- 位置转移**只能走移动式接口**：`equip_from_inventory(index)` / `unequip_to_inventory(slot)` /
  `take_for_forge(index, slot)` / `return_from_forge(item)`
- 裸调 `equip(slot, item)`（不移出背包）会造成「一物两件」；裸调 `unequip(slot)`（不回背包）会让装备凭空消失
- `add_item()` 内部是 `duplicate()` **浅拷贝**，`add_item(a)` 之后背包里是副本不是原对象

### ③ 判断「同一个对象」只能用 `is_same()`

GDScript 的 Dictionary `==` 是**内容深比较**，两件同款装备会被误判成同一件。

### ④ UI 术语

玩家可见文案一律用「**主动功法 / 被动功法**」，不出现「神通 / 增益」。引用任务书原文时保留原词并旁注。

### ⑤ 验证方式

项目没有单元测试框架，流程是：

1. 改前 `cp file file.bak`
2. 写临时 `verify.gd` + `verify.tscn`，`godot --headless --path . res://verify.tscn`
   用断言统计失败数，`get_tree().quit(失败数)` 回传退出码
3. **跑完必须删除**这几个临时文件
4. 冒烟：`godot --headless --path . --quit-after 150`（主场景无报错）

⚠ `--script` 模式不注册 autoload，验证**必须走场景**。

## 3. 世界观与内容结构

### 3.1 万界秘境（位面）

**每个位面 3 名 BOSS，三名全部击杀 = 该位面通关**，通关后下一个位面自动开放。

| 位面 | 境界要求 | 3 名 BOSS |
|---|---|---|
| 凡界（domain_01） | 练气 | **虎妖**（800 血）/ **刀客**（1000 血）/ 断刃客（占位） |
| 位面 02（domain_02） | 筑基 | BOSS 02 / BOSS 02-B / BOSS 02-C（全是占位） |
| 位面 03（domain_03） | 金丹 | BOSS 03 / BOSS 03-B / BOSS 03-C（全是占位） |

- 首个位面默认开放；**境界不阻挡**（只红字警告，可硬打）
- 只有真实位面 BOSS 才产「万界本源」，塔投影不产
- BOSS 之间**没有顺序限制**，位面开放后三只都能直接挑战

### 3.2 通天仙塔

**一名 BOSS 对应一层，共 9 层**（层表由 `DOMAINS` 自动生成，不手写）：

- 在万界秘境**击败某名 BOSS → 对应塔层立刻开放**（不等位面通关）
- 层内 BOSS 是该 BOSS 的「投影」，与本尊同形
- **每次通关都能随机感悟该层功法**：必 1 门 / 30% 得 2 门 / 5% 得全部；已掌握的门类跳过
- 玩家**不能自选**
- 锻造晶石按「第几次通关」给量：**首通 9 块 → 第二次 6 块 → 第三次及以后 3 块**
- 塔是**唯一功法来源**

### 3.3 主城（原初位面）9 个设施

| 设施 | 状态 | 说明 |
|---|---|---|
| 演武场 | ✅ | 进战斗练手，无奖励；里面的 BOSS **就是虎妖** |
| 万界秘境 | ✅ | 3 位面 × 3 BOSS |
| 通天仙塔 | ✅ | 9 层 |
| 装备锻造台 | ✅ | 强化 / 进阶 / 破损 / 分解（**不再打造新装备**） |
| 材料仓库 | ✅ | 材料存取 |
| 记忆幻像碑 | ✅ | 文案化回放 |
| 炼丹房 / 药田 / 制符台 | 🚫 | **暂未开启**：点击只提示，设施压暗，代码仍在 |

开关表：`primordial_realm.gd` 的 `const LOCKED_FACILITIES`（把 id 删掉即重新开放）。

### 3.4 剧情

主角李青云；关键词「挚友」「世代守护时空至宝（万界锚点戒指）」「背叛」。3 片记忆碎片，
分别在通关 3 个位面后解锁。**目前只有文案，没有演出。**

## 4. 数值体系

### 4.1 属性表（`AttributeDB`）

| id | 名称 | 说明 |
|---|---|---|
| `hp_max` | 气血 | 上限 |
| `speed` | 速度 | 移动速度（像素/秒） |
| `strength` | 力量 | 物理攻击力（×1.0） |
| `spell_power` | 法强 | 法术攻击力（×1.0） |
| `attack_speed` | 攻速 | 百分比，+100% → 普攻间隔减半 |
| `physical_resist` | 物抗 | 减物理伤害 |
| `magic_resist` | 法抗 | 减法术伤害（总体） |
| `resist_metal/wood/water/fire/earth` | 金木水火土抗 | 减法术伤害（按五行） |
| `mana_max` / `mana_regen` | 灵力 / 灵力恢复 | 功法消耗资源 |
| `stamina_max` / `stamina_regen` | 精力格数 / 精力恢复 | 弹刀闪避资源 |

**抗性递减**：`减免 = 抗性 / (抗性 + 100)`，上限 **90%**。
法术伤害**同时吃法抗与五行抗**（两个减免相乘）。

### 4.2 玩家基础值（`CharacterData.base_attributes`）

```
气血 100 / 速度 220 / 力量 12 / 法强 10 / 攻速 0
物抗 0 / 法抗 0 / 五行抗各 0
灵力 60 / 灵力恢复 3 每秒（2026-10-19 减半，原 6）
精力 5 格 / 精力恢复 0.25 格每秒
```

### 4.3 伤害公式（`DamageCalc`，全项目唯一入口）

```
物理段 = 物理攻击力 × 技能物理系数
法术段 = 法术攻击力 × 技能法术系数

物理段最终 = 物理段 × 攻击方增伤 × (1 − 物抗减免)
法术段最终 = 法术段 × 攻击方增伤 × (1 − 法抗减免) × (1 − 五行抗减免)

最终伤害 = (物理段最终 + 法术段最终) × 目标易伤系数 × 随机浮动(±5%)
```

- 玩家物理攻击力 = 力量 × 1.0 + 装备 `attack_bonus`
- 普攻：`攻击力 × 兵器系数 × 招式倍率`（**不乘已装配功法系数**）
- 功法：`攻击力 × 兵器系数 × 招式系数 × 功法系数`
- BOSS：`BOSS 攻击力 × 招式系数 × 阶段倍率`（刀客 attack_power = 100）
- **扣抗性只在受击方做**（`DamageCalc.incoming`），攻击方不重复扣

### 4.4 战斗手感参数

| 项 | 值 |
|---|---|
| 三段连击 | 第 3 段为终结技：伤害 ×`FINISHER_COEFF`、范围 ×1.4、后摇 0.5s |
| 闪避 | 时长 0.18s / 冷却 0.5s / 速度 480 / 极限闪避窗口 0.108s |
| 极限闪避奖励 | 回 2 格精力 + 慢动作（时间流速 0.15，持续 0.3s） |
| 弹刀窗口 | 0.22s |

| 完美弹反判据 | 剩余窗口 > 65% |

| 弹刀增伤 buff | 下一次**近战**伤害 ×1.5，命中即消费、不累计、**无任何视觉** |

### 4.5 装备强化（`ItemDB` + `CharacterData.enhance_item`）

| 结果 | 概率 | 效果 |
|---|---|---|
| 成功 | 80% | 随机选面板上**一条**属性，在其区间内 +N，等级 +1 |
| 大成功 | 5% | 同一属性连升两级、两次都取区间**上限**，等级 +2 |
| 失败 | 20% | **不掉等级、不掉属性**，只累加「磨损」 |
| 磨损满 10 次 | — | **破损**：仍可穿戴，强化永久停止 |
| 满 +10 再敲 | — | **进阶**：品阶 +1、等级归 0，不给属性、不计磨损 |
| 分解 | — | 返还**累计消耗晶石的一半**（向下取整） |

强化区间（`AttributeDB.ENHANCE_RANGE`）：力量/法强 1~2、速度 1~2、攻速固定 +1、气血/灵力 2~4、
各项抗性 1、灵力恢复 0.5~1、精力恢复 0.05~0.10；**精力格数不参与**；未登记属性不参与。

**固定攻击力已作废**（`ENHANCE_ATTACK_PER_LEVEL` / `GRADE_ATTACK_PER_TIER` = 0）。

### 4.6 品阶与境界

- 品阶 **7 档**：凡品 → 法器 → 灵器 → 宝器 → 道器 → 仙器 → 神器/先天至宝
  （法宝没有凡品档，最低法器）
- 境界 **5 阶**（练气 / 筑基 / 金丹 / 元婴 / 化神），**只作难度提示，不阻挡进入**

## 7. 关键调用链

### 7.1 一场战斗

```
主城点设施 → primordial_realm._on_facility_activated
  → BattleResolver.start_domain(domain, boss) / start_tower(floor)
      → 写 GameState.battle_context → change_scene(combat_arena)

combat_arena._ready
  → 按 battle_context 决定加载哪个 BOSS 场景（WorldDB.get_boss_scene）
  → BOSS 死亡 → _on_boss_died
      → BattleResolver.resolve_victory()      # 结算：本源 / 塔层感悟（只出结果不写数据）
      → _record_clear_time()                  # 只有塔记录最快用时
      → _spawn_drops()                        # 装备掉落 + 晶石（按通关次数）
      → 字幕播完 → InsightPanel（有待确认功法时）→ confirm_tower_rewards() 才真正入册
```

### 7.2 一次伤害

```
攻击方：player._perform_attack_hit / _apply_skill_hit 或 boss 出招
  → DamageCalc.resolve(ctx)  得到 amount
  → 受击方 take_damage(amount, ...)
      → DamageCalc.incoming(amount, target, kind, element)  # 扣抗性
      → _apply_damage / BossBase 扣血
      → DamageNumber.spawn(...)  # 只在受击方飘字
```

### 7.3 装备位置转移

```
背包 → 穿戴：equip_from_inventory(index)
穿戴 → 背包：unequip_to_inventory(slot)
背包/穿戴 → 铁砧：take_for_forge(index, slot)
```

## 8. 开发规范

1. **全中文注释**：函数头 `##` 写「干什么 / 参数含义 / 有什么坑」；文件头写「负责什么 + 分节索引 + 改数值去哪」
2. **分节标签** `# ===== 序号、中文标题 =====`（`player.gd` 已按「一～十二」分好）
3. **同一逻辑只写一次**：普攻与功法共用 `_damage_bosses_in_shape()`；音效共用 `_make_metal_sound()` 等
4. **数值 / 表现 / 逻辑三层分离**：数值在数据表，形象在 `ArtDB`，玩法代码不写死贴图配色与伤害常量
5. **`var x :=` 推断限制**：不能推断 `Dictionary.get()`、void 返回值、`instantiate()`/`load()`
6. **`const` Dictionary 运行期只读**；**`Node.duplicate()` 只复制 `@export`**
7. **新建 `class_name` 后必须先跑** `godot --headless --path . --editor --quit-after 300` 刷类缓存
8. **多行替换写成 `.py` 文件再执行**：`bash -c "python -c '...'"` 会把 `\n` 吃掉

## 9. 已知坑（都是踩过的）

| 坑 | 说明 |
|---|---|
| `SystemPanel` 是 `CanvasLayer` | 没有 `get_global_mouse_position()`（用 `get_viewport().get_mouse_position()`），也没有 `set_drag_preview()` |
| autowrap Label 塞进 `GridContainer` | 会被压成竖条并把整块区域撑高 |
| `ItemDB._signed_value()` | 返回值自带正负号（如 `"+1.4"`），拼文案别再手写 `+` |
| `queue_free()` 是延迟释放 | 同名新节点入树会被自动改名，需先 `remove_child` |
| z 层级 | 地面 `Ground` z=-10、刀痕 `Visual` z=-1、实体 z=0（曾因刀痕 -2 完全看不见） |
| `boss.tscn` 是回退场景 | 没在 `BOSS_SCENES` 登记的 boss 都用它，所以它的参数（800 血）会影响所有占位 BOSS |
| 旧存档字段缺失 | 新加字段一律给默认值即可，不做版本迁移；法宝老结构有 `migrate_legacy_treasures()` 补齐 |
