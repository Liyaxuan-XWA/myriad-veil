# 音效系统

> 2026-10-22 新增界面音效（用户要求：各种点击都要有声、风格统一、音量一致、不突兀）。
> 全部音效都是**程序合成**的占位音（项目没有音频素材，E 盘美术包里也没有音效目录），
> 后期换成真音频只需替换 `GameState._ui_cache` 里对应条目，**调用方一行都不用改**。

## 1. 两套音效，别混用

| | 战斗音效 | 界面音效 |
|---|---|---|
| 接口 | `GameState.play_sfx(name)` | `GameState.play_ui(name)` |
| 音量 | `-8 dB`（`_sfx_player`） | `-16 dB`（`_ui_players` ×4） |
| 声部 | 1 个 | **4 个轮转**（连点不互相打断） |
| 重复间隔 | `SFX_MIN_INTERVAL = 0.06s` | `UI_MIN_INTERVAL = 0.035s` |
| 现有音效 | `attack_hit` / `player_hit` / `boss_attack` / `phase_change` / `boss_death` | 见下表 |

界面音比战斗音轻约 9 dB —— 这是"不突兀"的第一层保障：点了有反馈，但不抢耳朵。
延后播放用 `GameState.play_ui_delayed(name, delay)`（计时器挂在 autoload 上，
不用面板的 `self`，否则面板在这几十毫秒里被关掉，`await` 恢复会撞上已释放的节点）。

| `forge_success` | 强化成功 | 三音上行 | 290 ms | 958 Hz | 0.24% |
| `forge_great` | 大成功 / 进阶 | 四音上行、更亮 | 300 ms | 1246 Hz | 0.36% |

| `title_charge` | 开始游戏 · 蓄力 | 55→132Hz 上滑；基音让位给 2~4 次谐波 + 摩擦层 | 900 ms | 251 Hz | 0.61% |
| `title_pull` | 开始游戏 · 牵引 | 带通噪声扫频呼啸 + 0.9s 内 3 次气旋摆动 | 1000 ms | 1352 Hz | 8.44% |
| `title_dissolve` | 开始游戏 · 溶解 | 四枚非谐波铃片 G6→C5 + 砂化颗粒 | 550 ms | 1317 Hz | 2.45% |
| `title_collapse` | 开始游戏 · 收束 + 白闪 | 140→34Hz 下潜 + 中频闷拳 + 三枚高频闪耀 | 850 ms | 231 Hz | 0.13% |

> 谱重心与高频占比是 Python 对导出的 wav 做 FFT 实测的。
> 除锤击音（10.62%）与牵引呼啸（8.44%）外全部音效 >4kHz 能量 ≤2.9%，整体听感圆、不刺；
> **锤击音是唯一的例外（10.62%）**——用户明确要"锤击铁器"的真实感，见下一节。
> **`title_*` 四个是过场演出音，不属于"界面点击"那一族**：它们必须带噪声与低频，
> 否则蓄力只剩电子"呜"、收束只剩一声闷屁。但低频也不能任性 —— 第一版 `title_charge`
> 有 99.7%、`title_collapse` 有 99.8% 的能量在 500Hz 以下，手机与笔记本扬声器几乎发不出声，
> 实测后把基音降权、补上 2~4 次谐波与 1kHz 中频闷拳，谱重心提到 251 / 231 Hz 才收工。
> ⚠ **改动过场音后务必重新测一遍这两个数**（<500Hz 占比 >98% 就等于"只有重低音音箱才听得见"）。

### 打铁音的两版演变（2026-10-22）

| | 谱重心 | >4kHz | <500Hz | 头 20ms 能量 | 听感 |
|---|---|---|---|---|---|
| 一版「柔和打铁」 | 574 Hz | 1.93% | 59.7% | 38.2% | 闷、像敲木头，用户反馈"不够铁" |
| **二版「锤击铁器」** | **1537 Hz** | **10.62%** | 40.4% | **43.2%** | 有击打冲击 + 金属亮泽，仍保留铁砧的沉 |

二版怎么做到的：
1. **击打瞬态**：极短高频噪声（decay 130，只有头 20ms），给"啪"的冲击
2. **金属共鸣**：非谐波分音 780Hz × 1.0 / 2.4 / 3.9 / 5.6，频率越高衰减越快
3. **铁砧低频**：150Hz 慢衰减（decay 13），保证不是纯脆响
4. 起音 **1ms**（界面点击是 3ms）—— 锤击必须"打下去"才有力度
5. 最后过 **0.60** 的一阶低通（≈4.5kHz）：保住金属感又不刺耳

⚠ 调风格只改一个数：`_forge_hammer_samples()` 里的 `lp += 0.60 * ...`
→ 更脆 **0.70**，更闷 **0.45**。

## 3. 四条口径（加音效时必须守住）

写在 `game_state.gd` 的 `_setup_ui_sfx` 上方，这里再强调一次：

1. **同一个合成器**（`_ui_tone`）：正弦主体 + 少量谐波 + 3ms 软起音 + 指数衰减。
   界面音**一律不加噪声**（噪声 = "嘶"，在界面上最刺耳）；唯一例外是打铁，噪声压到 0.05 且两级低通。
2. **峰值归一化到 `UI_PEAK = 0.62`**：这是"音量一致"的落地手段。
   实测 11 个音效峰值全部 = 0.6200，极差 0.0000。
3. **独立声部池 + 统一音量 `UI_VOLUME_DB = -16`**：不要给单个音效单独调音量。
4. **音高取自然音阶**（A/C/D/E/G 系）：避免不协和的电子"哔"。

## 4. 挂载点（改交互时对着查）

| 交互 | 位置 | 音效 |
|---|---|---|
| 按钮点击 | `UIKit.button()` 自动挂 | `ui_click` |
| 直接 `Button.new()` 的按钮 | 创建后调 `UIKit.attach_click_sfx(btn)` | `ui_click` |
| 想要别的音色 | `UIKit.set_click_sfx(btn, "ui_tab")` | 任意 |
| 面板打开 / 关闭 | `SystemPanel.open()` / `close()` | `ui_open` / `ui_close` |
| 点击设施（能进） | 面板 `open()` 出声，设施本身不播（避免双响） | `ui_open` |
| 点击设施（未开启） | `primordial_realm._on_facility_activated` | `ui_deny` |
| 拿起锤子 | `forge_panel._pick_hammer()` | `forge_hammer_pick` |
| 放下锤子 | `forge_panel._drop_hammer()` | `forge_hammer_down` |
| 锻造敲击 | `forge_panel._commit_forge()` → `play_ui("forge_hammer")` | `forge_hammer` |
| 锻造结果 | 同上 → `_play_enhance_result_sfx()` 延后 90ms | `forge_success/great/fail` |
| 材料不足 / 铁砧空 | `_commit_forge()` 里 `_forge_block_reason()` 的拒绝分支 | `ui_deny` |
| 穿戴 / 卸下 | `_on_equip()` / `_on_unequip()` | `ui_equip`（失败 `ui_deny`） |
| 页签切换 | `_build_bookmarks()` | `ui_tab` |
| 领奖 / 合成 | `tower_panel` / `forge_panel._try_synthesize()` | `ui_confirm` |

**禁用按钮**：引擎不会为 `disabled` 按钮发 `pressed`，所以 `attach_click_sfx` 额外连了
`gui_input`，禁用态被点会播 `ui_deny` —— 否则玩家会以为界面卡了。

**拖拽**：Button 的 `pressed` 只在"按下并在同一控件上松开"时发，拖拽动作不会触发点击音，不用额外处理。

## 5. 加新音效 / 换成真音频

加一条：

```gdscript
# game_state.gd 的 _ui_cache 里
"ui_xxx": _sfx_wav(_ui_tone(标注频率, 时长, 衰减, [[倍频, 幅度]], 低通系数)),
```

琶音用 `_ui_arp([频率...], 步长, 单音时长, 衰减, 谐波, 低通)`。

换真音频（后续接素材）：

```gdscript
"ui_click": load("res://assets/audio/ui_click.wav"),
```

只要音量（`UI_VOLUME_DB`）和响度大致对齐，其余不用改；`play_ui` 的调用名不变。

⚠ **代码里用的每个音效名都必须真的存在于 `_ui_cache`**：
`play_ui` 遇到不存在的名字会静默忽略（不报错），很容易"以为加了其实没响"。
验证脚本里有一条断言会扫 `scripts/` 下所有 `play_ui("xxx")` / `set_click_sfx(x, "xxx")`，
跟音效表比对——加新音效后跑一次就能发现漏配。

## 7. BGM（2026-10-24，含主城 / 大陆扩展；2026-10-26 补登录界面）

当前 BGM 为**纯 numpy 合成**的无缝循环（可直接试听，正式曲目可替换），
生成器：`tools/gen_battle_music.py`，重跑即可覆盖全部 WAV。
统一播放器：`scripts/audio/bgm_player.gd`（`BgmPlayer`，处理循环、淡入淡出、暂停继续）。

| 曲目 | 文件 | 风格 / 用途 |
|---|---|---|
| `battle_wuxia` | `assets/audio/bgm/battle_wuxia.wav` | 国风武侠 · 战斗随机池 |
| `battle_tense` | `assets/audio/bgm/battle_tense.wav` | 紧张压迫 · 战斗随机池 |
| `battle_epic` | `assets/audio/bgm/battle_epic.wav` | 史诗管弦 · 战斗随机池 |
| `realm_primordial` | `assets/audio/bgm/realm_primordial.wav` | 原初位面 · 空灵舒缓 |
| `world_continent` | `assets/audio/bgm/world_continent.wav` | 苍澜大陆 · 木琴/石片打击 + 合成器低音（**无弦乐、无低频律动**，危机感、不吵、不诡异） |
| `title_veil` | `assets/audio/bgm/title_veil.wav` | 登录界面 · **神秘涌动**（B 小调 pad + 50BPM 心跳 + 古琴泛音 + 钟磬；2026-10-26） |

- 除 `title_veil` 外全部 48 秒；`title_veil` 为 **44 秒**（见下方「登录界面」一节的折叠处理）。
- 全部 32 kHz、16-bit 立体声；首尾各 8ms 淡入淡出保证循环无缝（`title_veil` 例外，走折叠交叉淡化）。
- **战斗三曲随机轮换**：`CombatArena` 每次开战从洗好的牌堆抽一首，三首抽完再洗牌；不再绑定 BOSS / 关卡。
- **主城**：`primordial_realm` 循环 `realm_primordial`，淡入 2.2s。
- **苍澜大陆**：`secret_world` 循环 `world_continent`（**木琴/石片打击 + 合成器低音**；无弦乐、无低频鼓点/心跳、无钟声/风声/怪异高频），淡入 2.0s；死亡时淡出，撤离时淡出。
- **登录界面**：`title_screen` 循环 `title_veil`（常量 `BGM_TITLE`），`AMBIENT_VOLUME_DB - 1`（-21dB）、淡入 2.4s；按下「开始旅程」后 0.68s 起 `fade_out(0.7)`，1.38s 收干净、1.44s 切场景。
- `BgmPlayer` 复制 WAV 后设 `LOOP_FORWARD` / `loop_end=总帧数`；战斗目标音量 `BATTLE_VOLUME_DB = -18`，主城 `AMBIENT_VOLUME_DB = -20`，苍澜大陆与登录界面再降 1dB（-21）。
- 播放器 `PROCESS_MODE_ALWAYS`：打开角色 / 感悟 / 轮盘面板暂停游戏时 BGM 仍继续。
- 换正式音乐：替换同名文件或改各场景常量；循环点也可在导入设置里改用 `edit/loop_mode`，代码运行时设置仍兼容。

### 登录界面 BGM 的两个坑（2026-10-26）

1. **`env_adsr` 的衰减会把之后整段都当 release 斜坡** —— 12 秒的 pad 从第 2.5 秒起一路衰减到 0，
   曲尾必然是静音，循环起来「每 44 秒断一次气」。登录界面这首改用 `hold_pad()`（真 ADSR，起音后满幅保持），
   首尾都是满幅才接得上。**任何"持续垫底"的曲子都不能直接用 `pad()` / `synth_drone()`。**
2. **首尾能量对不上也要处理**：即便两端都不静音，0 秒处的磬与低音起音会让曲首比曲尾响 3 倍（实测 RMS 0.22 vs 0.07）。
   用 `tools/loop_title_bgm.py` 把尾巴 4 秒等功率叠进头部，循环体变 44 秒，接缝跳变降到曲内最大跳变的 0.09×。
   → 该脚本也用于「Suno 等外部生成的整首曲子」：`--seconds` / `--xfade` / `--offset` 可调。
