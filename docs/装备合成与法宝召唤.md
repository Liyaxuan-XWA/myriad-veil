# 装备合成台 · 元魂 · 召唤法宝

> 2026-10-21 用户需求落地。本文写规则、用法与**美术替换口**。

## 1. 元魂掉落

| 项 | 规则 |
|---|---|
| 掉落场景 | **只在万界塔**，且该层已进入「血量翻倍」阶段（该层第 11 次挑战及以后） |
| 概率 | **50%** |
| 数量 | 每次 1 枚，**不限次数**（2026-10-21 晚改：取消「每种只掉一次」的限制） |
| 对应关系 | 打哪名 BOSS 掉哪一枚：虎妖→虎妖元魂、刀客→刀客元魂、剑客→剑客元魂 |
| 品质 | 紫色（`rarity: "epic"`，配色走 `ItemDB.rarity_color()`） |
| 处置 | **不可丢弃、不可分解** —— 背包「丢弃」只对装备开放，分解只对铁砧上的装备生效，材料不会进这两条路径 |

判定用的是 `CharacterData.tower_hp_multiplier(floor) >= 2.0`，与血量成长同源——**血量翻倍 = 元魂开始掉**，不会出现"血量没翻倍却掉元魂"。

## 2. 合成台

位置：装备锻造台 → 顶部 **「熔铸」** 页（旧版左侧「合成」书签已并入熔铸）。

| 格子 | 放什么 |
|---|---|
| 第 1 格 | BOSS 元魂（任意一枚） |
| 第 2 格 | **该 BOSS 掉落、且已破损**（累计 10 次强化失败）的装备 |
| 第 3 格 | **留空**（本配方不需要，放什么都不影响） |

点击格子 → 下方列出可选材料 → 点材料放入。点已放入的格子可重新选。

**防呆（2026-10-21）**：另一格已经放了材料时，候选列表会**自动筛成同一个 BOSS** 的搭档
（放上虎皮袍后，元魂只列虎妖元魂），选不出跨 BOSS 的错配组合；
万一配不出来，结果行会直接写明原因（例如「元魂与装备必须来自同一个 BOSS」），而不是只把按钮变灰。

### 配方表（`ItemDB.SYNTH_RECIPES`）

| BOSS | 元魂 | 可用的破损装备 | 产物 |
|---|---|---|---|
| 虎妖 `boss_huyao` | 虎妖元魂 | 虎皮袍 | 虎妖令 |
| 刀客 `boss_01` | 刀客元魂 | 弯刀 | 刀客令 |
| 剑客 `boss_01_c` | 剑客元魂 | 清风剑 / 清风鞋 | 剑客令 |
| 两仪真人 `boss_02` | 两仪真人元魂 | 两仪玉玦 / 玄素道袍 | 两仪令 |
| 定阵先生 `boss_02_b` | 定阵先生元魂 | 朱弦阵尺 / 定阵缠手 | 阵旗令 |
| 太虚气君 `boss_02_c` | 太虚气君元魂 | 太虚云履 / 气海玉坠 | 气君令 |
| 赫连霄 `boss_03` | 赫连霄元魂 | 雷纹护臂 / 判官铁笔 | 判官令 |
| 离照 `boss_03_b` | 离照元魂 | 烬纹战袍 / 逐日履 | 火正令 |

- 装备必须**已破损**（`is_broken = true`）才可选，未破损的不会出现在候选里
- 合成**消耗**元魂 ×1 与那件破损装备（装备熔掉，不可恢复）
- 产物是**法宝**（`equipment_type = "treasure"`），进背包，可装备到法宝槽

## 3. 召唤法宝

装备到法宝槽（法宝一 / 二 / 三）后，战斗中按 **1 / 2 / 3** 催动：

### 战斗内法宝栏

技能栏（Q/E/R/T）**左边**有一排 3 格法宝栏：

- 每格左上角是按键数字 1/2/3，中间是法宝图标，空槽显示「空」
- 召唤后该格进冷却：图标压暗 + 中心显示剩余秒数，转好后自动恢复
- 布局常量在 `combat_arena.gd` 顶部：`TREASURE_SLOT_SIZE` / `TREASURE_SLOT_GAP` / `TREASURE_BAR_MARGIN`
- 位置由「技能栏左边界 − 间距 − 栏宽」算出，改技能栏格数时法宝栏会自动跟着挪

| 项 | 数值（模板 `TREASURE_TEMPLATES`） |
|---|---|
| 持续 | `summon_duration` = 20 秒 |
| 召唤物血量 | 本体基础血量 × `summon_hp_ratio`（0.5） |
| 召唤物伤害 | 本体伤害 × `summon_damage_scale`（0.7） |
| 冷却 | `summon_cooldown` = 60 秒（按法宝 id 记，跨战斗保留，**不消耗法宝**） |

### 行为

- 召唤物复用**原 BOSS 的场景与 AI**，只是把阵营翻到玩家这边：追击最近的敌方 BOSS、照常出招
- 头顶有绿色「**友军**」标签 + 绿色血条，与敌方一眼区分
- **有独立血量**：敌方 BOSS 的扇形/圆形/矩形攻击会把它当目标之一（按它自己的位置判定），会被打死
- 玩家**打不到**召唤物（它不在 `boss` 组），也不会干扰 BOSS 血条与战斗结算
- 20 秒到 / 被打死 → 缩小淡出消散，**不触发 `died`**，不影响"是否通关"的判定

### 穿戴：从背包拖进已穿戴区（2026-10-22）

法宝和普通装备走**同一条拖放路径**，不需要额外操作：

- 锻造台「背包素材区」→ 拖到左侧「已穿戴」的**法宝一 / 二 / 三**任一格，松手即穿戴
  （拖拽数据 `kind = "bag_equipment"`，`equipment_type = "treasure"`，
  落点判定 `slot_accepts("treasure_N", "treasure")`）
- 拖到武器/护甲/饰品槽会被拒绝（部位不匹配）
- 换装到**同一个法宝槽**允许——旧的自动回背包（所以可以拿强化更高的同款替换）
- 左键卸下、右键看属性，和装备格一致

### 同一种法宝 / 饰品不能重复佩戴（法宝 2026-10-22、饰品 2026-10-31 用户定）

- **判定口径**：按**模板 id**（`tr_huyao_ling` / `eq_huyaxianglian` 这种）。同一种装备即使强化等级/磨损不同，
  也算"同一种"，不能各占一个槽。只对多槽类别生效：**饰品 3 槽、法宝 3 槽**；武器/护甲/鞋各只有一槽，天然不重复
- **三层拦截**：
  1. UI 拖放 `_can_drop_on_worn()`（锻造台）/ 角色面板悬停 `_can_drop_data()` —— 鼠标经过目标槽时就显示"不可放置"，松手不生效
  2. `equip_from_inventory()` —— 在 `inventory.remove_at()`**之前**拦，否则会先移出背包又没穿上，物品直接丢失
  3. `equip()` —— 最后一道防线（`push_warning` + 不穿），防未来新代码绕过
- **提示文案**：「『虎牙项链』已经戴在【饰品一】了。」（状态栏，红色）
- **换装到同一槽不算重复**：`equip_dup_slot(item, except_slot)` 会跳过目标槽自己；
  同一件**对象**换槽（`is_same`）也不算重复——它只会从旧槽挪走
- 相关函数：`CharacterData.equip_dup_slot(item, except_slot) -> String`（返回已占用该装备的槽位，空串 = 无冲突）
- **旧档迁移**：读档时 `migrate_duplicate_accessories()` 把多戴的同款饰品挪回背包；
  背包到软上限时允许临时超出一格，仍强制去重，不吞装备
- ⚠ `equip_treasure()` 现在**返回 bool**（是否真穿上）：调用方在 false 时必须把物品放回背包，
  否则会凭空消失（`ensure_starting_treasures` 已按这个口径改）

## 3.5 法宝锻造与分解（2026-10-21 晚）

法宝（BOSS 令）**和装备一样可以放上铁砧强化**，规则差异只有一条：

- 每强化成功 **1 级** → 召唤物的**气血与攻击各 +基础值的 2%**
  （大成功算 2 级 → +4%），跨进阶累积
- 每**进阶成功**一次 → 召唤物的**存在时间 +5 秒**（失败不加），可无限累积；
  同时按**进阶前累计召唤加成的一半**再追加（2026-10-24 定的装备进阶奖励，法宝同享），
  写入小数字段 `summon_ascend_boost_pct`
- 法宝模板的 `attributes` 是空的，普通强化不会加词条，所以它的成长完全走这条线
- 强化提示会直接写「召唤物气血与攻击 +2%（累计 +X%）」/「召唤时长 +5 秒（累计 +X 秒）」

### 境界锁（2026-10-24）

- `ItemDB.REALM_GRADE_CAP`：练气→法器、筑基→灵器、结丹→宝器、元婴→道器、化神→仙器。
- 装备品阶到达当前境界上限后，**整件停敲**（+N 与进阶都锁），突破后自动解锁。
- ⚠ 法宝初始品阶为**法器** → **练气期三件法宝全部锁死**，筑基后才能继续强化。
- 拦截在 `CharacterData.enhance_item()` 扣晶石之前；锻造台与背包详情会显示具体原因。

### 上限与破损（与普通装备完全一致）

- 满 10 级 → 下一次敲击变成**进阶**（品阶 +1、等级归零、加成保留）
- **品阶到顶（神器/先天至宝）+ 满 10 级 → 不能再强化**（召唤法宝没有例外）
- 累计 **10 次失败** → **破损**：强化永久停止，但**法宝仍可装备、仍可正常召唤**
- 破损法宝只能在锻造台分解

### 分解返还

普通装备：返还「自身强化消耗晶石的一半」。

召唤法宝**两笔都算、各返一半**：

```
返还 = floor((法宝自身强化消耗 + 合成时熔掉那件破损装备消耗) / 2)
```

- 合成时会把那件破损装备的 `enhance_crystal_spent` 记到法宝实例的 `synth_crystal_spent`
- 所以一件「花过 9 颗晶石才敲坏的虎皮袍」合出来的虎妖令，分解返还 4 颗
- 法宝自己再强化花掉的部分，也同样按一半计入

数据字段（都在 `CharacterData.make_treasure_instance` 里初始化为 0）：

| 字段 | 含义 |
|---|---|
| `summon_boost_count` | 强化成功的累计级数（每级 +2% 气血/攻击） |
| `summon_ascend_boost_pct` | 进阶奖励累计的**额外百分比**（每次加进阶前累计加成的一半，可带小数） |
| `summon_duration_bonus` | **进阶成功的次数**（每次 +5 秒存在时间） |
| `synth_crystal_spent` | 合成时熔掉的破损装备花过的晶石（分解按一半返还） |

### 背包详情显示的数值（2026-10-21）

模板 `desc` 里那句「…助战 **20 秒**」是**写死的底稿**，升级后不会变。
详情里显示的真实数值一律由 `ItemDB.treasure_effect_lines(item)` **现算**（背包详情与已穿戴 tooltip 共用）：

```
召唤时长：30 秒（基础 20 + 进阶 +10）
召唤物气血与攻击：+10%
冷却：60 秒
```

- 时长 = `summon_duration` + `summon_duration_bonus × 5`
- 加成 = `summon_boost_count × 2 + summon_ascend_boost_pct`（%）；整数时不显示小数，否则保留一位
- 描述行会把底稿里写死的「 20 秒」抹掉（`treasure_desc_without_duration`），避免和上面这行打架
- 🚫 别把真实数值写回 `desc` / 模板：以后改数值要改多处，必然漏

### 伤害加成覆盖范围（2026-10-21 修）

召唤物的伤害倍率 = `summon_damage_scale(0.7) × (1 + 0.02 × summon_boost_count + summon_ascend_boost_pct / 100)`，
存在实例的 `ally_damage_scale`。**凡是召唤物打出的伤害都要乘它**，目前四条路径：

| 路径 | 位置 | 怎么乘 |
|---|---|---|
| 近战 / 范围 | `BossBase.deal_damage_to()` | 函数内统一乘 |
| 远程投射物 | `boss_projectile` | `_spawn_projectile` 把倍率写进 `ally_scale`，命中时乘 |
| 天剑阵（剑客） | `sky_sword._hit_player` | 生成时写 `ally_scale`，命中时乘 |
| 刀痕激活（刀客） | `blade_scar._slash_enemies` | 生成时写 `ally_scale`，结算时乘 |

⚠ 后三条是**直接调 `take_damage`** 的，走不到 `deal_damage_to()`——新增任何「BOSS 之外的伤害实体」
（新的召唤物、机关、地面效果）都要照这个模式把 `ally_scale` 带过去，否则召唤物升满级还是原伤害。

### 友军外观（2026-10-21 用户定）

- **自身变暗**：`SkinVisual.render_node` 的 `modulate` 压到 `Color(0.52, 0.48, 0.60)`
  > ⚠ 不能改 BOSS 的 `Visual.modulate`：基类 `_flash_attack` 会把它覆盖成白色再还原，变黑会被冲掉。
  > 改 `render_node` 是叠在上层的，不受影响；头顶血条也不在 `Visual` 下，不会被压暗。
- **身边冒黑气**：召唤时挂一个 `BlackSmokeTimer`（每 0.25 秒在身体周围随机位置冒一团），
  特效走 `ArtDB.EFFECTS.fx_summon_black_smoke`，召唤物销毁时 Timer 一起释放
- 头顶仍有绿色「友军」标签 + 绿色血条

### 底层实现（改机制时看这里）
| 位置 | 作用 |
|---|---|
| `BossBase.is_ally` / `summon_life` / `ally_damage_scale` | 召唤物标记与参数，**必须在 `add_child` 之前设** |
| `BossBase.deal_damage_to()` | 按目标类型选签名（玩家 4 参 / BOSS 5 参），召唤物伤害倍率在这里生效 |
| `BossBase.attack_units()` | 敌方 = 玩家 + 所有友军；友军 = 只有自己的 target |
| `Player._try_summon_treasure()` / `_summon_ally_boss()` | 按 1/2/3 使用法宝、实例化友军 |
| `boss_projectile` | 友军的投射物 `collision_mask` 改打 BOSS 层，命中走 BOSS 版签名 |

## 4. 美术替换口（长期约定：素材后置）

| 要换的东西 | 改哪里 |
|---|---|
| 元魂图标 | `ItemDB.MATERIALS` 里 `soul_*` 条目的 `icon` 填 `res://assets/ui/icon/...` |

## 野外修士法宝：按境界分档的携带池（2026-10-24 / 10-25，2026-11-07 接线）

野修法宝**不走合成台**：苍澜大陆的野外修士出生时按所在区域，从
`SecretWorldDB.get_cultivator(rid).treasure_pool` **必定携带一件**（`treasure_carry_chance = 1.0`，池内等概率）；
携带者会在战斗中主动使用，**死亡时 100% 掉落这一件**，掉进局内背包，撤离后进入永久背包。

| 区域（境界） | 配置表 | 池内件数 | 相较上一档新增 |
|---|---|---|---|
| 青岚野（练气） | `CULTIVATOR` | 3 | 凝水佩 / 逐电环 / 禁步桩 |
| 云隐谷（筑基） | `CULTIVATOR_ZHUJI` | 6 | 断念铃 / 棘甲佩 / 回风袋 |
| 赤金丹霞（结丹） | `CULTIVATOR_JIEDAN` | 9 | 续命灯 / 血饲印 / 换位玦 |
| 幽冥灵墟（元婴） | `CULTIVATOR_YUANYING` | 10 | 蚀甲锥 |

> ⚠ 2026-11-07 之前 `_roll_cultivator_treasure()` 写死读 `CULTIVATOR`，四个区一律只掉练气那 3 件，
> 后三档追加的 7 件「配置登记了却永远掉不出来」。现已改为按 `rid` 取分档表，出生 / 死亡兜底 / 兜底概率三处同源，
> 并由 `tools/probe_wild_treasures.gd:_check_runtime_pools()` 从真实入口采样守住四区 3/6/9/10 件齐且不多。

### 掉落 → 合成全链路自检（2026-11-07）

`tools/probe_plane_treasure_pipeline.{gd,tscn}` 从**真实入口**验，而不是只查表登记（项目踩过「表里登记了、运行时读的是写死基准表」的坑）：对 `WorldDB.DOMAINS` 的 12 只 BOSS 各调 `ItemDB.roll_boss_drops()` 采样 400 次，守住 20% 掉率、装备掉落未被挤掉、结算数量 = 实得数量、`add_item` 后进永久背包；再对 `PLANE_TREASURE_RECIPES` 四条配方各自走 `ForgePanel._try_synthesize()`，验乱序识别 / 三件材料清零 / 产物入包 / 可装备 / 主动数值可读；另验跨位面混投被拦且不损失材料、合成动画期间关闭面板产物不丢。运行：`godot --headless --path . res://tools/probe_plane_treasure_pipeline.tscn -- --no-save`（**必须带 `--no-save`**，探针会清背包）。

本轮修掉两处真实缺陷：

- `forge_panel.gd:_run_synthesis()` 原先在 1.15 秒炉火 `await` 之后才把产物入包，面板在动画期间关闭 / 切场景时 `is_inside_tree()` 早退会**吞掉整张配方**（材料已扣、产物没了）。改为函数开头无条件 `return_item_or_force()`；位面法宝与「元魂 + 破损装备」两条合成路径共用本函数，同时受保护。
- `item_db.gd:roll_boss_drops()` 的材料分支只写顶层 `count`，但拾取读的是 `d["item"]["count"]`（`make_material_drop` 恒为 1）。已两层同步；当前 12 条都是 `count: 1`，无数值变化，防的是日后调成 2 时「结算文案说掉 2、实得 1」。

**掉落口径边界（设计如此，不是 bug）**：位面材料只在**界域 / 位面 BOSS 战**与**万界塔投影**（`_spawn_drops()` 只排除 `SOURCE_WORLD_CORE`，塔层仍会摇本体掉落表）走 `DROP_TEMPLATES` 的 20%；大世界**核心重战**被显式排除，只掉本区装备 + 锻造晶石，避免重复刷首杀材料；**演武场**（`start_arena()` 不写 `boss_id`）与**棋坛**完全不发 BOSS 掉落。材料存进**仓库**后不计入锻造台候选（候选只扫 `CharacterData.inventory`），要先取回背包。三件各自独立 20%，凑齐一套期望约 15 次击杀。

**两仪令**：`tr_liangyi_ling`，召唤类法宝；两仪真人元魂 + 任一破损的两仪装备在锻造台熔铸；召唤两仪真人助战 20 秒（伤害 ×0.7、气血 ×0.5），冷却 60 秒。元魂只在塔第 4 层第 11 次及以后 50% 掉落（与其他 BOSS 同规则）。
