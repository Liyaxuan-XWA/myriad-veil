# 原初位面四周屏障（2026-10-22 用户定）

> 玩家活动范围 = **地面美术的可见范围**（读 `Ground/Skin` 的实测矩形，换了地图自动跟着变，不用手改数字）。
> 当前实测：2488 × 1400（x ∈ [-1244, 1244]，y ∈ [-700, 700]）。

## 三层限制（缺一层都会漏）

| 层 | 作用 | 实现 |
|---|---|---|
| ① 镜头 limit | 镜头视口不越过地面边缘 | `Camera2D.limit_left/right/top/bottom` = 地面矩形 |
| ② 碰撞墙 | 人走不出去 | `StaticBody2D"Barrier"` + 四面 `RectangleShape2D`，第 1 层（玩家 mask=1） |
| ③ 能量光墙 | 让玩家看得见边界 | 4 层叠宽柔光 + 1 层能量流，全部 `Line2D` + 程序化 shader |

## 能量墙的外观怎么来的（2026-10-22 第二轮：灵力波动 + 能量流转）

只画纯色线会「太生硬」，现在由 `assets/shaders/barrier_flow.gdshader` 生成：

| 观感 | 实现 |
|---|---|
| 能量流转 | 两层值噪声按**不同速度/方向**沿世界坐标流动（主流向 + 回卷次级流），再乘 `flow_contrast` 拉开亮暗 |
| 灵力波动 | 低频正弦「一呼一吸」，**相位按世界坐标错开**（`world.x*0.006 + world.y*0.0045`），同一圈墙不会一起亮暗 |
| 纵向柔边 | **4 条不同宽度的线叠加**（86 / 63.6 / 43 / 25.8，alpha 0.14→0.30）+ 内层 13px 能量流（alpha 0.95） |
| 与地图融洽 | 配色取地图灵脉的青绿（core `(0.80,1.0,0.98)` / glow `(0.26,0.80,0.90)`） |

参数全在 `ArtDB.VISUALS["realm_barrier"]`：`flow_speed / turbulence / flow_contrast / pulse_speed / pulse_amount /
barrier_width / core_alpha / glow_width / glow_alpha / core_color / glow_color / shader`。

### 两个必踩的坑（Shader 相关，别再试）

1. **`MODEL_MATRIX` 在 canvas_item shader 里不存在**（那是 spatial 的）→ 用 `VERTEX` 的本地坐标；
   光墙节点挂在场景原点、无旋转缩放，本地坐标就是世界坐标。
2. **不要用 `UV.y` 做纵向柔边**：Line2D 没贴图时 UV 取值不可靠（实测 `UV.y` 不是 0~1），
   `1 - abs(UV.y*2-1)` 会直接把 alpha 算成 0 → **整面墙消失**。柔边改用「多条不同宽度的线叠加」。
3. 呼吸不要再用 tween 改 alpha：两层线各自 tween 会同步闪，看起来是「整块亮暗」而不是灵力流动。


## 为什么墙要「内缩 56px」

`const BARRIER_INSET := 56.0`

如果碰撞墙和光墙都贴在地面边缘，而镜头 limit 也贴边，**光墙会正好落在屏幕最外沿**，
玩家贴着墙也几乎看不见它（2026-10-22 实测截图确认）。

做法：**镜头 limit 用地面矩形，墙与光带向内缩 56px**。
于是人被墙挡住时，镜头还能往外带 56px，那一圈光带就露在屏幕里侧，看得很清楚。

## 调参位置

- 墙的位置/厚度：`primordial_realm.gd` 的 `BARRIER_WALL_THICKNESS(40)` / `BARRIER_INSET(56)`
- 光墙外观：`ArtDB.VISUALS["realm_barrier"]`（见上一节表格）
  - 想改用贴图：填 `texture`（沿环平铺）并把 `shader` 留空
- 光墙 `z_index = -5`：压在地面(-10)之上、设施(-1)之下，不会盖住设施画面

## 换地图会怎样

`_setup_barrier()` 读的是 `Ground/Skin.visual_rect`（SkinVisual 按贴图实际内容算出来的尺寸），
所以把 `assets/scenes/primordial_realm_ground.png` 换成别的比例的图，屏障范围会自动跟着变。
⚠ 前提是贴图真的接上了：如果走占位（`visual_rect` 太小），会跳过屏障并打一条 warning，
避免把玩家锁死在原点附近。
