# BOSS 设计规范

> 本文整理自用户 2026-10-27 的需求说明，是设计与制作新 BOSS 时必须满足的要求。
> 条目顺序即制作顺序：模板 → 机制 → 技能 → 数值 → 行为树 → 掉落 → 美术 → 验证 → 接入。

---

## 一、基础模板

- 所有 BOSS 必须遵循基本 BOSS 模板：**二阶段**。
- 攻击类型限定在既有体系内（**法术攻击**与**物理攻击**等），不另起新类型。

## 二、核心机制（每只必须独有）

1. 每一只 BOSS 都要设计**一个独特的机制**。
2. 先**头脑风暴多个**独特机制，再**择优选择**。
3. 机制要**由技能组联动**展现。
4. 玩家侧使用这套技能组时，也要能**正常使用同一机制**
   （例：刀客的刀痕、剑客的剑意）。
5. **不要被已有机制局限住**，要放开想象。
6. 机制**不能与已有的 BOSS 机制雷同**。

## 三、技能设计

- 技能不仅要能展示和运用本 BOSS 的机制，**形态也要各异** ——
  毕竟是修仙游戏，功法要各种各样。
- **技能飘字必须是前摇的第一帧**：只报招名，`hold` 至少盖住前摇；释放阶段只出特效，不再补报一次。
  **招名后不加应对语句**（2026-10-31 用户定，如「离开落点」「打断它」「停手」都不要），
  机制读法交给动作、预警圈、状态提示与图鉴。
  特例：结果类提示（破盾 / 弹刀 / 打断 / 转阶段）跟着事件本身走，不提前，也不挂进招名。
- 技能可以设计、并结合各种 **buff 和 debuff**。
- 技能的数值设计要合理，要注重**玩家侧的实际使用**。
- **默认全部招式都可学**（用户 2026-10-27 定）：不要因为「和另一门位移技同型」
  就把招式留在 BOSS 侧。位移 / 防御类招法的分工按**它喂的是哪个机制**来判定，不按形态判定 ——
  破步突进斩留刀痕、剑客四式（刺/撩/劈/云）攒剑意、三叠踏叠两仪势，形态相近而用途不同。
- 可学功法要**成组地给出取舍**（快捷位只有 Q/E/R/T 四格），
  让玩家有得挑：站桩输出 / 贴脸位移 / 不瞄准领域 / 远程双色 / 防御转势 / 收割 / 节奏技。

## 四、数值设计（从玩家当前强度反推）

BOSS 数值要按玩家当前的整体情况反推，**不能过难也不要过简单**：

- 玩家当前能达到的**境界**所提供的属性；
- 玩家当前装备的**最高强化数值**；
- 玩家当前的**养成情况**（功法 / 法宝 / 丹药等整体进度）。

### 反推口径（2026-10-29 结丹档实测定标）

1. **先量面板，不估算 DPS**：用无头探针把标准档装备穿齐，直接读
   `max_hp / physical_attack / spell_attack / 物抗 / 法抗 / attack_interval`。
   结丹初期标准档（灵器 +6）实测：279 血 / 99 物攻 / 66 法攻 / 物抗 33 / 法抗 42。
2. **普攻 DPS**：三段一轮 = 普通间隔 × 2 + 终结间隔（1.42×），系数 1 / 1 / 1.8。
   结丹档一轮约 1.0 秒、376 伤害；真人 2.5 刀/秒 ≈ 313 DPS，满速 3.2 刀/秒 ≈ 376 DPS。
   功法施法会挤占普攻，不能把功法 CD DPS 直接加到普攻 DPS 上。
3. **TTK**：目标 60~80 秒，按走位/躲招损耗 25~40% 折算有效输出，再反推血量。
   赫连霄按此取 **13,000 血**（原 5600 血 = 20 秒被打穿）。
4. **BOSS 攻击**：按「玩家吃 3~5 下大招收命」反推**过抗后**单下伤害，再除抗性还原成攻击力。
   赫连霄取 **90 攻**：主招过抗后 55~95，结丹初期 3~5 下死。
   离照（塔 8）在同一结丹中期标准档下取 **15,500 血 / 96 攻**；它的 15% 持种减伤
   把「放着火种不管」的等效血量抬到约 18,200，机制本身承担一部分耐久。
5. **改动最大气血后，必须复查所有按 `max_hp × 百分比` 结算的门槛**
   （引导打断、护盾、回血、处决线等），否则血量一抬，门槛会悄悄失效。
   例：赫连霄聚雷打断从 8% 下调到 2.5%。

## 五、行为树与应对

- 行为树设计要**灵活多变**；实战中**每个技能都要有机会使用**，都要有对应的**应用场景**。
- BOSS 可以**有弱点**让玩家利用，但**不能让玩家逃课**。
- BOSS 要有**针对自身弱点的应对行为**：
  - 贴脸虎妖 → 它会后跳；
  - 拉扯虎妖 → 它会贴脸；
  - 刀客容易被拉扯，但有**破步**技能拉近距离；
  - 刀客还能**弹刀**反制远程拉扯。

## 六、掉落装备

- 掉落装备要按玩家当前的整体情况设计 —— **玩家缺什么就设计什么**。
- **不与已有装备的用途重复**：
  - 弯刀：主打暴力输出；
  - 清风剑：输出与精力恢复平衡，更加灵活多变。
- 装备**不需要数值膨胀**，只需要**用途的差异**。

## 七、位面专属材料与法宝（第二位面起）

- 从第二位面开始，每个位面的**三只 BOSS 各掉落一件专属材料**。
- 集齐同一位面的**三件专属材料**，可以**合成一件该位面专属法宝**。
- 法宝的作用设计要**灵活多变**，可以是：
  - 攻击向；
  - 防御向；
  - 增益向（buff）；
  - 削弱对方（强力的 debuff）；
  - 各种不同的机制（例如瞬移、格挡、CD 刷新、法阵等）。

## 八、美术设计

**BOSS 的内核设计完成之后，才开始设计美术**，顺序如下：

1. 各种**掉落物**的美术；
2. BOSS 的**整体形象**设计 —— 不要和前面的 BOSS 设计雷同；
3. BOSS 的**地图纹理** —— 要符合该 BOSS 的形象；
4. 相关**元魂、BOSS 令、法宝**的美术。

另外：

- 一个 BOSS 的**技能特效要内部统一化**；特效设计要对标之前的 BOSS 特效设计，**但不要雷同**。
- 开始制作 BOSS 形象时，**先设计原型图**；原型图的设计要利于后面的**骨骼动画**制作。
- 骨骼动画要**流畅**，**不要粘连服饰**之类的；**骨骼关节处运动时不要有白色缝隙**；
  **动作设计要和技能相符合**。

## 九、验证与测试

- BOSS 整个实现落地过程中，要**不停地验证**，确保它正确地应用到了项目中。
- 整体落地之后，还要进行**完整的玩法机制测试**，**不要有 bug**。
- 特别是：**玩家侧的技能是否可以完整继承机制玩法**。

## 十、接入手续

- BOSS 要按规范**同步接入万界秘境和万界塔**。
- 新增的**材料、道具、法宝**都要**记录图鉴**。
- **机制介绍也要记录**。

## 验收清单

- [ ] 二阶段；攻击类型在既有体系内（法术 / 物理等）
- [ ] 独有机制：先头脑风暴多套 → 择优
- [ ] 机制由技能组联动展现
- [ ] 玩家侧使用同技能组也能正常使用该机制
- [ ] 与已有 BOSS 机制不雷同，且未被已有机制局限
- [ ] 技能形态各异，可结合 buff / debuff，数值经玩家实测
- [ ] 数值按玩家境界 / 最高强化 / 养成整体反推，难度不过高不过低
- [ ] 行为树灵活：每个技能都有使用机会与应用场景
- [ ] BOSS 有可利用的弱点，但有应对行为，玩家无法逃课
- [ ] 掉落装备补玩家缺口，用途不与已有装备重复，无数值膨胀
- [ ] （第二位面起）三只 BOSS 各掉一件专属材料 → 合成位面专属法宝
- [ ] 美术顺序正确：掉落物 → 形象 → 地图纹理 → 元魂 / BOSS 令 / 法宝
- [ ] 同 BOSS 技能特效内部统一，且与旧 BOSS 不雷同
- [ ] 先出原型图（利于骨骼）；动画流畅、不粘连服饰、关节无白缝、动作对技能
- [ ] 落地全程验证；整体玩法机制测试无 bug；玩家侧完整继承机制玩法
- [ ] 接入万界秘境 + 万界塔；材料 / 道具 / 法宝入图鉴；机制介绍已记录
