## 方案 A（推荐）：「执烛」—— 投影 · 身外之影

**一句话**：它自己不打人，**它投在地上的影子才是判定**；影子永远落在背光一侧、长度随它离灯的距离变化 —— 所以「把它逼到灯下」就是拆它的招，而它每一步走位都在挣影子长度。

- 场中央挂一盏照影界灯（静态光源，地面画光向渐变 + 一条从灯到它的淡光束）。
- 影子 = 本体沿「灯→本体」方向的反向延长，长宽随距离线性放大：贴灯时只剩脚下短刃，退到边缘时能拉到 600px 外、扇面张开。
- 读数完全靠**动作与位置**：地上那条黑刃朝哪、多长，就是它这一招能打多远。没有条、没有层。

**八式**（职能互不重复，没有一招是「+1 资源」的凑数招）

| 招式 | 形态 | 职能 | 影子规则怎么用上的 |
|---|---|---|---|
| 影削 | 本体身前扇形，物理，可弹反 | 近身基础 | 贴灯时它只剩这招 |
| 投晷 | 影子末端的直线刺，物理，可弹反 | 中远程主攻 | 射程＝当前影长；影不够长就不会出招（不许空放） |
| 缚影 | 影手抓玩家影子 → 定身 1.2s + 一斩 | 控制 | 起手瞬间你在移动，抓到的就是空影，只留一段减速墨痕 |
| 踏波 | 掠向侧后方的位移，掠过的走廊上影子先行横扫 | 位移 / 反风筝 | 逼它离开灯时它用这招抢回边缘；确认真的位移 |
| 明灭 | 4s 压暗全场，影子几乎消失 | 自我保护 / 节奏 | 你把它逼到灯下它反而变凶：攻速 +30%、本体伤害 ×1.35 —— 弱点是收益交换，不是白嫖 |
| 照骨 | 本体直线水属性光束，不可弹反 | 远程术法压力 | 光束扫过你的影子时会加宽，逼你连自己脚下一起看 |
| 分影 | 撕下影子独立横扫 5s | 爆发 / 场面压制 | 期间本体受伤 +35%：它把唯一的近身窗口卖给你 |
| 长夜 · 一灯 | 二阶段大招，夺灯 + 全场影子向它聚拢的一次挤压斩 | 终局压制 | 前摇最长，落点全在地面画好 |

**二阶段专属机制层（P2 才出现的规则）「夺灯 · 反照」**：半血后它把光源收进自己灯笼 —— 光源从此是它。于是**你自己的影子开始动手**（沿「它→你」反向延长，它出招时你的影子同步挥斩，伤害 0.6×），而它的本体不再有影子：你原来靠弹反打的「影子反噬它」全部失效。新解法只靠走位：背对它的灯笼站，你的影子甩到你身后；或者一直保持移动让它读不到你的静止位置。P2 数值只是这次规则改动的补贴，不是 ×1.25。

**空手可破**：弹反影削/投晷 → 影子折回去砍它自己（0.9× 反噬）； perfect 闪避 → 影尖在地上留墨痕，墨痕只拖慢**它**；走位 → 把它逼到灯下它的远程招全部哑火。没有一门观澜或执烛的功法是必需的。

**不逃课**：贴灯＝进它的本体近战射程，且它缺距离时立刻用踏波抢回边缘；缩在灯背后（影子的盲区）＝正好站在本体与照骨光束的直线上。

**玩家侧继承**（8 式 → 8 门可学，与刀客 9→9、剑客 12→8、观澜 8→8 同量级）：玩家招式「随身布一盏灯」——把灯笼落在地面某处（可主动摆位），之后你的影系招式都在**灯笼的反向延长线**上结算，等于你的判定框可以打在别人身后；弹反、元素、走位照常。不依赖任何 BOSS 私有状态。

**数值（反推）**：48,000 血 / 205 攻 / 移速 108·126 / P2 伤害 ×1.5（按 2026-10-31 定的 1.5 口径）。目标自动 TTK 68~78s（观澜 63s 的上一档）；单下小招 0.55~0.85×，大招 1.6×（≈328，62% 血），保证至少两下以上才致死。魔抗 0、物抗按现有档 12%。

**掉落**：`mat_zhaoying_zhulei`「照影烛泪」（位面第二材料，20%）+ 物理向武器「长夜刃」（物攻 / 攻速 / 移速）+ 饰品「烛泪坠」（气血 / 物抗 / 一个现有装备没覆盖的抗性，具体抗性按现有装备表挑缺口）。元魂 + 执烛令照旧。

**美术**：赛璐璐人形——高瘦、提一盏铜灯、披风下垂到地但不粘腿（rig 拆 body / lantern / 下摆两件，下摆单独一层方便影子复用贴图）；影子直接用本体贴图压暗拉伸，零新增素材成本；战场地面沿用 `zhaoying_arena_ground` 但换一张「灯台石坪」变体，FX 用 `ArtDB.SKILL_FX` + `SkillFx.play_at_strike`，影＝墨黑柔边、光＝银白冷光，与观澜的镜片涟漪区分。

## 方案 B：「回川」—— 折光 · 界水

场地上有一片浅水与一段干礁，**交界线会缓慢平移**。它的光束招跨越交界线时**折向一个确定角度**：你在哪一侧，同一招的落点就完全不同。它的整套技能围绕「把你推过线 / 把你钉在线的一侧」设计（击退、封路、拉拽），折光才是兑现。

- 二阶段专属层：交界线裂成**两条对向移动的前缘**，中间只剩一条会滑动的干礁带；新增「倒灌」——全场淹水 4s，只有几块石洲露出，站水里移速 −35%。
- 空手可破：读数就是水面与干礁的实际边界 + 前摇画出的折线；站在同侧不越线即可，弹反它的物理突进、闪避它的水法。
- 与既有差异：没有人做过「同一招因场地介质改变判定路径」。风险：**方向可读性最难做**，折线必须每招画全，否则必被判空放；且「场地平移」和方案 D 有重叠。

## 方案 C：「司夜」—— 先声 · 后实

它每招**先立一个声（铜铃 + 地面刻漏纹），延迟 1.4s 才落下实体一击**；立声期间它继续走位、封你退路。场上同时存在 2~3 个「已宣告未兑现」的落点，你要在多个未来时间点里选一条还能走出去的路。

- 二阶段专属层：落点不再等长 —— 刻漏纹收紧＝0.4s 后落、变淡＝3s 后落，且它会「催漏」一次让全部已立声同步落下。
- 空手可破：在**落下的那一帧**弹反可取消并让它僵直；纯走位也能全躲。
- 与既有差异：弹反窗口从起手挪到结算帧，是全新动词。风险：**和定阵先生的插旗读法在观感上最像**（地上有纹样、之后才生效），也容易被判「像延迟版空放」；另外「站原地会被落点追到」有擦边判词「禁立」的嫌疑。

## 方案 D：「海若」—— 潮信 · 浮沉

潮汐按固定拍子上落（拍子由水位线本身画在场上，不是条）。水位低＝干礁可用、它的突进砸地成立；水位高＝浅水拖慢你 25%、它的物理投射入水即灭、术法射程加长。它潜进水里再从某处浮出，浮出点决定这一招打谁。

- 二阶段专属层：出现**两道相向潮头**，中间挤出一条安全缝并持续位移，逼你每 6s 重新找一次落脚点；新增「归墟」在潮头交汇处开一个吸口。
- 空手可破：水位与潮头是看得见的实体边界，走位 + 按时机切换物理/术法即可，不需要任何功法。
- 与既有差异：没有人用「随时间变形的场地」做核心。风险：**最像方案 A/B 的场地家族**，且「它潜在水里＝打不到」的窗口一旦被拉长就会被判逃课反噬（玩家无事可做）。

## 对照与结论

| | 核心动词 | 势条/叠层 | 首战空手 | P2 专属机制层 | 与既有最近的一只 |
|---|---|---|---|---|---|
| A 执烛 | 位置→投影几何 | 无 | ✔ | 光源交接，影子规则反转到玩家身上 | 观澜（都有「影」字面，但观澜是复制玩家招式的独立镜像体，A 是没有实体的投影 hitbox） |
| B 回川 | 介质改变判定路径 | 无 | ✔ | 双潮头 + 全场淹水 | 定阵（场地分割） |
| C 司夜 | 结算帧后移 + 弹反时机 | 无 | ✔ | 落点时长可变 + 同步催发 | 定阵 / 判词 |
| D 海若 | 场地随时间变形 | 无 | ✔ | 双潮头挤压安全缝 | B / 苍角（水） |

**推荐 A**。它是四个里唯一把「读数＝物件几何」做成硬规则、并且**AI 选招门禁直接被机制本身约束**的方案：投晷的射程等于当前影长，影不够长就不许出招 —— 这一条天然把「不许原地空放」从检查项变成机制，也让「把 BOSS 逼到灯下」成为玩家真正的空间目标。B/C/D 的场地变形与延迟落点各有一处需要额外证明「玩家不是被动等待」，A 从第一帧就在抢位置。
